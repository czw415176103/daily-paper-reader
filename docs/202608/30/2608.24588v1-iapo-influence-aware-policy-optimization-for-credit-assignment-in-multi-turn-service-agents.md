## 摘要
大语言模型（LLM）智能体越来越多地通过与用户和外部工具的多轮交互来解决长程任务。在这些场景中，相关任务信息通常随时间逐步展开，而不是在初始提示中完全给定。服务智能体使这一挑战尤为具体：用户可能澄清或修改其目标，而工具响应则为后续决策提供所需信息。因此，仅凭最终奖励无法指示哪些动作有助于解决任务。近期方法依赖于来自其他轨迹或重采样延续的比较证据，或依赖于单独构建的步骤级学习信号，以细化信用分配。然而，一次完整的轨迹展开已经记录了信息和错误如何在智能体动作之间流动。我们提出了影响感知策略优化（IAPO），将每次轨迹展开表示为一个类型化的影响依赖图，图节点为可训练的智能体动作，用户和工具的观测作为证据。IAPO将支持使用和失败使用的结构转换为路由权重，从而重新分配相同的轨迹级优势。使用Qwen3-4B和Qwen3-8B进行的实验表明，在三个服务智能体基准（{τ^2}-Bench、UserBench和AgentChangeBench）上，性能优于多轮强化学习（RL）基线。BFCL-v4多轮进一步表明这些增益不会损害多轮函数调用性能。这项工作推进了对多轮用户交互中信用分配的理解，并提供了一种从稀疏结果反馈中训练服务智能体的原则性方法。

## Abstract
Large Language Model (LLM) agents increasingly solve long-horizon tasks through multi-turn interactions with users and external tools. In these settings, relevant task information often unfolds over time rather than being fully specified at the initial prompt. Service agents make this challenge especially concrete: users may clarify or revise their goals, while tool responses provide information needed for subsequent decisions. Thus, a final reward alone cannot indicate which actions contributed to resolving the task. Recent methods rely on comparative evidence from other trajectories or resampled continuations, or on separately constructed step-level learning signals, to refine credit. However, a completed rollout already records how information and errors flow between agent actions. We introduce Influence-Aware Policy Optimization (IAPO), which represents each rollout as a typed influence-dependency graph over trainable agent actions, with user and tool observations serving as evidence. IAPO converts support-use and failed-use structure into routing weights that redistribute the same trajectory-level advantage. Experiments with Qwen3-4B and Qwen3-8B demonstrate superior performance over multi-turn reinforcement learning (RL) baselines across three service-agent benchmarks: {τ^2}-Bench, UserBench, and AgentChangeBench. BFCL-v4 Multi-Turn further shows that these gains do not compromise multi-turn function-calling performance. This work advances the understanding of credit assignment in multi-turn user interactions and provides a principled approach to training service agents from sparse outcome feedback.

- **现有方法的不足**：
  - 轨迹级 RL（如 GRPO）将同一 group-relative advantage 均匀分配给所有 token，无法区分中间动作的真实贡献；
  - 跨轨迹方法（如 GiGPO、Tree-Search）依赖可复现状态/可重置环境，自由形式的用户和工具对话不满足这类条件；
  - 额外信号方法（如 InfoPO、SWEET-RL）引入独立于任务奖励的 step-level 学习信号，有与真实目标发生漂移的风险。
- **关键洞察**：一次已经完成的 rollout 内部，其实已经记录了信息如何在动作间流动、错误如何传播。论文主张直接利用轨迹内部已实现的依赖结构来重新分配信用，**无需额外的奖励信号、对比轨迹或重采样**。

## 2. 论文提出的方法论

### 核心思想

IAPO 将每条完成轨迹建模为 **类型化影响-依赖图（typed influence-dependency graph）**，节点为可训练的 assistant 动作，边表示动作间的“支持使用”（support-use）或“失败使用”（failed-use）关系，用户消息与工具返回仅作为证据（不参与策略梯度）。随后将轨迹级 advantage 依据该图结构路由（routing）到各动作，从而收紧信用分配粒度。

### 关键技术细节与流程

1. **影响依赖图构建**：
   - 定义节点集合 V_τ = {a_1, …, a_T}，边分为正边（支持使用，annotation 类型为 input/success_utilization）和负边（失败使用，类型为 failed_utilization）。
   - 边的接受需同时满足三个条件：
     - **必要性**：后续动作引用了源自先前动作的具体信息单元（仅讨论同一主题不够）；
     - **显式绑定**：引用信息需绑定到后续动作的具体参数/分支/纠错行为；
     - **来源优先级**：多个来源重叠时保留最全面者，最早出现者优先；非重叠信息允许多来源。
   - 错误指示器 e_i 标记动作是否携带可观察错误（工具、schema、运行时、规则失败或用户/环境明确拒绝）。

2. **图特征计算**：
   - 支持得分：φ⁺_i = log(1 + d⁺_i + d_in_i)
   - 错误得分：φ⁻_i = log(1 + e_i(1 + d⁻_i + d_in_i))
   - 其中 d⁺_i 为支持使用出度，d⁻_i 为失败使用出度，d_in_i 为支持证据入度。

3. **有界权重变换**：
   - 将特征标准化（长度加权均值/方差）、clip 到 [-c, c]、再按长度加权均值归一化为 1，得到支持权重 m⁺ 和错误权重 m⁻。这种方式保证乘性权重为正、有界且总质量守恒。

4. **符号条件路由（sign-conditioned routing）**：
   - **正优势 rollout**（Â_τ > 0）：以 m⁺ 为基础，对带有超出平均错误证据的步骤打折扣：
     
     w⁺_i(β⁺) = L · m⁺_i · exp(−β⁺ · ψ⁻_i) / Σ_j L_j · m⁺_j · exp(−β⁺ · ψ⁻_j)
     
     其中 ψ⁻_i = φ⁻_i − φ̄⁻。β⁺=0 时退化为纯支持路由；β⁺ 越大则对“修复过错误”的步骤惩罚越多。
     
   - **负优势 rollout**（Â_τ < 0）：直接采用 m⁻，保守地将责备集中于有可观察错误证据的步骤。
   
5. **最终 token 优势**：A_i,ℓ = Â_τ · w_i，传给与 GRPO 相同的 clipped-loss 实现。

6. **理论保障**（Proposition 1–4）：
   - **质量守恒**：总 token 优势质量等于 L·Â_τ；
   - **均匀回退**：图特征恒定时退化为 GRPO 的均匀分配；
   - **符号保持**：所有权重为正，不改变优势符号；
   - **优化接口保持**：不改变奖励、rollout、归一化等，只改变 token 级梯度估计。

## 6. 论文的主要结论与发现

- **IAPO 显著优于 GRPO**：8B 规模下 τ²-Bench 从 29.61% → 42.18%（+12.57 pp），UserBench +4.61 pp，AgentChangeBench +4.41 pp；
- **“延迟状态使用”场景收益最大**：电信域 +18.19 pp、零售 +12.57 pp——因为这类场景中早期动作的价值只有在后续信息揭晓后才能辨识，均匀 credit 的误导性最强；
- **OOD 泛化良好且不牺牲函数调用能力**：BFCL-MT 与 GRPO 基本持平（39.36 vs 39.04），说明服务域增益来自更精准的信用分配，而非对函数调用能力的过拟合损伤；
- **路由权重显著偏离均匀分配**：正权重 std=0.222，范围 0.637–1.505，86.5% 的步骤偏离均匀 credit 超过 10%；
- **支持信号与错误信号均有用**：β⁺=0 已提升 τ² 至 32.50；加入小 β⁺（0.05）达最优（42.18），过大反而下降（31.39），说明错误证据是“修正”而非“替代”支持路由；
- **标注稳定性良好**：跨模型标注一致性高（边缘 F1 约 0.87，m⁻ 的 Spearman ρ 接近 1），说明 IAPO 不依赖特定标注模型的输出；
- **可证明的性质保障**：质量守恒、符号保持、均匀回退、接口保持等理论性质为方法提供了可靠保证。

## 7. 优点

- **方法论亮点**：
  - 首个仅利用 **已实现轨迹内部依赖结构** 进行信用分配的方法，无需额外的对比轨迹、重采样、可重置环境或独立步骤级评分通道；
  - 设计了带理论保障的乘性权重路由机制（质量守恒、符号保持、长-均值归一化），避免 additive 修正带来的符号翻转和总质量变化；
  - 保持 GRPO 的 critic-free、group-based 架构，改动极小、接口兼容，易于在现有 GRPO 框架上落地；
  - 将用户消息与工具返回作为“证据”而非“训练信号”，避免了信号漂移问题。
- **实验设计亮点**：
  - 与 GRPO 的对照严格隔离变量（仅 advantage 映射不同），是归因清晰的控制实验；
  - 多维度评估：in-domain 分域表现、OOD 泛化、函数调用保留、超参敏感性、标注模型迁移、行为案例，覆盖面广；
  - 标注一致性审计增强了方法对标注误差的鲁棒性证据。

## 8. 不足与局限

- **依赖冻结标注模型**：影响图由 Qwen3-32B（或替代模型）在 temperature=0 下提取，虽然跨模型一致性较好，但标注仍可能有系统偏差；标注模型的成本和质量是实际部署时的重要考量。此外，文中未报告标注失败的案例，仅报告了 100% 的 parse rate；
- **实验覆盖范围有限**：训练仅在 τ²-Bench 单一源上进行（178 任务），虽然验证了多个 OOD benchmark，但服务域多样性（如金融、医疗、法律等）和更广泛的语言/文化场景尚未验证；
- **算力相关信息不透明**：未报告训练时长、总 GPU 时数、采样成本等，不利于成本和可复现性评估；
- **超参敏感性**：β⁺ 和 c 对结果影响较大（如 c=0.5 时 UserBench 从 24.44 降至 17.78），虽然默认值在三个 benchmark 上表现好，但对新域需要重新调参；
- **负优势分支的设计偏保守**：负分支只依赖错误证据，对“无明显错误但策略本身不佳”的失败轨迹可能缺乏辨别力；
- **与外部 SOTA 的对比不足**：Fission-GRPO（4B/8B）在部分指标上优于 IAPO，但训练数据规模和构造方式差异较大（630 任务 vs. 178 任务），两者并非完全可比；表中也明确指出这些数字来自外部报告，未在同一 protocol 下复现验证；
- **基准本身的限制**：用户模拟器（GPT-5.2 等）与真实用户存在分布差异，评估指标的生态效度仍待实际部署验证。
