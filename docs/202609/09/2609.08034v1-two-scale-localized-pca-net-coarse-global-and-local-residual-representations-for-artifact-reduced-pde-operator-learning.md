## 摘要
局部化降维提高了高维偏微分方程（PDE）算子学习的可扩展性，但独立解码的局部块可能引入块偏移、界面失配和虚假的高波数内容。我们提出了双尺度局部PCA-Net，将解分解为粗尺度全局分量和局部残差校正。一个紧凑的全局PCA基捕获域尺度结构，而非重叠的局部PCA基表示剩余的细尺度残差。一个块平衡的潜在目标耦合了两种表示，可选的界面感知微调通过重建和迹损失进一步促进连续性。在Poisson基准测试中，与普通和基于重叠的局部PCA-Net相比，双尺度表示显著减少了重建误差和可见块伪影，同时相对于重叠方式将PCA拟合成本大约减半。在非均质Darcy流中，它强烈减少了界面和离散残差误差，而重建增益较为温和。消融研究表明，主要改进来自双尺度输出表示，而界面感知微调提供了互补的连续性细化。总体而言，将全局相干结构与局部残差细节分离为减少伪影的PDE算子学习提供了一种高效表示。

## Abstract
Localized dimensionality reduction improves the scalability of operator learning for high-dimensional partial differential equations (PDEs), but independently decoded local patches can introduce block offsets, interface mismatches, and spurious high-wavenumber content. We introduce Two-Scale Localized PCA-Net, which decomposes the solution into a coarse-global component and local residual corrections. A compact global PCA basis captures domain-scale structure, while nonoverlapping local PCA bases represent the remaining fine-scale residual. A block-balanced latent objective couples the two representations, and optional interface-aware fine-tuning further promotes continuity through reconstruction and trace losses. On Poisson benchmarks, the two-scale representation substantially reduces reconstruction error and visible block artifacts relative to plain and overlap-based localized PCA-Net while approximately halving PCA fitting cost relative to overlap. On heterogeneous Darcy flow, it strongly reduces interface and discrete-residual errors, with more modest reconstruction gains. Ablations show that the primary improvement arises from the two-scale output representation, while interface-aware fine-tuning provides complementary continuity refinement. Overall, separating globally coherent structure from localized residual detail provides an efficient representation for artifact-reduced PDE operator learning.

- **研究背景**：在高维偏微分方程（PDE）算子学习中，局部化降维技术（如局部PCA-Net）通过将计算域划分为块，以分而治之的方式提升模型的可扩展性。
- **核心问题**：独立解码的局部块在拼接时会产生**块偏移**、**界面失配**以及**虚假高波数伪影**，破坏重建的整体质量与连续性。
- **研究含义**：如何在享受局部化带来的计算效率与可扩展性的同时，有效抑制因块间不协调产生的伪影，是局部算子学习方法落地的关键障碍。

## 2. 方法论：Two-Scale Localized PCA-Net
- **核心思想**：将偏微分方程解分解为两个互补的尺度分量：
  - **粗尺度全局分量**：用紧凑的全局PCA基捕获域的全局结构/低频大尺度形态；
  - **局部残差分量**：用非重叠的局部PCA基来拟合扣除全局分量后的细尺度空间残差。
- **关键技术细节**：
  - **双尺度潜在目标**：通过一个"块平衡"（block-balanced）的潜在目标函数将两种表示耦合并统一训练；
  - **界面感知微调**：可选步骤——在预测阶段使用**重建损失**与**迹损失**（trace losses）对局部界面进行额外约束，以强制跨块的连续性与平滑过渡；
  - **无重叠设计**：相比必须引入重叠区域来缓解伪影的旧方案，本方法使用非重叠块，降低计算与拟合成本。

  5. （可选）加入界面感知微调，强化跨块连续性并进一步降低迹损失与重建误差。

  - 共两大物理场景（Poisson、Darcy）；
  - 对比三类方法（普通、overlap、Two-Scale）；
  - 对 Two-Scale 进行了**消融实验**测试各模块单独贡献；
  - 还考察了重建误差、界面误差、离散残差、PCA拟合成本等多类指标。
- **充分性与客观性评价**：
  - **优点**：实验覆盖了均匀/非均质、显式界面及算子学习多种典型情况，误差度量维度较多，消融设计较为清晰，能够有效分离方法各组成部分的贡献；
  - **不足**：实验主要集中于稳态椭圆/扩散型方程（Poisson 与 Darcy），**未覆盖**时间依赖的非线性PDE（如Navier-Stokes、浅水波等），此类方程中的伪影形态与传播特性差异更大，结论的可推广性有限。

## 6. 主要结论与发现
- 在 Poisson 基准中，两尺度表示相比普通局部 PCA-Net 和 overlap 方法显著降低重建误差，并有效抑制可见块伪影；
- 在非均质 Darcy 流中，界面误差与离散残差显著下降，重建精度提升相对温和；
- 相对于 overlap 方案，两尺度方法将 PCA 拟合成本大致减半（效率提升）；
- 消融显示，**主要收益来自双尺度输出表示**，界面感知微调仅提供互补、次要的连续性细化；
- 总体结论：**将全局相干结构与局部细节分离，是一种高效且能减少界面伪影的算子学习表征策略**。

## 7. 方法/实验设计的优点
- **结构创新性强**：巧妙地用全局-局部残差分解打破"重叠才能连续"的惯性思路，从根源上避免部分界面冲突;
- **效率与精度兼顾**：非重叠 + 全局粗尺度联合策略，使 PCA 拟合成本明显低于 overlap 方案，精度不降反升；
- **模块清晰、可解释**：块平衡目标与界面感知微调解耦，便于进行模块级消融分析；
- **适用面覆盖了常见的算子学习工业场景**：Poisson 与 Darcy 分别是经典线性椭圆问题和非均质介质流动的典型代表，对比基准明确；
- **指标全面**：从重建误差、伪影可见性、解释性残差到界面误差多方位评估。

## 8. 不足与局限
- **基准场景较窄**：只验证了 Poisson 和 Darcy（线性的椭圆型稳态问题），未评估在**非线性、高雷诺数、时变/湍流系统**中的表现；
- **界面强制方式有限**：可选的"trace 损失 + 重建损失"微调只保证 C0 型连续而非高阶光滑性的严格约束，可能在某些含强间断/激波问题上出现过平滑；
- **关于算力资源的信息缺失**：未报告 GPU 型号、数量、单次训练时长等实际资源占用情况，这会影响研究者判断该方法在大规模部署时的真实硬件门槛；
- **缺乏与更多主流的非局部模型比较**：没有直接和全局 FNO/DeepONet 等 SOTA 基底做重建精度与计算成本的双向对比，因此无法权衡该方法与纯全局方法的适用群体边界；
- **实测增益在各指标上的不一致性值得警惕**：在 Darcy 问题中重建增益温和，说明该方法在不同问题严重度上的改善存在差异，适用性挑选依据（如谱性质、界面结构）并未被系统刻画。
