## 摘要
表格数据作为机器学习中的核心数据格式，由于特征信息量不足，往往缺乏高性能建模所需的判别能力。自动特征工程（AutoFE）通过自动化特征生成与选择来克服这一局限，从而兼顾模型性能与运行效率。然而，传统AutoFE因依赖盲目的数学变换，常生成可解释性较差的特征；而基于大语言模型（LLM）的AutoFE则需要昂贵的多轮迭代来生成高价值特征以有效提升模型性能，同时还存在固有的偏差与幻觉风险。本文结合符号回归与LLM进行特征工程（SymboLLM-FE），以解决上述挑战。我们通过符号回归提取与目标强相关且具有数学表达形式的公式，以增强模型性能，再借助具有丰富先验知识的LLM对其进行优化，确保可解释性。在六个真实数据集和四个Kaggle竞赛上的实验结果表明，SymboLLM-FE优于现有AutoFE方法。SymboLLM-FE还通过采用基于统计先验的LLM优化机制和个位数次的LLM调用，解决了可解释性差和迭代次数多这两个双重挑战。

## Abstract
Tabular data, as a core data format in machine learning, often lacks the discriminative power needed for high-performance modeling due to insufficient feature informativeness. Automated Feature Engineering (AutoFE) overcomes this by automating feature generation and selection, ensuring both model performance and operational efficiency. However, traditional AutoFE often yield features with poor interpretability because they rely on blind mathematical transformations, while large language models (LLM)-based AutoFE faces challenges in requiring costly multi-round iterations to generate high-utility features to effectively enhance model performance, compounded by inherent risks of bias and hallucination. In this paper, we combine symbolic regression with LLMs for feature engineering (SymboLLM-FE) to solve these challenges. We extract mathematically expressive formulas strongly correlated with the target via symbolic regression, which can enhance model performance, then refine them by LLMs with rich prior knowledge to ensure interpretability. Empirical results on six real-world datasets and four Kaggle competitions demonstrate that SymboLLM-FE outperforms existing AutoFE. SymboLLM-FE also addresses the dual challenges of poor interpretability and numerous iterations by employing a statistical prior-grounded LLM refinement mechanism and single-digit LLM calls.

## 2. 方法论：核心思想、关键技术细节、公式或算法流程

SymboLLM-FE提出一种**两阶段协同流水线**，将符号回归（Symbolic Regression, SR）与LLM结合：

### （1）第一阶段：符号回归的公式构建（Formula Construction by Symbolic Regression）

- **特征子集采样**（Feature Set Sampling）：
  - 采用**Spearman相关系数**对原始特征进行重要性排序，得到有序特征序列 \( C' = \{c'_1, c'_2, ..., c'_n\} \)。
  - 提出**扩张-滑动窗口**（expanding-sliding window）策略：窗口大小从 \( \lfloor n/2 \rfloor \) 逐渐扩张到 \( n \)，并在每个固定窗口大小下向右滑动，生成多个连续特征子集。
  - 该策略将搜索空间从指数级 \( O(2^n) \) 降低到多项式级 \( O(n^2) \)，具体公式为：
    \[
    \sum_{k=\lfloor n/2 \rfloor}^{n} (n-k+1) = \begin{cases}
    \frac{(n+2)(n+4)}{8}, & \text{if } n \text{ is even} \\
    \frac{(n+3)(n+5)}{8}, & \text{if } n \text{ is odd}
    \end{cases}
    \]

- **公式生成**（Formula Generating）：
  - 对每个特征子集 \( S_i \)，训练一个符号回归模型（使用遗传编程，如gplearn库），生成从 \( S_i \) 到目标变量 \( y \) 的数学公式 \( \tau_i \)。
  - 同时记录符号回归模型的性能 \( P_f(S_i) \)，构建**公式仓库**：
    \[
    R = \{ (S_i, P_f(S_i), \tau_i) \}_{i=1}^{|S|}
    \]

### （2）第二阶段：基于LLM的特征生成（Feature Generation via LLMs）

- **LLM引导的代码生成**：
  - 将符号回归得到的公式 \( \tau_i \) 转化为自然语言描述，并附加数据集背景信息和代码生成提示词，通过**思维链（Chain-of-Thought）** 让LLM生成可执行的Python pandas特征工程代码。
- **下游预测器性能验证**：
  - 执行生成的代码，得到新特征集 \( C_{new} \)，与原始数据合并得到 \( C_{final} = C \oplus C_{new} \)，并训练下游预测器（如CatBoost、TabPFN）评估性能。
- **迭代特征优化**：
  - 将预测器性能、使用的特征和代码反馈给LLM，进行迭代优化，直到预测器在增强特征集上达到相对最优性能。
  - 同时，通过**特征预算管理**和**冗余消除**机制（包括动态剪枝、语义等价性检查等）确保最终特征集的紧凑性，抑制过拟合和多重共线性。

该框架将LLM的角色限制为**语义解释器和规则优化器**，而非开放式的特征生成器，从而在统计上锚定特征生成过程，消除幻觉风险。

## 8. 不足与局限

- **可扩展性瓶颈**：尽管搜索空间被压缩，但符号回归本身在高维数据上仍耗时，论文承认在资源受限或实时场景下可行性受限。
- **子集构建策略局限**：基于Spearman排序的连续滑动窗口可能**遗漏非相邻特征之间的协同效应**——当两个隐式相关的特征在排序中不相邻时，它们的联合预测贡献可能被忽略。
- **数据集规模有限**：实验数据均为中小规模（最大1.2万条），未验证在大规模高维表格数据上的表现。
- **LLM调用次数过少可能限制优化上限**：仅4次调用是否足以充分探索特征空间值得商榷，且未对更多迭代轮次进行敏感性分析。
- **依赖数据预处理**：符号回归对数值特征更友好，对高基数分类特征或缺失值处理未做深入讨论。
- **统计显著性不均衡**：在Credit-g和Ailerons数据集上，SymboLLM-FE的优势未达到统计显著（p>0.05），说明性能提升并非在所有场景下都稳定。
