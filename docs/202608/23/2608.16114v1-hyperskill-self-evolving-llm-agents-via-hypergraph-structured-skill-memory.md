## 摘要
随着智能体任务日益复杂，LLM智能体越来越依赖经验记忆来跨任务重用程序性知识。有效的记忆设计必须共同解决存储什么、记忆如何结构和检索，以及记忆如何演化。现有系统仅部分地处理这些问题：它们将轨迹、见解或工作流存储为孤立条目，丢弃了子任务与可重用技能之间的组合关系；通过忽略关系信号的扁平嵌入相似性进行检索；并在不利用其关系结构的情况下维护记忆。我们提出HyperSkill，一种基于超图的记忆框架，共同改进这三个方面。HyperSkill将记忆表示为具有两种节点类型（子任务步骤和可重用技能）的超图，其中每条超边连接来自单个轨迹的子任务和技能。双路径检索同时查询子任务和轨迹级别，通过检索轨迹中的共现对技能进行排序。周期性结构感知维护修剪低效用节点，并通过质量加权传播合并冗余技能。在xBench、GAIA和WebWalkerQA上，使用GPT-4o和Qwen3-30B-A3B，HyperSkill优于十种记忆基线，在GAIA上获得高达+11.51的提升，在WebWalkerQA上获得+11.18的提升。

## Abstract
As agentic tasks grow in complexity, LLM agents increasingly rely on experiential memory to reuse procedural knowledge across tasks. Effective memory design must jointly address what to store, how memory is structured and retrieved, and how memory evolves. Existing systems tackle each only partially: they store trajectories, insights, or workflows as isolated entries, discarding compositional relationships among subtasks and reusable skills; retrieve by flat embedding similarity that ignores relational signals; and maintain memory without leveraging its relational structure. We propose HyperSkill, a hypergraph-based memory framework that jointly improves all three. HyperSkill represents memory as a hypergraph with two node types, subtask steps and reusable skills, where each hyperedge links the subtasks and skills from a single trajectory. Dual-path retrieval queries both subtask and trajectory levels, ranking skills by co-occurrence across retrieved trajectories. Periodic structure-informed maintenance prunes low-utility nodes and merges redundant skills via quality-weighted propagation. Across xBench, GAIA, and WebWalkerQA with GPT-4o and Qwen3-30B-A3B, HyperSkill outperforms ten memory baselines, yielding gains of up to +11.51 on GAIA and +11.18 on WebWalkerQA.

## 1. 论文的核心问题与整体含义（研究动机与背景）

LLM 智能体在长时程任务（如网页导航、交互式计算机使用、多步科学推理）中，单一交互往往不足以可靠地完成任务。经验记忆（experiential memory）通过对智能体自身历史轨迹进行蒸馏，将过程性知识转化为可复用的记忆，使智能体能够“自我演化”（self-evolving），从每次轨迹中不断积累能力。

然而，现有记忆系统在三个关键设计维度上均存在明显缺陷：

- **存储什么（what to store）**：现有系统或将轨迹、见解、工作流以孤立条目存储，或提炼为独立技能，但都丢掉了子任务与可复用技能之间的组合关系，导致无法跨任务共享过程性规划结构。
- **如何结构化与检索（how is structured and retrieved）**：多数系统采用扁平向量库或二元图，仅依赖嵌入相似度检索，无法表达技能与子任务模式之间的 n 元共现关系，忽略关系信号。
- **如何演化（how memory evolves）**：大多数系统无条件堆积记忆，少数系统仅做简单的逐节点剪枝或去重，未利用记忆的关系结构进行联动维护。

论文的核心主张是：**一条轨迹不是单一知识单元，而是子任务、技能与结果之间的 n 元关联结构**。扁平列表与成对边只能有损地表示这种结构。为此，论文提出 **HyperSkill**，一个基于超图（hypergraph）的经验记忆框架，将记忆构建为“子任务节点 + 技能节点 + 轨迹级超边”的三元结构，从而在存储、检索、演化三个维度上同时改进经验记忆的设计。

## 2. 论文提出的方法论

### 2.1 核心思想

HyperSkill 将经验记忆组织为超图 G = (V, E)：

- **节点（Nodes）**：包含两类节点：
  - 子任务节点（V_μ）：每个节点编码任务分解中的一步，包括步骤描述与前置条件。
  - 技能节点（V_s）：从轨迹中提炼的可复用执行策略（成功轨迹产出正向策略，失败轨迹产出错误模式）。
  - 每个节点都带有内容（c_i）、类型标签（ℓ_i ∈ {u, s}）和动态效用分数（γ_i ∈ [0,1]）。
- **超边（Hyperedges）**：每条超边对应一条完整轨迹，将其中出现的子任务节点和技能节点连接在一起，同时附有原始任务描述、蒸馏出的可迁移经验教训（lesson）和效用分数。

### 2.2 关键技术细节

**效用分数更新（公式 3）**：对所有参与检索的节点和超边，根据成功次数、总检索次数和步数更新效用分数，平衡成功率与步骤效率（β 为调和系数）。

**双路径超边检索**：
- **子任务路径**：将当前任务先经 LLM 分解为子任务集合 P0，编码后匹配最相似子任务节点，再通过节点关联的超边扩展到候选轨迹集合 E_sub。此路径能发现任务层面描述不同但过程结构相似的轨迹。
- **轨迹路径**：将完整任务描述编码后，直接与超边表示 h_e = φ(d_e ∥ ℓ_e) 匹配，检索任务语义最接近的轨迹集合 E_traj。
- 两条路径的候选集合并集 E* = E_sub ∪ E_traj 作为最终检索结果，形成互补。

**技能共现排序**：对合并后的轨迹集合，收集其中全部技能节点，按技能在检索到的超边中出现的频次 κ(v) 排序，选取 top-k 技能作为执行指导（并列时以嵌入相似度破平）。此排序利用技能节点跨轨迹重用的结构信号，弥补纯语义相似度无法捕捉的“是否实际被应用”的问题。

**执行与记忆更新**：检索到的技能与经验教训在整轮执行中固定。任务完成后，通过结果条件化提示从轨迹中提取新技能和教训，新增子任务节点，并依据去重阈值 δ_dedup 合并相近技能，添加新超边，更新相关元素的效用分数。

**结构感知维护（每 ⌈0.1 × N⌉ 个任务触发一次）**：
- **质量驱动剪枝（公式 11）**：移除被检索次数足够多（ν(v) ≥ N_min）但效用分数低于阈值（γ(v) < τ_prune）的节点，并从所有超边成员关系中删除。
- **结构感知合并（公式 12–14）**：构建质量加权共现矩阵 W（基于节点效用 min(γ_i, γ_j) 与超边大小归一化系数），通过 L 步对称传播获得结构嵌入，对相似度超过阈值 δ_merge 的技能对，用 LLM 将其合并为更通用的高阶技能，并将原超边成员关系重分配给新节点。

- **一致性的性能提升**：在 GPT-4o 下，HyperSkill 的成功率相对第二好方法在 xBench、GAIA、WebWalkerQA 上分别高出 +3.00、+2.30 和 +0.59；在 Qwen3-30B-A3B 下相对 No Memory 分别提升 +6.00、+4.85 和 +11.18。

- **自演化效应**：HyperSkill 是唯一表现出持续上升累积成功率趋势的方法，且任务多样性越强，自我演化收益越明显。
- **对噪声标签具有鲁棒性**：self-judge 变体保留了 GT-judge 87.7%–96.8% 的性能，表明共现排序能稀释个别错误结果的影响。

## 7. 优点

- **统一解决三个设计维度**：HyperSkill 在一个框架内同时改进“存储什么、如何检索、如何演化”，而非只优化单一环节。
- **超图天然表达 n 元组合关系**：超边保留了轨迹中所有子任务与技能的组合上下文，是扁平列表与成对图无法实现的独特优势。
- **双路径检索设计巧妙**：子任务路径与轨迹路径互补，一个捕捉过程结构相似，一个捕捉任务语义相似，合流后覆盖更全面的检索视角。
- **共现排序简单有效**：利用技能节点跨轨迹重用的结构信号进行排序，比纯嵌入相似度更能反映技能在任务相关情境中的实际效用。
- **结构感知维护先进**：质量加权传播同时考虑节点效用与超图拓扑，剪枝与合并不是孤立逐节点操作，而是利用关系结构的联动维护。
- **实验严谨度**：引入 token 成本与延迟分析，报告性能-成本权衡而非只报准确率，有助于评估实际部署价值。
