## 摘要
在智能体科学机器学习（SciML）中，大语言模型（LLM）智能体能够发现代理模型并通过自动化评分（通常是误差指标）选择一个。然而，低误差并不能保证预测场满足力学中重要的物理特性，例如边界条件、叠加原理、刚度缩放或因果性。我们引入了物理审核的智能体科学机器学习（PA-SciML），这是一种面向智能体科学机器学习发现的验证优先工作流程。该工作流程在搜索之前固定评分评估器，推导可审查的机器可检查的物理要求，检查每个训练后的候选模型在其输出上的表现，并分别对规定的输入范围或测量的载荷历史跨度进行搜索，以发现高违规案例（无需参考解场）。仅在满足所述检查的情况下，代理模型才被报告为已验证。启用该工作流程后，还会在训练前添加建议性数值探测，并每次测试一个建模变更，记录哪些独立的编辑与评分提升相关，以备后续复用。在报告的计算固体力学数值示例中，静态弹性运行选择的代理模型比纯误差基线的验证误差更低，而两个选定的模型都通过了常见的线弹性检查。在瞬态弹性动力学运行中，一个具有相似平均误差的纯误差基线由于对未来部分载荷历史的响应而未能通过更严格的因果性检查，而选定的代理模型则通过了所述检查。主要区别在于每个候选模型在预测场上提供的物理证据，而非更丰富的聚合评分。

## Abstract
In agentic scientific machine learning (SciML), large language model (LLM) agents can discover surrogate models and select one by an automated score, typically an error metric. A low error, however, does not establish that the predicted fields satisfy the physics that matter for mechanics, such as boundary conditions, superposition, stiffness scaling, or causality. We introduce Physics-Audited Agentic SciML (PA-SciML), a verification-first workflow for agentic SciML discovery. The workflow fixes a scoring evaluator before search, derives reviewable machine-checkable physics requirements, checks each trained candidate on its outputs, and separately searches prescribed input ranges or measured load-history spans for high-violation cases without reference solution fields. A surrogate is reported as verified only under the stated checks. When enabled, the workflow also adds advisory numerical probes before training and tests one modeling change at a time to record which isolated edits are associated with score gains before reuse. In the reported computational-solid-mechanics numerical examples, the static elasticity run selects a surrogate with lower validation error than the error-only baseline while both selected models pass the common linear-elastic checks. In the transient elastodynamics run, an error-only baseline with similar mean error fails a stricter causality check by responding to future parts of the loading history, while the selected surrogate passes the stated checks. The main distinction is per-candidate physics evidence on predicted fields, not a richer aggregate score.

## 论文总结

### 1. 核心问题与整体含义（研究动机和背景）

- **背景**：在科学机器学习（SciML）中，大型语言模型（LLM）智能体可以自动发现代理模型，传统上通过误差指标（如验证损失）进行评分和选择。然而，低误差并不等价于模型预测满足力学问题中的关键物理规律（如边界条件、叠加性、刚度缩放、因果性）。
- **核心问题**：现有的智能体SciML框架（如AgenticSciML、ATHENA等）虽然包含验证步骤，但主要针对代码执行、计划一致性或聚合奖励，缺少对每个候选模型预测输出的独立、可复现的物理检查。仅依赖误差评分可能导致选取的物理上不可信的模型。
- **研究目标**：提出一种**验证优先**的工作流——PA-SciML，在代理发现过程中对每个候选模型施加可机器检查的物理合约，并将物理检查证据与预测误差证据分开报告，从而提升代理模型的可信度。

### 2. 方法论（核心思想、关键技术细节、算法流程）

- **核心思想**：将模型发现与物理验证解耦。LLM智能体负责提议、实现和迭代候选模型，而固定的执行例程（fixed routines）负责评分、物理审计和报告。物理合约（contracts）在搜索开始前设定，包含检查类型、参数、容差和硬/软标签。
- **关键技术细节**：
  - **Discovery Loop**（发现循环）：
    - 用户提供问题陈述、数据描述、可接受输入域和评分目标。
    - 设置阶段：数据分析师、评估员（Evaluator）和机械师（Mechanician）分别生成数据摘要、固定评估器和物理合约文件。
    - 候选搜索：提议者、批评者、工程师、调试者等LLM角色生成、审查、实现和修复候选模型。通过固定例程验证、训练和评分。
  - **Verification Layer**（验证层）：
    - **物理审计（Physics Audit）**：针对每个活跃硬合约，在有限样本集上计算无量纲违规度 `v_c(q)`，并归一化为 `viol_max = max_{c in H} max_{q in S_c} v_c(q)/τ_c`。当 `viol_max` ≤ 报告阈值时，候选通过“采样硬合约门”（Sampled hard-contract gate）。
    - **对手（Adversary）**：可选的独立输入搜索，保持模型固定，在允许输入域内最大化合约违规度，无需参考解场。结果与门分离报告。
    - **软合约**：仅记录，不影响门决策。
  - **Post-Discovery Attribution**（发现后归因）：对改进步骤进行单一编辑隔离测试，计算每个编辑对分数提升的贡献份额 `ϕ_i = (s_parent - s_edit,i) / (s_parent - s_child)`，若主导编辑份额≥0.5则保存方法卡（method card）以供后续检索。
- **算法流程**（文字描述）：
  1. 用户输入问题、数据、输入域、评分目标。
  2. 设置阶段：LLM角色生成数据摘要、固定评估器、物理合约（包括校准和容差，容差不低于3倍校准残差）。
  3. 候选搜索：从根候选开始，通过提议-批评-实现-修复循环生成树。每个候选被验证、训练、用固定评估器评分。启用审计时，运行物理审计。
  4. 验证层：计算 `viol_max`；若 ≤ 阈值，通过门；否则标记为未验证。
  5. 可选的对敌搜索（Adversary）在后运行，报告最大违规。
  6. 可选的后发现归因：对改进步骤分解编辑，重训练并重评分，计算份额，满足条件则保存方法卡。
  7. 最终报告：选定的代理模型标记为“已验证”或“未验证”，同时报告预测误差和物理检查证据。

### 3. 实验设计（数据集/场景、基准、对比方法）

- **场景1：参数化线弹性（Parametric Linear Elasticity）**
  - 域：单位正方形 Ω=[0,1]²，固定网格2601节点。
  - 输入：四个标量——牵引力分量 f_x, f_y ∈ [-0.3, 0.3]，杨氏模量 E∈[5,20]，泊松比 ν∈[0.15,0.35]。
  - 输出：全场位移 u=(u_x, u_y)。
  - 数据：有限元参考解，4000训练集，1000验证集。
  - 评分指标：相对L2误差（rel-L2）。
  - 对比：启用审计的PA-SciML vs. 禁用审计的纯误差基线（error-only baseline）。两者均在同一搜索框架下执行，仅审核开关不同。
  - 附加分析：共同参考审计（post-run reference audit）、对敌搜索、孤立编辑比较。

- **场景2：瞬态弹性动力学（Transient Elastodynamics）**
  - 域：薄矩形 [−0.5,0.5]×[−0.1,0.1]，固定材料参数 (E=10, ν=0.25, ρ=1)，二阶三角形网格4681节点。
  - 输入：右边界运动历史（四通道：u̅_x, u̅_y 及对应速度），100个时间步。
  - 输出：全场瞬态位移场 u(x,t)。
  - 数据：有限元参考轨迹，500个验证历史。
  - 评分指标：全场全时域相对L2误差。
  - 对比：同样PA-SciML vs. 纯误差基线。
  - 附加分析：共同参考审计（其中因果性被设为硬合约）、对敌搜索、孤立编辑比较。

### 7. 优点

- **明确区分误差与物理可信度**：PA-SciML首次将机器可检查的物理合约作为代理模型选择的必要条件，报告格式清晰（验证/未验证标记）。
- **固定执行与LLM分离**：合约检查代码固定不变，避免LLM生成不可靠验证逻辑。
- **可追溯性强**：保存完整运行记录（包括合约文件、采样结果、对敌报告、孤立编辑份额），便于审计和复现。
- **对敌搜索增强证据**：无需参考解，直接在合法输入域内搜索高违规案例，提高了负例发现能力。
- **方法卡机制**：支持跨任务迁移的改进知识积累，通过孤立编辑验证后再保存。
- **实验设计客观**：两个问题域覆盖静态和瞬态，采用相同的固定评估器进行比较，避免了评分差异。

### 8. 不足与局限

- **单次运行**：所有实验仅使用一个随机种子，结果缺乏统计显著性检验，无法评估方法稳定性。
- **外部基准缺失**：仅与自身消融的纯误差基线对比，未与已有智能体系统（如AgenticSciML、ATHENA）进行直接性能或成本对比。
- **计算资源未量化**：无法评估PA-SciML相对于纯搜索的额外开销（LLM token消耗、训练次数等）。
- **搜索规模有限**：候选数量少（<30），可能无法充分探索架构空间；失效路径未深入分析。
- **物理合约设计依赖专家**：合约由LLM辅助设定，但最终仍需人工审查；容差选择可能影响结果（如瞬态案例中因果性在运行中被设为软合约，仅在事后审计中才成为硬合约）。
- **数据规模固定**：静态问题有足够数据（4000训练），但未测试数据稀缺或仅有方程残差监督的场景，此时物理检查的区分能力可能变化。
- **三维及非线性问题未覆盖**：方法学上可扩展，但未实验；线性检查无法直接迁移到非线性力学问题。
