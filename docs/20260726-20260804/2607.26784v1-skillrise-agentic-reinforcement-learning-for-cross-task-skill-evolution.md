## 摘要
大语言模型智能体常常遇到相关但不同的任务，这些任务共享可复用的解决方案模式。然而，标准的智能体强化学习将任务视为独立的片段，而现有的技能学习方法要么专注于对单一任务的重复尝试，要么使用多阶段流水线，将提取、检索和执行纠缠在一起。我们引入了SkillRise，一个用于跨任务学习技能的统一强化学习框架。SkillRise将相关实例组织为渐进难度递增的序列，并使用单一策略在任务解决和整理一份不断演化的技能文档之间交替，该文档直接传递给下一个任务。跨任务的解耦信用分配通过当前任务结果监督解决过程，并通过折扣后的下游结果监督整理过程。在ALFWorld、WebShop和ScienceWorld上的实验表明，SkillRise在所比较的方法中取得了最强的Pass@1性能，相比最强基线提升了2.3到8.5个百分点。尽管在不同任务上训练，其学到的整理策略在相同任务的重复尝试中仍然有效。进一步的分析揭示了跨任务的测试时扩展：即使每个任务只尝试一次，随着相关任务序列的延长，性能也会提升。这一趋势表明，SkillRise跨任务复用可迁移技能，而非受益于对同一任务的重复采样。SkillRise在显著降低多阶段技能学习流水线的运行时开销的同时，还保持了强劲的性能。综合来看，这些结果为LLM智能体跨任务提取、精炼和复用可迁移技能提供了一种简单且高效的训练范式。

## Abstract
Large language model agents often encounter related yet distinct tasks that share reusable solution patterns. Yet standard agentic reinforcement learning treats tasks as independent episodes, while existing approaches to skill learning either focus on repeated attempts of one task or use pipelines with multiple stages that entangle extraction, retrieval, and execution. We introduce SkillRise, a unified reinforcement learning framework for learning skills across tasks. SkillRise organizes related instances into progressively challenging sequences and uses a single policy to alternate between task solving and curating an evolving skill document passed directly to the next task. Decoupled credit assignment across tasks supervises solving with the current task outcome and curation with discounted downstream outcomes. Experiments on ALFWorld, WebShop, and ScienceWorld show that SkillRise achieves the strongest Pass@1 performance among the compared methods, with gains over the strongest baseline ranging from 2.3 to 8.5 percentage points. Although trained across distinct tasks, its learned curation policy remains effective for repeated attempts on the same task. Further analysis reveals scaling at test time across tasks: performance improves with longer sequences of related tasks even when each task is attempted only once. This trend suggests that SkillRise reuses transferable skills across tasks rather than benefiting from repeated sampling of the same task. SkillRise further retains strong performance while substantially reducing the runtime overhead of skill learning pipelines with multiple stages. Together, these results provide a simple and efficient training paradigm for LLM agents to extract, refine, and reuse transferable skills across tasks.

## 1. 论文的核心问题与整体含义

- **研究动机**：大语言模型（LLM）智能体在实际应用中常面临一系列**相关但互不相同**的任务，这些任务共享潜在的可复用解决方案模式。然而，标准的智能体强化学习（agentic RL）将每个任务视为独立片段，丢弃了交互中获得的经验，导致智能体反复从零开始探索。
- **现有方法的不足**：
  - 一类方法（如 Reflexion、LaMer）专注于对**同一任务**的重复尝试，从中总结轨迹；但学到的知识往往具有实例特异性，且需要额外交互，未直接优化跨任务迁移。
  - 另一类方法（如 RetroAgent、SkillRL）构建外部经验库或技能库，涉及多阶段流水线（提取、存储、检索、更新、执行），但下游性能由多个组件共同决定，难以归因技能本身的质量，且计算开销很大。
- **核心问题**：如何让智能体在解决任务的同时，从经验中提取**可迁移的技能**，并在后续相关任务中持续复用和精炼，从而不断提升跨任务表现？论文希望提出一个**简单、端到端**的跨任务技能学习框架，以统一的方式训练技能提取、策展与使用。

## 2. 论文提出的方法论

### 2.1 核心思想

- 将相关任务实例组织成**渐进难度递增的有序序列**（cross-task sequence），通过后续任务的表现来评估从前序任务中提取的技能是否可迁移。
- 使用**单一策略**在“任务求解”和“技能策展”两个角色间交替：求解时利用当前技能文档完成任务，策展时根据本次轨迹和结果更新文档，并将更新后的文档作为唯一信息通道传递给下一个任务。
- 采用**解耦的跨任务信用分配**：求解阶段仅由当前任务奖励监督，策展阶段由后续任务的折扣回报监督，并通过角色感知的分组相对优化（role-aware group-relative optimization）联合训练。

### 2.2 关键技术细节

1. **跨任务序列构建**：
   - 利用环境提供的家族元数据（如 ALFWorld 的六个任务家族、WebShop 的产品类别）对任务分组。
   - 在同一家族内**贪心选择多样实例**，并按任务属性（如所需属性数量、选项数）从简单到复杂排序。

2. **跨任务 rollout 与技能演化**：
   - 每个试验从空文档 S₀ = ∅ 开始。
   - 对第 i 个任务，策略用当前文档 S_{i-1} 生成求解轨迹 τ_i，获得奖励 r_i。
   - 对非最后一个任务，同一策略切换到策展模式，根据 S_{i-1}、τ_i、r_i 生成更新后的文档 S_i。
   - 只将 S_i 传给下一个任务，之前的轨迹不进入下一个求解上下文——S_i 是跨任务唯一的技能传递通道。

3. **解耦信用分配**：
   - 对第 n 次试验、第 i 个任务、阶段 z（solve 或 curate）：
     - 求解返回：G_{i,z}^(n) = r_i^(n)
     - 策展返回：G_{i,z}^(n) = Σ_{j=i+1}^{K} γ^{j-i} r_j^(n)，γ 为跨任务折扣因子（默认 0.6）。
   - 通过将求解和策展的返回分开，避免将序列级混合回报同时分配给两个角色，从而混淆任务求解质量与技能迁移质量。

4. **角色感知的分组相对优化（RAGRO）**：
   - 对同一序列、同一任务位置、同一阶段的 N 个试验计算组内相对优势：A = G - 均值(G)。
   - 分组同时考虑任务位置和阶段，确保求解和策展的回报不互为基线。
   - 使用 PPO 风格的裁剪目标，联合优化两个阶段的 token 级重要性比值。

## 3. 实验设计

### 3.1 数据集 / 基准

- **ALFWorld**：文本版具身家庭环境，报告六个任务家族（Pick、Look、Clean、Heat、Cool、Pick2）的成绩，使用 held-out 128 个实例。
- **WebShop**：电商购物环境，使用 1,000 商品版本，128 个 held-out 实例，报告成功率（SR）。
- **ScienceWorld**：科学推理交互环境，128 个 held-out 实例。

### 3.2 对比方法

- **Prompting 基线**：Zero-shot、ReAct、Reflexion。
- **任务无关 RL 算法**：PPO、RLOO、GRPO、GiGPO。
- **技能学习基线**：LaMer（同任务重复尝试的 Meta-RL）；以及流水线型方法 RetroAgent 和 SkillRL（用于管线效率对比）。
- 所有方法均使用 Qwen3-1.7B/4B 作为骨干模型。

### 3.3 训练设置

- SkillRise 每次训练批包含 16 个序列，每个序列 K=3 个任务，N=8 个独立试验；LaMer 也用 8 个试验、3 次尝试；任务无关 RL 基线每个任务用 24 个 rollout，保证所有可训练方法每更新处理相同数量的任务次数（384 次）。
- 学习率 1×10⁻⁶，mini-batch 128，最大响应长度 1024 token，最多训练 150 个更新。
- 评估时使用温度 0.7 的采样，报告 Pass@1、Pass@2、Pass@3。

## 6. 论文的主要结论与发现

- SkillRise 在三个基准上均取得最强 Pass@1 性能：ALFWorld 85.9%、WebShop 84.4%、ScienceWorld 54.6%，比最强基线 GiGPO 分别高 2.3、7.1、8.5 个百分点。
- 尽管训练时跨不同任务，学到的策展策略在**同一任务的重复尝试**（Pass@2/Pass@3）中也有效，优于专门训练重复尝试的 LaMer（尤其在 ScienceWorld 上高 14.2 个百分点）。
- 表现出**跨任务测试时缩放**：在 ALFWorld 上，将相同 128 个任务划分为更长序列（K=2→6）时，SkillRise 性能单调提升（83.6%→87.5%），而 LaMer、GiGPO、GRPO 无持续提升。由于每个任务只尝试一次，证明增益来自技能迁移而非重复采样。
- 模型规模增大时（1.7B→4B），SkillRise 收益更大（+7.8 个百分点），说明更大容量对“求解+跨任务抽象”联合学习有利。
- 消融表明：对折扣因子 γ 不敏感（收敛差异约 1 个百分点内）；移除策展后性能显著下降，说明仅用相关任务序列训练不足，显式的技能文档演化至关重要。
- 相比多阶段流水线，SkillRise 以 1/6 到 1/4 的运行时间达到相同或更好性能，证明简洁端到端设计的优势。

## 7. 优点

- **统一端到端框架**：将技能提取、精炼与复用整合到一个策略中，避免了复杂的多阶段管理流水线，减少了组件耦合和归因困难。
- **新颖的解耦信用分配**：根据求解与策展的时间角色分配不同监督信号，使策略能同时优化任务执行技能和跨任务抽象能力，且不互相干扰。
- **角色感知分组**：按任务位置和阶段分组计算优势，避免求解和策展收益互作基线，提高了训练稳定性。
- **效率高**：在保持最强性能的同时，大幅降低训练开销（仅为多阶段流水线的 1/6~1/4 运行时间）。
- **测试时缩放特性**：验证了跨任务技能并非静态记忆，而是随序列长度动态积累，支持连续的自我提升。
- **消融与案例分析严谨**：包括折扣因子敏感性、无策展变体、模型规模、测试时缩放及定性案例，增强了结论的可信度。

## 8. 不足与局限

- **依赖任务家族元数据**：当前方法需要知道任务属于哪个家族才能构建序列；在开放任务流中自动发现任务关系仍待解决。
- **模型规模有限**：仅评估了最多 4B 参数的模型，更大规模（如 70B+）下的有效性未验证。
- **基准范围较窄**：仅覆盖三个文本交互环境，缺少多模态、真实世界或弱监督场景的评估；所有任务都有可验证的二元奖励，不适用于奖励难以自动判定的场景。
- **未报告方差与显著性**：没有多次种子运行的标准差或统计检验，样本量（128 个 held-out 实例）相对有限，可能影响结论稳定性。
- **对比方法复现不等价**：RetroAgent 和 SkillRL 使用 Gemini-2.5-Pro 作为教师模型，而 SkillRise 为自训练，这种配置差异可能使效果对比不够严格。
- **策展角色的奖励延迟**：尽管采用折扣下游回报，但当序列较短（K=3）或折扣较小时，策展信号可能不够充分；对更长序列的效果尚待验证。
- **未分析技能文档内容质量**：除了定性示例，没有对技能文档的结构、可读性或冗余度进行量化评估，无法明确技能迁移增益的具体来源。
