## 摘要
基于提示的强化学习通过在每个回滚前保留专家轨迹的前缀，使策略能够从更接近成功的状态开始探索，从而解决长时程智能体任务中的奖励稀疏问题。其有效性取决于引导深度：即保留轨迹的多少。现有方法将该深度视为确定性标量。调度方法在样本间共享单一值，忽略任务异质性；逐样本探测则单独估计深度，但以额外回滚为代价。我们发现，有用的引导占据一个深度带，其信息量分布大致呈以带中心为中心的高斯形状，而非集中在单一最优点上。我们提出Agent-G$^2$，一种高斯引导框架，从已为策略优化收集的回滚中在线估计每任务深度，服从高斯分布，其中心和宽度在线估计，无需探测回滚或学习深度预测器。中心结合全局基线与每簇难度，宽度追踪簇内方差。我们在ALFWorld和WebShop上对Qwen2.5-1.5B/7B-Instruct评估了Agent-G$^2$。Agent-G$^2$在ALFWorld上以低于逐样本探测三分之一的回滚成本，比最强的基于提示、无提示和Aux-RL基线分别高出2.3/3.9/7.4分。

## Abstract
Hint-based reinforcement learning addresses reward sparsity in long-horizon agentic tasks by retaining a prefix of an expert trajectory before each rollout, letting the policy explore from a state closer to success. Its effectiveness hinges on the guidance depth: how much of the trajectory to keep. Existing methods treat this depth as a deterministic scalar. Scheduled approaches share one value across samples and ignore per-task heterogeneity; per-sample probing estimates it separately at the cost of extra rollouts. We find that useful guidance occupies a band of depths whose informativeness profile is approximately Gaussian around the band center, rather than concentrating at a single optimal point. We propose Agent-G$^2$, a Gaussian guidance framework that draws the depth per task from a Gaussian whose center and spread are estimated online from rollouts already collected for policy optimization, requiring no probe rollouts or learned depth predictor. The center combines a global baseline with per-cluster difficulty, and the spread tracks within-cluster variance. We evaluate Agent-G$^2$ on ALFWorld and WebShop on Qwen2.5-1.5B / 7B-Instruct. Agent-G$^2$ outperforms the strongest hint-based, hint-free, and Aux-RL baselines on ALFWorld by 2.3 / 3.9 / 7.4 points at under one-third the rollout cost of per-sample probing.

# 论文总结：Agent-G²: Gaussian Guidance for Agentic Reinforcement Learning

## 1. 核心问题与整体含义（研究动机与背景）

**研究背景**：大语言模型（LLM）智能体通过强化学习（RL）训练，在长时程决策任务（如网页导航、具身控制、科学实验）上取得了显著进展，但面临一个核心障碍——**奖励稀疏**（reward sparsity）问题。任务跨度数十步决策，但只在终止时发出二元奖励信号，策略从初始状态探索时很难达到成功终止状态。

**已有解决方案及其不足**：提示强化学习（Hint-based RL）通过在每个 rollout 前保留专家轨迹的前缀，使策略从更接近成功的状态开始探索，直接缓解了 GRPO 训练中的优势崩溃问题。其关键在于**引导深度**（guidance depth）——保留多少专家轨迹。现有方法存在两类问题：

- **调度方法（Schedule-based）**：从训练步或批次反馈中推导单一深度，在所有样本间共享，忽略任务异质性（如同一批次中两步的"Pick"任务与二十步的"Pick Two"任务难度差异巨大）。
- **每样本探测（Per-sample probing）**：通过二分搜索或枚举为每个样本独立估计深度，但代价是每个样本额外消耗 O(log n) 乃至 N 倍的 rollout 预算。

**核心洞察**：论文通过诊断实验发现，有用的引导深度并非集中于单一最优点，而是**形成一条带状区域（band）**，其信息量分布（以伯努利方差为代理）围绕带中心呈**近似高斯分布**（σ=0.22, R²=0.92）。这一发现推翻了现有方法共同依赖的"每任务存在单一最优深度"的假设，指明正确的引导深度是一个需要覆盖的邻域而非需要寻找的点。

**整体含义**：Agent-G² 将引导深度建模为逐任务的高斯分布，其均值和方差从已收集的 rollout 中在线估计，无需额外探测 rollout，从而以零额外代价实现任务感知的自适应深度选择。

## 2. 方法论

### 2.1 核心思想

Agent-G² 的核心理念是：**引导深度不是一个需要精确定位的点，而是一个需要覆盖的邻域**。通过全局-局部分解（global-local decomposition）构建逐任务高斯分布：

- **中心（μ）**：全局基线反映策略整体进展，簇级统计量根据任务难度对中心进行校正。
- **宽度（σ）**：跟踪簇内方差，为采样器提供对信息带的覆盖。

### 2.2 关键技术细节

**问题设定**：每个任务 i 有自然语言指令 qᵢ 和一条长度为 Lᵢ 的专家轨迹 τ\*ᵢ。调度器选择引导比例 rᵢ∈[0,1]，转换为前缀长度 nᵢ = min(⌈rᵢLᵢ⌉, Lᵢ−1)。在执行前 nᵢ 个专家动作后，策略 π_θ 从后续状态运行 R 条独立 rollout，每条以二元奖励终止。

**(1) 全局基线**：维护 μ_global 跟踪策略当前所需引导水平。根据批次平均成功率 acc_B 与目标 p_target=0.5 的差距进行步长为 Δ 的更新：

```
μ_global ← clip(μ_global + sign(p_target − acc_B)·Δ, 0, 1)
```

**(2) 簇统计量**：训练集按专家轨迹长度离线划分为 K 个难度簇。对批次中的每个非空簇 C_k，计算簇内平均成功率 p̄_Bk 和方差 v_Bk，通过 EMA 更新：

```
A_k ← (1−α)A_k + α·p̄_Bk
V_k ← (1−α)V_k + α·v_Bk
```

**(3) 逐任务分布**：任务 i（属于簇 k）的高斯参数为：

```
μ_i = clip(μ_global + λ(p_target − A_k), 0, 1)
σ_i = max(γ·V_k, σ_min)
```

- 簇成功率 A_k 低 → μ_i 向更深引导偏移；
- 簇内方差 V_k 高 → σ_i 加宽，增加对信息带的覆盖。

**(4) 采样与 rollout**：每任务从 N(μ_i, σ_i²) 抽取一个引导比例 rᵢ，转换为前缀长度并执行，所有 R 条 rollout 共享前缀执行状态。

**(5) 联合训练目标**：

```
L(B) = L_GRPO(B) + η·L_aux(B)
```

其中 L_aux 是对采样前缀的教师强制交叉熵损失（前缀 SFT），L_GRPO 是组相对策略优化损失。

**(6) 闭环更新**：同一批 rollout 同时驱动策略更新和调度参数更新（μ_global, A_k, V_k），**零额外探测成本**。

## 6. 主要结论与发现

1. **引导深度的带状结构**：有用引导深度构成一条带，信息量分布近似高斯（σ=0.22, R²=0.92），而非单一最优深度。共享深度调度方法将超过 60% 的分配置于信息带之外，每样本探测在 GRPO 匹配预算下仍留有大量错配。

2. **Agent-G² 的综合优势**：
   - **ALFWorld**：1.5B 达 95.3%，7B 达 98.4%——超过最强提示基线 1.5/2.3 点、最强无提示 RL 基线 3.9 点、最强 Aux-RL 基线 7.4/6.6 点、最强探测基线 9.3/2.3 点；
   - **WebShop**：两规模均达 92.3 奖励分；购买成功率 78.9%/84.4%；
   - **训练效率**：约以一半梯度步数达到调度基线最终精度；每步成本 88 秒 vs 探测法 285–425 秒（仅为其 1/3.24–1/4.83）；
   - **跨规模稳健**：1.5B 模型超越所有 7B 非探测基线，表明调度设计可替代骨干扩展。

3. **可迁移性与涌现行为**：
   - Agent-G² 的增益不能用模仿学习解释：Sampled-Prefix SFT 仅 26.6%，Full SFT 仅 56.3%，而 Agent-G² 达 95.3%——关键贡献来自 post-prefix 状态上的 GRPO 学习；
   - 调度分布由训练自身涌现：早期深引导（策略弱）、中期簇分离且峰宽变阔（簇方差 V_k 峰值）、后期收敛至浅引导；
   - 全局基线与簇统计量的分离是必要的：移除簇中心校正降 3.9 点，移除自适应宽度降 1.5 点（Long 任务降 16.4 点），合并为单簇降 6.2 点。

4. **消融关键结论**：
   - 采样比确定性均值重要：w/o sampling 降 5.5 点；
   - 高斯形状比均匀分布略优：方差匹配的均匀分布降 7.0 点；
   - 辅助损失是稳定器而非主导：w/o L_aux 降 8.6 点，w/o L_GRPO 降 68.7 点。

## 7. 优点

1. **洞察新颖且具有解释力**：揭示引导深度的"带状结构"与"高斯型信息量分布"，从根本上解释了现有方法的系统性失效原因，而非简单修补。

2. **零额外 rollout 成本的自适应机制**：巧妙利用策略优化已有的 rollout 统计数据（成功率均值与方差）在线更新调度参数，将调度更新与策略优化闭环融合，无需探测 rollout、附加网络或学习的深度预测器。

3. **全局-局部分解的简洁设计**：全局基线（对策略整体进展）与簇级统计量（对任务难度）的组合，在单一公式中实现了任务异质性的自适应处理，且每个参数都有明确的直觉对应。

4. **实验设计严谨**：所有基线共享同一骨干，隔离变量；5 种子平均；跨模型规模验证；多角度消融系统全面；聚类设计有专门消融；训练成本有量化对比。

5. **调度替代模型扩展的启示**：1.5B Agent-G² 超越 7B BEACON 等基线，展示了智能调度策略在计算效率上的经济价值。

6. **全面的诊断分析**：本文的初步诊断部分（共享深度失配、探测代价-精度权衡、高斯拟合跨训练窗口验证）本身即为有价值的实证贡献。

   - 任务类型单一（均为家用任务/购物），缺乏数学推理等更结构化任务的验证；
   - 两种基准的奖励结构相似（终止时二元信号），可能限制结论的泛化性。

3. **高斯参数化的适用性边界**：高斯分布拟合基于经验观测，在深度信息量分布呈多模态或严重偏斜的任务上可能不充分。作者承认精确形状不如对信息带的随机覆盖重要（均匀分布消融仅降 7.0 点），但完全非参数化或更丰富分布族的方案未探索。

4. **静态聚类无法适应策略改进**：难度簇按专家轨迹长度离线划分，不随策略改进和任务相对难度变化而自适应调整；作者承认在线难度估计是未来改进方向。且当长度与难度解耦时（文中未覆盖），此代理指标可能失效。

5. **算力报告不完整**：未披露 7B 模型训练时长、完整实验总算力消耗、以及 5 种子平均的具体方差（仅 ALFWorld/1.5B 聚类消融给了标准差）。

6. **诊断实验的计算代价与规模限制**：初步诊断在单个检查点（step 50）和一个数据集上进行细致分析（跨训练窗口的高斯拟合虽提供补充，但窗口粗粒度），且每任务每深度 32 条 rollout 的枚举式评估本身计算昂贵，限制了可诊断的任务规模。

7. **工程实现上的特定依赖**：方法涉及多个 EMA 超参数（Δ, α, λ, γ, σ_min, η），虽然固定跨基准使用，但最优值的选择对方法性能的影响程度未作敏感性分析。
