## 摘要
我们开发了两种参数化数据驱动降阶模型：物理信息神经网络（PINN）和非侵入式张量降阶模型（TROM），并将这两种方法应用于参数化的一维浅水溃坝问题。两种降阶模型均不需要时间积分，而是直接从空间、时间和溃坝参数学习到物理状态的映射。我们针对样本外参数值和外推参数值进行了详细比较。此外，我们证明了引入激波感知配点对于提高PINN模型的鲁棒性至关重要。

## Abstract
We develop two parametric data-driven reduced models: a physics-informed neural network (PINN) and a non-intrusive tensorial reduced-order model (TROM), and apply both approaches to the parametrized one-dimensional shallow-water dam-break problem. Both reduced models do not require time integration and learn a direct solution map from space, time, and dam-break parameters to the physical state. We present a detailed comparison for out-of-sample and extrapolated parameter values. In addition, we demonstrate that it is essential to introduce shock-aware collocation to improve the robustness of the PINN model.

- **研究背景**：浅水方程（Shallow-Water Equations, SWEs）是一类典型的双曲型平衡律，广泛用于描述自由表面流动。一维溃坝问题是其经典基准算例，尽管形式简单，但解常包含非线性波相互作用、移动波前以及激波等强间断结构，给经典数值方法和代理模型带来挑战。在不确定性量化、实时预报、设计与控制等实际问题中，需要快速且可靠地预测不同参数下的流场状态，因此发展能够处理输运与激波的高效降阶模型具有重要意义。
- **现有方法的局限**：
  - 传统的基于投影的降阶模型（ROM，如POD）在处理含激波的输运主导问题时，解流形的 Kolmogorov n-宽度衰减缓慢，导致线性子空间压缩效率低，并在间断附近丧失保真度。
  - 已有的PINN用于SWEs的研究大多针对固定PDE实例或单一前向场景，不能直接学习覆盖一族溃坝初始条件的参数化代理模型，参数泛化问题尚未被充分解决。
- **核心问题**：本文要解决的核心问题是：如何构建并比较两种参数化降阶模型（PINN 与 TROM），使其无需时间积分即可从空间、时间和参数直接预测状态，并在一维浅水溃坝问题中保持精度与鲁棒性，尤其是面对移动激波和参数外推时。
- **整体含义**：通过系统对比两种范式，揭示各自在不同流态（干床、湿床、近干床）和参数插值/外推下的优势与不足，并证明激波感知配点对PINN的关键作用，为含间断双曲问题的参数化降阶建模提供可选方案与设计指导。

### 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

- **问题设置**：
  - 控制方程为一维浅水方程的守恒形式：∂ₜU + ∂ₓF(U) = 0，其中 U = (h, q)ᵀ，h 为水深，q = hu 为流量（动量），F 为通量函数。
  - 参数化初始条件：μ = (h_L, h_R)，表示坝址 x_dam = L/2 处上下游初始水深，h_L > h_R ≥ 0；h_R = 0 为干床，h_R > 0 为湿床（含下游激波）。
  - 学习目标：近似参数到解映射 S: (x, t, μ) → U_FOM(x, t; μ)。

- **方法一：参数化物理信息神经网络（PINN）**：
  - 网络输入为 (x, t, h̄, γ)，其中 h̄ = (h_L + h_R)/2，γ = (h_L − h_R)/(h_L + h_R + ε)，ε 为正则化小量；输出为 (h_θ, u_θ)，流量由 q_θ = h_θ u_θ 诱导得到。
  - 网络结构：全连接前馈网络，5个隐层，每层宽度120，激活函数为 SiLU，输出维度2；总计58,922个可训练参数，Xavier正态初始化。
  - 损失函数为加权和：
    L = λ_data L_data + λ_pde L_pde + λ_bc L_bc + λ_ic L_ic + λ_nn L_nn，
    包含数据损失、PDE残差损失、边界条件（零梯度）损失、初始条件损失、非负性惩罚。
  - 关键技术细节：
    - **激波感知配点（Shock-aware collocation）**：从FOM数据估计激波位置 x_sh(t; μ)，设定排除带 B_excl = {x : |x − x_sh(t;μ)| < w_excl}，PDE残差配点从 Ω \ B_excl 均匀采样；对干床（h_R < ε_dry）则禁用排除。
    - **残差缩放（Residual scaling）**：对两个PDE残差分量使用 EMA-RMS 尺度归一化，稳定早期训练。
    - **PDE门控（PDE gating）**：根据预测深度梯度和水深值对每个配点赋予权重 w_j，在陡峭梯度和近干区域弱化强形式残差约束。
    - **损失类型**：数据/初始条件使用 L1；PDE残差/边界条件使用 L2 或 Charbonnier 惩罚。
    - **训练策略**：Adam优化器，学习率10⁻³，余弦退火，梯度裁剪，前1/4训练阶段对物理项权重进行 warm-up 线性提升。
  - 公式化流程：构建输入特征 → 网络前向输出 (h,u) → 自动微分计算残差 → 加权损失 → 反向传播更新参数。

- **方法二：非侵入式张量降阶模型（TROM）**：
  - 核心思想：利用高阶张量（HOSVD）对参数化快照数据进行低秩压缩，然后通过参数插值直接重建新参数的解，无需时间积分。
  - 将每个物理量（h, u）的快照组织成四阶张量 Q ∈ R^{N_x × N_L × N_R × N_T}，模式分别为空间、h_L、h_R、时间。
  - 采用 Tucker 分解：Q ≈ G ×₁ V_x ×₂ V_L ×₃ V_R ×₄ V_T，其中 G 为核心张量，V 为因子矩阵。
  - 多线性秩通过各模式奇异值能量阈值（ϵ=10⁻³）自动选取，得到 (Ñ_x, Ñ_L, Ñ_R, Ñ_T) = (94, 4, 5, 21)。
  - 对新参数 μ*：用三次样条在参数网格上插值得到插值系数，通过模式收缩得到低维矩阵，再重建出 N_x × N_T 的解矩阵。

### 6. 论文的主要结论与发现

- 在参数插值（样本内/样本外）任务中，TROM 和 PINN 均能高精度预测水深和流量，误差主要集中在移动激波附近。
- 流态依赖性强：TROM 在干床情形下更精确；PINN 在湿床情形（h_R 较大）下更优；两者在近干床 μ=(26,0.14) 均表现最差。
- PINN 能较好缓解谱偏差，在多数情况下准确重建谱信息；近干床高频成分仍难捕捉。
- 外推实验中，PINN 在所有外推案例中均优于 TROM，特别是在 h_L > 28 时 TROM 在激波附近产生伪凸起，而 PINN 保持较好精度。
- 激波感知配点对PINN至关重要：去掉后聚合误差从2.494×10⁻² 升至7.839×10⁻²（超过三倍），流量误差更敏感。其次是PDE门控和残差缩放；去掉PDE损失本身影响相对较小。说明对激波主导问题，“在哪里”和“如何”施加残差比“是否”施加更重要。
- 在线评估时两种模型均比FOM快两到三个数量级（约500–700倍），且推理成本不依赖于查询时间。
- 两种模型在激波出计算域时（如 μ=(26,0.14), t=2.5）在右边界附近出现失真，但远离边界处仍准确。
- 整体上 TROM 与 PINN 应视为互补工具：TROM 适合结构化参数网格和快速离线构建，PINN 更适合非均匀采样数据、参数外推和灵活性需求；选择取决于数据形式、参数域结构和应用目标。

### 7. 优点

- 首次系统对比了参数化PINN和非侵入式TROM在含激波浅水溃坝问题上的性能，填补了参数泛化场景的比较空白。
- 两种模型均无需时间积分即可预测任意时刻的解，在线加速比显著，具有实际应用价值。
- PINN设计遵循物理结构，使用守恒形式残差而非原始变量，配合激波感知配点、残差缩放和门控，有效提升对间断问题的鲁棒性。
- 消融实验设计规范，单因子控制变量并采用蒙特卡洛平均，结论清晰可复现。
- 评估维度丰富：包括相对L2误差、谱分析、激波定位、插值/外推、运行时间等，全面刻画模型行为。
- 对近干床极限的参数奇异行为给出解释（h_R→0时解对参数的非光滑依赖），有助于理解模型失效原因。

### 8. 不足与局限

- 实验仅覆盖一维问题，未扩展到二维或三维；作者虽提及扩展方向，但未提供实例。
- PINN训练成本高（20小时CPU训练），且超参数众多，实际应用门槛高；不同硬件/随机种子下的稳定性未深入讨论。
- TROM要求矩形张量积参数网格，无法直接处理非规则采样或局部加密；添加单个新参数需要重新生成完整张量，扩展性受限。
- 外推实验的参数点数量有限，且主要集中在 h_L 方向，对 h_R 外推（如 h_R > 8）覆盖不充分。
- 激波位置的估计依赖FOM参考数据，在实际部署中若无法获得FOM快照，该方法不适用；配点排除带的宽度、阈值等参数需要人工调节。
- 两种模型在近干床和激波出域边界附近误差显著增大，该关键场景未提出有效的补救方案（仅建议混合FOM初始化）。
- 未给出多次独立训练的标准差，无法评估PINN训练随机性导致的性能波动。
- 在线速度对比仅给出大致倍数（500–700倍），缺少对硬件和实现细节的精确基准。
