## 摘要
本文研究物理信息神经网络用于建模下垂控制构网型变流器的完整动态行为。该方法使用数值求解器生成的合成数据进行训练，并与传统积分方法和普通神经网络进行对比测试。结果表明，在相同训练数据下，该方法的预测精度高于普通网络，且运行时间相比数值求解器大幅减少。

## Abstract
This paper investigates physics-informed neural networks for modeling the full dynamic behavior of droop-controlled grid-forming converters. The approach is trained on synthetic data generated via numerical solvers and benchmarked against both traditional integration methods and a vanilla neural network. Results show higher predictive accuracy than the vanilla network using the same training data and substantially reduced runtime compared with numerical solvers.

- **核心问题**：随着可再生能源渗透率提高，逆变器基资源（IBR）引入快速非线性动态，传统电磁暂态（EMT）仿真依赖数值求解器（如Runge-Kutta），在大规模系统中计算成本高、速度慢；而纯数据驱动的机器学习模型（如普通神经网络VNN）需要大量标注数据且预测可能违背物理规律。
- **整体含义**：本文旨在探索物理信息神经网络（PINN）是否能够高效且精确地建模构网型变流器（GFM）的完整动态行为，以平衡计算效率与物理一致性，为实时动态稳定性评估（DSA）提供可行替代方案。
- **背景**：现有研究仅将PINN应用于同步发电机或部分电网跟随型变流器（GFL）状态，尚无工作成功建模完整GFM状态动态。

## 2. 论文提出的方法论

### 核心思想
- 将构网型变流器的物理动态方程（ODE）嵌入神经网络的损失函数中，使训练过程既利用少量标注数据，又通过物理约束（如导数匹配、初始条件）确保预测的物理合理性，减少对大量标注数据的依赖并提升泛化能力。

### 关键技术细节
1. **动态建模对象**：采用下垂控制的GFM，包含电气部分、下垂控制、内环电压控制和内环电流控制，系统状态向量共13个变量（如滤波器电压、电流、辅助积分变量等），输入为有功/无功参考、电压/频率参考。
2. **PINN架构**：4层隐藏层，每层128个神经元，激活函数为tanh；输入为时间t、初始状态x0、输入u；输出为预测状态x̂(t)。
3. **损失函数设计**（公式20）：
   - 标准神经网络损失（NNL）：预测值与真值均方误差。
   - 物理数据损失（PDL）：预测导数与基于真值计算的ODE导数之差。
   - 初始条件损失（ICL）：预测在t=0时刻与给定初值的误差。
   - 物理配点损失（PCL）：在任意配点处，预测导数与基于预测值计算的ODE导数之差。
   - 各损失项通过权重λ调整（λ_NNL=1, λ_PDL=1e-5, λ_ICL=0.1, λ_PCL=1e-5）。
4. **训练流程**：
   - 使用RK45求解器生成500条训练标签轨迹（含1200个时间点），以及16000个初始条件用于配点采样。
