## 摘要
当偏微分方程输入在数千个强相关传感器上被观测但仅有少量算子样本可用时，深度算子网络可能变得统计上不稳定。我们提出了FAST-DeepONet，一种结合固定谱路径与正交残差正则化投影的分支表示，其中方向惩罚作用于每一行归一化后的有效残差映射。在Navier-Stokes流上，当分支从129个坐标增长到8193个坐标时，普通DeepONet的平均相对L2误差从0.0394恶化到0.1556，而FAST-DeepONet保持在0.04附近，因此传感器网格可以在不产生统计惩罚的情况下进行细化。在Navier-Stokes流、Darcy流和终端波场预测的独立测试集上，它分别将平均相对L2误差降低了4.7%至37.0%，同时可训练参数减少了三到七倍。共享同一基底的仅谱分支将两条路径分开：固定谱路径在Navier-Stokes和Darcy上带来了改进，而终端波预测则需要残差路径及其方向惩罚。FAST-DeepONet针对坐标查询架构，并仅基于解值进行训练。

## Abstract
Deep operator networks can become statistically unstable when partial differential equation inputs are observed at thousands of strongly correlated sensors but only a small number of operator samples is available. We introduce FAST-DeepONet, a branch representation combining a fixed spectral path with a regularized projection of the orthogonal residual, in which the directional penalty acts on the effective residual map after each of its rows is normalized. On Navier--Stokes flow a plain DeepONet degrades from $0.0394$ to $0.1556$ mean relative $L_2$ error as the branch grows from $129$ to $8193$ coordinates, while FAST-DeepONet stays near $0.04$, so the sensor grid can be refined without a statistical penalty. Across independent test sets for Navier--Stokes flow, Darcy flow, and signed terminal wavefield prediction it lowers mean relative $L_2$ error by $4.7\%$ to $37.0\%$ with three to seven times fewer trainable parameters. A spectral-only branch sharing the same basis separates the two paths: the fixed spectral path carries the improvement on Navier--Stokes and Darcy, while terminal wave prediction requires the residual path together with its directional penalty. FAST-DeepONet targets coordinate-query architectures and trains on solution values alone.

## 1. 论文的核心问题与整体含义

- **研究背景**：参数化偏微分方程（PDE）在气候模拟、地下流、能源系统和工程设计中广泛出现，算子学习旨在用神经网络替代重复数值求解。DeepONet 通过分支网络（branch）编码输入函数、主干网络（trunk）编码输出坐标来逼近解算子。
- **核心问题**：当 PDE 输入在高维空间被观测（如数千个强相关传感器，p≈4096–8193），但可用的独立算子样本很少（仅 40–60 个）时，普通 DeepONet 的分支网络面临“维度灾难”：第一个全连接层需要在高维小样本下估计，统计上极不稳定。普通 DeepONet 在分支维度从 129 增长到 8193 时，平均相对 L₂ 误差从 0.0394 恶化到 0.1556。
- **整体含义与意义**：该工作希望在不改变 DeepONet 主干网络和输出构造的前提下，仅通过改进分支输入表示来稳定高维小样本下的算子学习，使传感器网格可以自由细化而不引入统计惩罚。同时，方法只依赖解值（solution values）监督，不依赖导数信息，适用面比 derivative-informed 方法更广。

## 2. 方法论：FAST-DeepONet

**（1）核心思想：双路径分解**

受 FAST-NN（Fan and Gu, 2024）的 factor-augmented sparse-through neural network 启发，FAST-DeepONet 将高维分支输入分解为：

- **固定谱路径（spectral path）**：用训练输入场的 SVD 右奇异向量作为谱基，提取低维全局特征；
- **可训练残差路径（residual path）**：将输入投影到谱基的正交补空间，用可训练矩阵将其压缩成少量特征；
- 两条路径的特征拼接后送入分支 MLP。

**（2）关键技术细节**

- **谱分解**：对训练场矩阵 X_f ∈ R^{n×p_f} 做不中心化的 thin SVD，取前 r_f 个右奇异向量组成 Q_f ∈ R^{p_f×r_f}。谱特征为 f̂_f = c_f Q_fᵀ x_f / √p_f，其中 c_f 是固定尺度。
- **数值秩保护**：定义数值秩 r_num = #{i: σ_i > 10⁻⁶σ₁}，并设置有效秩 r_eff = max(1, min(r_f, r_num))，防止请求超过数据支撑的秩。
- **残差计算**：e_f(x_f) = x_f − Q_f(Q_fᵀx_f)，即无关尺度的正交投影残差；辅助物理参数（如粘度）直接进入固定表示，不参与残差路径。
- **有效残差映射与方向惩罚**：令 G = H_z ΘP_res ∈ R^{w×p} 为残差贡献到第一隐层 preactivation 的有效映射。对 G 的每一行做精确归一化 G̃ᵢ = Gᵢ/‖Gᵢ‖₂（零行保持为零），定义方向裁剪惩罚 Ω(G;τ) = (1/wp) ΣᵢΣⱼ min(|G̃ᵢⱼ|/τ, 1)。该惩罚对残差特征空间的可逆坐标变换不变，也对第一层 ReLU 单元的正缩放不变——这解决了直接惩罚 Θ 时因参数化歧义（(Θ + A)P_res = ΘP_res）导致的尺度依赖问题。
- **训练目标**：MSE 损失 + λΩ(G;τ_k)，裁剪阈值 τ_k 从 0.1 线性退火到 0.01。
- **整体架构**：FAST 将 4096–8193 个传感器值压缩为至多 32 个特征（r_eff + s），第一层参数量大幅减少。

## 6. 论文的主要结论与发现

1. **误差降低**：在三个基准的独立测试集上，FAST-DeepONet 将普通 DeepONet 的平均相对 L₂ 误差降低 4.7%（波）到 37.0%（NS）；Diff 的置信区间在三个基准上都排除零。
2. **维度稳定性**：当分支维度从 129 增至 8193 时，Plain 误差从 0.0394 恶化到 0.1556，而 FAST 保持在 0.04 附近——传感器网格细化不引入统计惩罚。
3. **参数效率**：可训练参数减少 3.7–6.8 倍，且参数量减少不是收益来源（参数匹配的窄 Plain 分支更差）。
4. **双路径贡献分离**：
   - 固定谱路径在 NS 和 Darcy 上几乎承担了全部改进（光谱-only 已达到 0.1108/0.0876）；
   - 终端波预测必须依赖残差路径 + 方向惩罚（光谱-only 是净损失 18.1%，完整 FAST 反而比 Plain 低 4.7%）。
5. **方向惩罚的必要性**：λ=0 时残差路径在波上无增益、在 Darcy 上反而有害；惩罚将 Darcy 误差降低 33.2%、波降低 19.8%。惩罚是残差路径“有用”的前提，而非细化。
6. **因子尺度敏感性**：波场在小保留秩（6）下对 c_f 高度敏感（c_f=1 时比 Plain 更差，c_f=8 时最优），Darcy 在大保留秩（16）下几乎不敏感。
7. **两种表示都无法弥补极端样本稀缺**（n=20 时两者误差都在 0.2 附近）。
8. **不确定性量化**：dropout + 共形校准下 FAST 的 MC 点误差在三个基准上均更低，但 NS 上 FAST 的 5 个种子都被 flag（覆盖不足）。

- **问题定位精准**：抓住 DeepONet 在高维小样本下的真实统计不稳定问题，且明确指出与已有方法（POD-DeepONet、PCA-Net、NOMAD、DE-DeepONet）的区别——不改变输出构造、不需要导数监督。

**（4）建模与适用边界**（接续）
- FAST 的谱路径本质上是线性降维，若输入场具有强烈的非线性流形结构，谱基可能无法充分捕获其变化；残差路径虽可补偿，但在样本极少时其容量有限。
- 方法以输入场在传感器网格上的函数值观测为前提，未涉及多尺度输入、多物理场耦合或由粗到细的多分辨率输入等更一般的算子学习设定。
- 分支输入维度一旦极高（如 p>10⁴）且样本量极小时，谱分解本身的稳定性也可能受限，论文未讨论该边界。

**（5）训练目标与损失函数**
- 仅使用 MSE 监督，未尝试感知损失、物理约束损失或对抗训练等，可能限制了在复杂高频输出上的表现。
- 方向惩罚退火策略（τ 从 0.1 到 0.01）的选择依据未给出充分敏感性分析。

**（6）不确定性量化仅作初步探索**
- MC dropout + 共形校准的实验显示 NS 上 FAST 全部 5 个种子被 flag（覆盖不足），说明其提供的不确定性质量并不健全；该部分深度不足，未能揭示为何高维小样本下覆盖失败。

**（7）可复现性的潜在障碍**
- 虽公开代码和数据，但未提供完整的随机种子清单、数据生成脚本的运行环境依赖、预训练权重文件或容器镜像，复现完整训练管道仍有一定门槛。

## 11. 未来工作与开放性

- **自适应秩选择**：当前 r_f 由 SVD 方差阈值和调优集决定，未来可探索在线或数据自适应秩选取，以减轻调参负担。
- **更灵活的传感器配置**：扩展到变传感器布局、随机子采样、传感器缺失下的输入表示，增强实际可用性。
- **非线性降维路径**：用可训练的编码器（如卷积、注意力）替代固定谱基，但需与小样本稳定性权衡。
- **结合物理信息**：将 PDE 残差或边界条件作为弱监督加入损失，可能进一步提升小样本下的稳定性和外推能力。
- **更稳健的不确定性量化**：针对高维小样本设计专用校准方法，修复 NS 上的覆盖不足问题。
- **理论分析**：为双路径降维 + 方向正则化提供泛化误差界，解释“谱路径何时足够、何时需要残差路径”的统计机制。
- **更大规模基准**：在真实地下流、气候或医学影像等工程数据上评估，检验方法在非合成分布下的实用性。

## 12. 总评与建议

本文是一篇高质量、方法创新与实验严谨兼备的算子学习论文。它将“高维传感器输入 + 极小样本”这一真实痛点明确摆在 DeepONet 面前，并给出了一种既简单又理论自洽的修复方案：通过谱路径稳定全局低秩结构，通过残差路径捕获基外信息，通过方向惩罚保证可训练部分在小样本下的行为不失控。整个论证链条完整，从问题诊断、方法设计、消融拆解到统计验证层层递进，在同类工作中属于方法论与实验规范的上乘之作。

主要遗憾在于三点：一是算力与资源细节缺失，妨碍直接的成本判断；二是波场基准上的收益有限且对训练预算与超参数敏感，说明方法的普适性仍有限；三是不确定性量化部分浅尝辄止，甚至暴露了 FAST 在 NS 上覆盖不足的问题，值得更深入讨论。

建议读者重点关注其双路径分解与方向正则化的思想，可将其视为“高维小样本算子学习”的一个新起点；但在实际应用中，需要自行评估 c_f、r、s 等超参数的敏感性，并针对自身 PDE 分布重做消融。
