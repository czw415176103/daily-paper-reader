## 摘要
智能体越来越依赖可复用技能来编码任务知识、工具使用流程和验证规则。现有的技能自我进化方法主要利用从当前任务中收集的执行轨迹来修订技能，而公共技能版本历史中积累的进化知识在很大程度上未被利用。我们的初步研究揭示了这两种来源之间的明显互补性：公共技能变更提供了可复用的进化先验，而轨迹则提供了基于当前任务的证据。受此启发，我们提出了VCE-Skill，它将嘈杂且特定于实现的公共技能变更提炼为可复用的、结构化的版本变更经验，并自适应地将其与基础进化器从轨迹中得出的提议融合，从而在利用外部经验的同时保留特定于任务的证据。大量实验表明，VCE-Skill改善了技能自我进化，平均得分提高了3.20--4.98分；迁移实验进一步表明，由此产生的技能实现了更强的跨模型迁移性能。我们的工作强调了公共技能版本变更作为一种先前未被充分探索但有效的先验知识来源，并推进了轨迹驱动的技能自我进化。

## Abstract
Agents increasingly rely on reusable skills to encode task knowledge, tool-use procedures, and validation rules. Existing skill self-evolution methods primarily revise skills using execution trajectories collected from current tasks, leaving the evolution knowledge accumulated in public skill version histories largely untapped. Our pilot study reveals a clear complementarity between the two sources: public skill changes provide reusable evolution priors, whereas trajectories provide evidence grounded in the current task. Motivated by this, we propose VCE-Skill, which distills noisy and implementation-specific public skill changes into reusable, structured version-change experience and adaptively fuses it with trajectory-derived proposals from the base evolver, thereby exploiting external experience while retaining task-specific evidence. Extensive experiments demonstrate that VCE-Skill improves skill self-evolution, increasing mean scores by 3.20--4.98 points; transfer experiments further show that the resulting skills achieve stronger cross-model transfer performance. Our work highlights public skill version changes as a previously underexplored yet effective source of prior knowledge and advances trajectory-driven skill self-evolution.

## 2. 论文提出的方法论

VCE-Skill 包含两个阶段：**经验蒸馏（Experience Distillation）** 与**自适应经验注意力优化（Optimization with Adaptive Experience Attention）**。

### 2.1 经验蒸馏

- **变更抽象（Change Abstraction）**：
  - 对每个收集到的技能按时间排序，比较相邻版本得到原始 diff；
  - 将 diff 拆解为原子化的更新事件：`u_j = ⟨d_j, {c_j}, o_j, i_j⟩`，其中 `d_j` 为 diff 片段，`{c_j}` 为受影响的组件（指令、脚本、参考、配置、模板等），`o_j` 为语义操作（如"增加输入存在性检查"），`i_j` 为更新意图（如"防止缺少必需输入时执行"）。
- **经验生成（Experience Generation）**：将更新事件逐级抽象为三层可复用知识：
  1. **更新模式（Update Pattern）**：在同一技能版本历史中对兼容事件分组，去除仓库特定细节后归纳为可迁移的操作指南；
  2. **进化洞察（Evolution Insight）**：将每个技能的模式综合为表征该技能历史中重复出现的更新策略；
  3. **领域洞察（Domain Insight）**：跨同一任务领域的多个技能泛化共同的进化洞察，形成可迁移的优化原则。
  - 所有条目存入**经验库 B**，并按任务领域建索引，供在线优化阶段检索。

### 2.2 自适应经验注意力优化

- **经验选择**：在第 t 轮迭代中，从目标任务、当前技能、前一轮统一反馈构造选择上下文 `z_t = Context(T, S_{t−1}, f_{t−1})`，由 LLM 选择器从 B 中选取至多 K=5 条经验，聚合成紧凑的外部指导 `p_exp_t`。
- **注意力融合**：基础进化器（base evolver）独立从轨迹生成自我提议 `p_self_t`。论文分配源级权重 `λ_exp + λ_self = 1`（初始各 0.5，采用 prompt 级相对依赖指令而非概率），将两者融合为增强提议 `p_enh_t = Fuse(p_exp_t, p_self_t; λ_exp, λ_self)`。每条经验/自我提议会被分配唯一来源标识（`EXP-k` / `SELF-k`），以保证后续反馈的可归因性。
- **适配反馈**：
  - 来源反馈 `f_St`：将实际技能变更与带来源标签的候选编辑做语义对齐，统计外部支持 vs 自我支持的实现情况，归一化到 [−1, 1]；
  - 验证反馈 `f_Vt`：固定验证集上性能提升为正、否则为负；
  - 统一反馈 `f_t = f_Vt × f_St`：决定下一轮注意力调整方向；
  - 注意力更新：`λ_exp ← clip(λ_exp + η·f_t, 0.3, 0.7)`，η=0.1，防止任一侧被永久忽略。
- **整体循环**：执行技能 → 生成轨迹 → 自我提议 → 选择经验 → 融合提议 → 优化技能 → 执行验证 → 反馈调整，循环至迭代预算终止。VCE-Skill 不改变基础进化器的评估、保留与停止机制，仅替换提议构造方式，因此可与不同基础进化器即插即用。

## 7. 局限性与潜在问题

- **对公共经验库质量的敏感**：VCE-Skill 的效果依赖经验库中公共版本变更的质量、覆盖度与目标任务领域的匹配度；若公共技能与目标任务差异过大，检索到的经验可能引入噪音而非有效指导。
- **注意力更新机制仍偏启发式**：λ 的调节依赖固定步长 η=0.1 和手工设定的裁剪范围 [0.3, 0.7]，缺少理论上的收敛保证或对任务自适应调节的能力，可能在某些场景下无法达到最优平衡。
- **经验选择环节可靠性相对偏低**：人类审计显示经验选择的 HAR 为 86.5%（κ=0.75），在所有 LLM 判定环节中最低，说明经验检索与排序仍有不确定性，可能影响融合质量。
- **算力与开销披露不足**：论文仅提供 token 级额外开销，未报告总 GPU 小时数、并发配置等关键算力指标，难以精确复现成本，也削弱了可重复性透明度。
- **评估场景覆盖有限**：虽有 5 个基准，但均集中于单轮或有限轮的工具调用/任务执行；未涉及多智能体协作、长程开放式交互或持续在线学习场景，方法在这些场景中的适用性尚待验证。

## 8. 未来研究方向

- **更细粒度的经验表示与自动构建**：探索将版本变更进一步抽象为可组合、可推理的经验模块，并研究如何减少对人工定义组件的依赖。
- **可学习的注意力调节机制**：用强化学习或可微控制器替代启发式 λ 更新，使外部经验与轨迹证据的融合权重能够根据任务特征自动适应甚至在线预测。
- **扩大公共经验库的规模与多样性**：从更多代码托管平台、更多任务领域收集技能版本历史，构建更丰富的经验库，并研究跨领域迁移的边界条件。
- **更强的选择器与验证器**：针对经验选择环节的可靠性瓶颈，设计带验证回路的检索机制或利用模型集成提升选择准确率。
- **扩展至多智能体与持续学习场景**：将版本历史先验用于多智能体协作技能共享，或在面对分布漂移时进行持续的经验库更新与技能演化。

VCE-Skill 提出了一种新颖且有效的技能自我进化增强框架：它将公共技能版本历史这一长期被忽视的知识源，系统蒸馏为多层级经验，并通过自适应注意力机制与轨迹证据动态融合。该方法不改变底层进化器的评估与保留逻辑，即插即用，且在 5 个基准、4 个模型、3 个基础进化器上均带来一致且显著的性能提升，跨模型迁移增益尤为突出。其主要贡献在于首次验证了公共版本历史与轨迹证据的互补性，并提供了工程上可行的融合方案。尽管在注意力机制的理论保障、算力披露的完整性以及经验选择可靠性方面仍有改进空间，但整体上这项工作为技能自我进化开辟了“外部经验先验+内部轨迹证据”双源驱动的新方向，具有较高的学术价值与应用潜力。
