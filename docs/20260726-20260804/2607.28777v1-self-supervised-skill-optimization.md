## 摘要
智能体技能为冻结的大型语言模型（LLM）智能体提供可复用的程序性指导，近期研究表明此类技能可以借助真实标签（GT）反馈进行优化。然而，许多应用缺少GT标签、任务分数、奖励或可靠的任务专属评估器。为此，我们提出自监督技能优化（SSO），一种仅从未标注任务实例中学习可复用技能的对比框架。在每一步中，SSO 在当前技能上运行一个未标注批次，使用部分执行结果生成完整的技能探针，并在同一批次上运行这些探针。一个 LLM 裁判会比较所得答案、轨迹、产物或最终状态。一个独立的行为提取器在不查看裁判决策的情况下识别行为差异。SSO 利用这些决策跨实例聚合支持和反对所观察行为的证据，然后根据所得证据对行为进行排序，并从排名最高的行为中生成新的完整技能。仅当新技能在未标注验证集上优于当前技能时，该更新才被接受。在封闭式和开放式任务上，SSO 均优于现有的无GT提示优化器。在封闭式基准上，它不使用任何GT反馈即可接近甚至有时超过最强的基于GT的技能优化器。

## Abstract
Agent skills provide frozen large language model (LLM) agents with reusable procedural guidance, and recent work shows that such skills can be optimized with ground-truth (GT) feedback. Many applications, however, lack GT labels, task scores, rewards, or reliable task-specific evaluators. We therefore introduce Self-Supervised Skill Optimization (SSO), a comparative framework that learns a reusable skill from unlabeled task instances alone. At each step, SSO runs the current skill on an unlabeled batch, uses a subset of the resulting executions to generate complete skill probes, and runs the probes on the same batch. An LLM judge compares the resulting answers, trajectories, artifacts, or terminal states. A separate behavior extractor identifies behavioral differences without seeing the judge's decisions. SSO uses these decisions to aggregate evidence for and against the observed behaviors across instances. It then ranks the behaviors by the resulting evidence and renders a new complete skill from the highest-ranked behaviors. The update is accepted only if the new skill outperforms the current one on an unlabeled validation set. SSO outperforms existing GT-free prompt optimizers on both closed-ended and open-ended tasks. On closed-ended benchmarks, it approaches and sometimes exceeds the strongest GT-based skill optimizer without using any GT feedback.

## 1. 核心问题与研究动机

- 大语言模型（LLM）智能体在执行多步推理、工具调用和环境交互时，需要可复用的程序性指导，即“技能”（skill）文档。技能以自然语言形式持久化，可被冻结的 LLM 代理复用、检查与编辑。
- 现有技能优化方法（如 SkillOpt）依赖真实标签（GT）反馈，包括任务分数、奖励或专门的任务评估器；这些反馈在开放性问题、企业级任务、交互式或工件生成场景中经常缺失。
- 因此本文提出 **自监督技能优化（Self-Supervised Skill Optimization, SSO）**，目标是**仅从未标注的任务实例中**学习可复用技能，不依赖任何 GT 标签、分数、奖励或任务专属评估器。
- 核心问题正式化为：给定无标注训练集、验证集、冻结执行函数和初始技能文档，希望学到在未见任务上提高相对性能的技能，且更新生成与选择过程均不使用 GT 反馈。

## 2. 方法论：SSO 框架

### 2.1 核心思想
- 与现有“候选级选择”的 GT-free 提示优化器不同，SSO 采用**行为级证据聚合**：将执行差异拆解为可比较的“行为单元”，跨探针（probes）和任务实例累加正/负证据，从而构造出**不必与任一探针完全相同的全新完整技能**。

### 2.2 探针生成与锚定比较
- 每轮迭代 t：从无标注训练集采样批次 Xt，用当前技能 S_t 在每任务上执行得到锚定执行 r_i^o。
- 基于当前技能和部分历史 Ht，用 LLM 生成器 f_gen 生成 K 个完整技能探针 {P_k}，要求相互不同且不同于当前技能。
- 所有探针在**同一批次**上执行，得到 r_i^k；固定 LLM 裁判 f_judge 比较每次探针执行与对应锚定执行，输出 y_{ki} ∈ {+1, 0, -1}（+1 为偏好探针，-1 为偏好锚定，0 为平局）。
- 为减轻位置偏差，呈现顺序被随机化后再映射回探针和锚定身份。

### 2.3 行为提取与聚类
- 对每个存在至少一个非平局比较的任务，行为提取器 f_beh（**不看到裁判决策**）提取一组行为记录 B_i = {(β_ij, α_ij)}，其中 β 是行为描述，α 给出该行为在每个执行中的激活状态（1=出现，0=未出现，⊥=不明确）。
- 另一个 LLM 聚类器 f_cluster 仅基于行为描述，将语义等价的描述聚成簇，且用原始描述作为代表，不改变语义。

### 2.4 证据聚合与排序
- 对每次决定性比较，找出探针与锚定执行之间行为激活明显不同的簇集合 A_{ki}。
- 对该集合中每个簇 c，计算激活差 d_{kic} = α_{ic}(r^k_i) − α_{ic}(r^o_i)，并分配证据：
  \[
  e_{kic} = \frac{y_{ki} d_{kic}}{|A_{ki}|}
  \]
  这样每次比较的总绝对证据归一化为 1，避免行为较多的比较获得过大影响力。
- 计算簇 c 的净得分 Q_c = Σ e_{kic} 和总证据质量 E_c = Σ |e_{kic}|；Q_c 的符号决定该行为的更新方向（鼓励/抑制/中性），Q_c=0 的簇被丢弃。
- 按 |Q_c| 降序，依次以 E_c 和贡献任务数作为平局处理，取前 U 个簇作为本轮行为单元 U_t。

### 2.5 全技能渲染与无标签验证
- 若 U_t 非空，渲染器 f_render 根据当前技能和所选行为生成候选新技能：对鼓励的行为增加/强化，对抑制的行为删除/弱化/限制；候选技能可融合不同探针的行为。
- 在无标注验证集 Vt 上执行当前技能和候选技能，用同一 LLM 裁判比较，统计候选胜场 W_t 与败场 L_t；仅当 W_t > L_t 时接受候选，否则保持当前技能。
- 算法流程（可视为梯度式迭代）：当前技能 → 生成探针 → 执行比较 → 行为提取/聚类 → 证据聚合/排序 → 渲染候选 → 无标签验证门控。

## 6. 主要结论与发现

- 在封闭式任务中，SSO 是**最强的 GT-free 方法**：相比 No skill 平均分别提升 20.4、16.6、14.2 个百分点（GPT-5.5、GPT-5.4-mini、Qwen3.5-4B）；在 GPT-5.5 上比 SPO 高 9.8 分，恢复了 SkillOpt 增益的 86.8%；在 GPT-5.4-mini 上甚至**超过 SkillOpt 1.2 分**；在 Codex 框架下仅落后 SkillOpt 1.9 分。
- 在开放式任务中，SSO 对所有基线的两两胜率均超过 50%，平均胜率：对 No skill 62.4%、对 SPO 63.6%、对 PDO 62.5%。
- 消融表明行为级聚合、证据归一化、验证门控等组件都贡献了性能，**直接探针选择和随机行为选择导致最大性能下降**。
- 优化动力学显示渲染候选始终优于后验最佳探针，验证门控能有效拒绝退化更新。

## 7. 优点

- **完全无 GT**：不依赖标签、分数、奖励或任务评估器，适用于现实中的开放式和资源缺乏场景。
- **行为级证据聚合**：超越候选级选择，能融合不同探针中的有利行为，构造出“更优且完整”的新技能。
- **防偏设计**：行为提取器不看到裁判决策，聚类器只看描述，且裁判比较时随机化呈现顺序以缓解位置偏差。
- **证据归一化**：每次决定性比较总证据权值为 1，避免行为数量多的比较主导优化。
- **无标签验证门控**：在验证集上通过 LLM 裁判比较候选与当前技能，防止退化和过拟合训练批次。
- **跨任务、跨模型、跨执行框架验证**：同时在封闭式/开放式、三种目标模型和 Codex 框架下评测。

## 8. 不足与局限

- **依赖 LLM 裁判**：即使随机化顺序，LLM 裁判仍可能有偏好、幻觉或对长轨迹判断不稳定；没有与人类判断的一致性分析。
- **行为提取与聚类同样依赖 LLM**，语义等价的聚类质量难以保证，可能影响证据分配的准确性。
- **GT-based 基线结果非全部复现**：多个基线沿用 SkillOpt 论文数据，存在实验环境、模型版本和评测细节不一致的风险。
- **封闭式基准虽然不使用 GT 优化，但评测仍依赖准确性指标；部分基准（如 LiveMathematicianBench）本身带有答案，没有完全体现“无任何标签”的极端情况**。
- **开放式任务仅限 MT-Bench-101 三个对话任务**，未涵盖真实代理场景（如工具调用、多轮交互工件生成）。
- **超参数扫描只在一个目标模型（GPT-5.4-mini）上进行**，对其它模型的泛化性结论尚不充分。
- **算力和实现细节披露有限**：未报告训练/优化耗时、GPU 资源、每次验证的运行成本，难以评估实际部署开销。
- **优化侧所有模块固定

优化侧所有模块固定使用 GPT-5.5，可能导致优化过程与目标模型之间存在模型偏好耦合，且未探索优化模块使用较弱或不同容量模型时的鲁棒性；此外，优化侧与裁判侧共用同一模型，也可能使验证信号带有自我增强偏差，进一步放大单个模型的主观性影响。

## 9. 总体评价

SSO 通过行为级证据聚合与无标签验证门控，在不依赖任何 GT 反馈的条件下显著提升了 LLM 智能体的技能文档质量，在封闭式和开放式基准上均超越了现有 GT-free 基线，甚至在某些目标模型上逼近或反超使用 GT 的 SkillOpt。其核心贡献在于将“候选级选择”升级为“行为级融合”，使优化过程能够跨探针重组有利行为，从而生成更优的完整技能。然而，该方法的高性能建立在 LLM 裁判、行为提取与聚类模块的可靠性之上，这些环节引入的潜在偏差尚未被系统性量化；同时，开放式评测仅覆盖对话型任务，真实代理工作流中的适用性仍有待验证。总体而言，本文为无监督技能优化提供了扎实的新基线，并为后续研究提出了几个关键方向：降低对 LLM 裁判的依赖、增强行为提取的鲁棒性，以及在更广泛的实际 Agent 场景中验证该框架的泛化能力。
