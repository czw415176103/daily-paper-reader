## 摘要
Beagle框架是一个基于GPU的遗传编程框架，通过利用NVIDIA GPU实现大规模种群的高效遗传编程搜索。本技术指南介绍了Beagle框架，并提供了使用该框架解决符号回归问题的详细说明。

## Abstract
The Beagle framework is a GPU-based genetic programming framework that enables highly efficient genetic programming search using large population sizes by leveraging NVIDIA GPUs. This technical guide provides an introduction to the Beagle framework and provides detailed instructions for using the framework for symbolic regression problems.

- **核心问题**：传统遗传编程（GP）在种群规模较大时计算开销极高，CPU实现在大规模搜索空间下性能瓶颈明显，难以充分利用现代GPU的并行计算能力。
- **背景**：符号回归是遗传编程的重要应用领域，但随着问题复杂度增加，需要大规模种群（数百万个体）来有效探索搜索空间。现有CPU框架受限于单线程或有限多线程，无法实现高效扩展。
- **整体含义**：Beagle框架旨在填补这一空白，通过深度定制的NVIDIA GPU加速内核，使遗传编程能够在合理时间内运行百万级种群，从而提升符号回归问题的求解效率和质量。

## 2. 方法论：核心思想、关键技术细节

- **核心思想**：将遗传编程的计算负载合理分配到CPU和GPU：GPU负责模型评估和适应度计算（大规模并行），CPU负责遗传操作（初始化、变异、选择等，不使用交叉）。通过减少CPU–GPU数据传输开销，实现高效协同。
- **关键技术细节**：
  - **软件环境**：基于.NET 10、开源库ILGPU（提供低层CUDA类似接口），在C#生态中编写自定义CUDA内核。
  - **硬件优化**：自动利用所有可用GPU和CPU；支持多GPU；GPU内存不足时自动分批处理。
  - **CPU优化**：使用“死亡池”重用个体内存，几乎消除垃圾回收和内存碎片，避免反复分配/释放。
  - **表示**：采用线性遗传编程（LGP）语言——基因组计算机语言（GCL），基于逆波兰表示法（RPN），栈大小为32。LGP更适合GPU静态内存模型。
  - **线程分歧避免**：每个CUDA块对应一个个体，每个线程处理一个适应度案例，保证同一warp内只有同一模型，减少分支分歧。
  - **适应度函数**：默认使用相关度适应度（基于皮尔逊相关系数），支持自定义点对点函数。处理无效数值（NaN/Inf）时采用特殊奖励机制。
  - **选择机制**：蒙特卡洛排名——每代随机抽样100个个体估算百分位数，按表2中的繁殖权分配后代数，避免全种群排序的高开销。
  - **种群大小动态**：目标种群大小可变化（如先大后小），实际大小在目标±20%范围内波动。
  - **停滞恢复**：设定无进步触发重置（TotalBirthsToResetColonyIfNoProgress），保留最佳个体，重新初始化其余个体。
  - **始终可变异**：对产生无效基因组进行随机修正，确保评估时间只花在有效个体上。
