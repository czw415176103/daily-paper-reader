## 摘要
多智能体大语言模型通过在共享环境中协调多个策略来解决复杂任务。然而，现有的强化学习方法通常单独优化每个响应或轨迹，即使多个输出共同导致一个状态转换。因此，更新单元与系统执行的动作不同。为了解决这个问题，我们提出了SRPO（集合级相对策略优化），它将活动集合——即一次转换所消费的最小输出集合——视为一个多智能体动作。具体来说，SRPO将成员对数比率合并为一个基数归一化的集合比率，分配一个相对优势，并对集合进行一次裁剪。这一表述将分工和联合共同进化统一为具有不同集合大小的动作。在数学推理和多轮搜索上的实验展示了在四种模型规模下适用于固定、混合和动态路由工作流的一种训练接口，在报告的对比中取得了最强的宏观平均结果。优化诊断进一步刻画了其在不同事件缩减和集合大小下的稳定性。

## Abstract
Multi-agent large language models solve complex tasks by coordinating several policies in a shared environment. However, existing reinforcement learning methods usually optimize each response or trajectory separately, even when several outputs jointly cause one state transition. Consequently, the update unit differs from the action executed by the system. To address this problem, we propose SRPO (Setwise Relative Policy Optimization), which treats the active set the minimal set of outputs consumed by one transition, as one multi-agent action. Specifically, SRPO combines member log-ratios into one cardinality-normalized set ratio, assigns one relative advantage, and clips the set once. This formulation unifies division of labor and joint co-evolution as actions with different set sizes. Experiments on mathematical reasoning and multi-turn search demonstrate one training interface for fixed, mixed, and dynamically routed workflows across four model scales, with the strongest macro-average results among the reported comparisons. Optimization diagnostics further characterize its stability under different event reductions and set sizes.

### 1. 核心问题与整体含义（研究动机与背景）
- **核心问题**：多智能体大语言模型（Multi-agent LLMs）通过多个策略在共享环境中协作完成复杂任务。然而，现有强化学习方法通常以单条响应或单条轨迹为更新单元，即使多个输出共同引发一次状态转移。这种“更新单元”与“系统真实执行动作”之间的不匹配，限制了统一的优化规则在不同协作模式（分工、联合共进化、混合路由）间的适用性。
- **核心挑战**：如何定义一种**独立于智能体顺序、角色与编排布局**的多智能体动作表征。
- **核心含义**：将“共同改变环境状态的输出”视为一个整体来优化，而非孤立地逐个优化。这一思想使分工与联合共进化统一在同一策略优化框架内。
- **整体背景**：现有 MAS-RL 方法（如 MAGRPO、Dr. MAS、MHGPO 等）的更新单元往往绑定于预定义的智能体、轮次、分组或 rollout 布局，缺少一种工作流无关（workflow-independent）的公式化表述。

### 2. 提出的方法论：核心思想、技术细节与算法流程

#### 2.1 核心思想：Active Set（活跃集）作为多智能体动作
- **Active Set（活跃集）定义**：在一次决策事件 e 中，环境共同消费以产生下一状态的最小的新采样输出集合，记作 Se；集合动作 ae = {ae,j : j ∈ Se}。
- **划分依据**：
  - **Ke = 1**：分工（division of labor），如路由器或聚合器的单例输出；
  - **Ke > 1**：联合共进化（joint co-evolution），如多个并行求解器或搜索代理的输出；
  - **混合工作流**：Ke 随时间动态变化。
- **原子性判定**：只有被提交到共享内存或被环境消费的输出才计入活跃集；私人草稿不算。若聚合器输出被提交，则活跃集是聚合器的单例输出而非其私有输入。
- **状态边界**：若一个输出在另一个策略行动前被披露，则二者属于不同事件。
- **关键性质**：所有成员输出采样自同一逻辑前置状态，并被单一转移消费；事件动作概率因子化为各成员策略的乘积。该定义与成员策略是否共享参数无关。

#### 2.2 关键技术细节：Setwise policy ratio（集合级策略比率）
- **成员级掩码序列对数比率**：
  - ℓe,j = Σu me,j,u log( qcur(ae,j,u | oe,j,u) / qold(ae,j,u | oe,j,u) )
  - 其中 me,j,u 排除 prompt、padding 与环境 token。
- **集合级归一化事件对数比率与事件比率**：
  - L_set_e = (1/√Ke) Σ_{j∈Se} ℓe,j
  - ρ_SRPO_e = exp(L_set_e)
- **归一化理由**：使用 √Ke 归一化（而非不归一化求和或 1/K 平均）：
  - 保持独立成员尺度的方差不变（若成员独立且方差为 σ²，则 Var(L_set) = σ²）；
  - 显式处理相关成员贡献（协方差项）；
  - 避免活跃集增大时更新量级不成比例增长。
- **Ke = 1 时的退化**：退化为普通序列级似然比。
- **单一优势分配**：每个事件分配一个优势值（group-relative，可替换为 critic 或 GAE）；同一事件的所有成员共享同一标量优势。
- **一次集合级裁剪**：J_SRPO(Θ) = (1/|B|) Σ_{e∈B} min( ρ_e Â_e, clip(ρ_e, 1−ε, 1+ε) Â_e )，即对完整活跃集整体裁剪一次，而非逐成员裁剪。
- **事件级别归约**：对完整事件做 mini-batch 归约（而非 token 或成员行级别），使每个环境转移恰好贡献一次。

#### 2.3 算法流程（训练循环）
1. 采样问题并重置环境；
2. 观察状态 oe，路由器选择活跃集 Se ← O(oe)；
3. 并行采样 Se 中每个成员输出 ae,j；
4. 执行聚合动作，获得下一状态与团队奖励；
5. 将完整事件（含事件 ID、成员索引、预期基数、策略版本、行为对数概率）追加到事件批次；
6. 移除不完整事件，对可比事件分组并计算相对优势；
7. 计算成员对数比率 → 归约为集合级比率 → 计算事件优势 → 一次集合裁剪；
8. 更新所有策略参数。
- **系统要求**：仅需一条附加约束——同一事件的所有行必须保留在同一全局 mini-batch 中，缺失成员则使事件失效。
