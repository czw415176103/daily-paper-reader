## 摘要
物理信息学习偏微分方程（PDE）一直由多层感知机（MLP）主导，但其频谱偏差和密集参数化限制了准确性和可解释性。Kolmogorov Arnold网络（KAN）通过可学习的样条激活函数，在结构上与经典离散化的分段多项式基对齐，从而缓解了这些限制。然而，将PDE转化为损失函数的方式与近似器的选择同样关键：强形式残差最小化需要高阶导数和重加权损失，能量（Bubnov-Galerkin）形式仅限于自伴算子，并且如我们所示，对于参数识别问题会退化为平凡解，而边界积分形式需要已知的基本解。我们提出PG-KINN，一种基于Petrov-Galerkin格式的物理信息KAN，其中试验空间是KAN，测试空间是一个独立的、紧支撑的、分段多项式空间，并通过Gauss-Legendre求积进行评估。分部积分降低了微分阶数，同时保持了对一般非自伴、非线性和逆问题的适用性；局部测试函数将全局残差转化为一组条件良好的单元弱残差。在一系列涵盖裂纹奇异性、应力集中、Neo-Hookean超弹性、非均匀介质中的逆参数识别以及复杂几何形状的基准测试中，PG-KINN始终优于传统的MLP基线和最先进的基于KAN的强/能量/逆形式（PIKAN）。这些结果将KAN试验空间与多项式测试空间的Petrov-Galerkin耦合定位为基于AI的计算力学的一条稳健且准确的路径。

## Abstract
Physics-informed learning of partial differential equations (PDEs) has been dominated by multilayer perceptrons (MLPs), whose spectral bias and dense parameterization limit both accuracy and interpretability. Kolmogorov Arnold Networks (KANs) mitigate these limitations because their learnable spline activations are structurally aligned with the piecewise-polynomial bases of classical discretizations. However, the way a PDE is cast into a loss functional is as decisive as the choice of approximator: strong-form residual minimization requires high-order derivatives and heavily weighted losses, the energy (Bubnov-Galerkin) form is restricted to self-adjoint operators and, as we show, collapses to a trivial solution for parameter-identification problems, and boundary integral forms require a known fundamental solution. We propose PG-KINN, a physics-informed KAN built on a Petrov-Galerkin formulation in which the trial space is a KAN and the test space is an independent, compactly supported, piecewise-polynomial space evaluated with Gauss-Legendre quadrature. Integration by parts lowers the differentiation order while retaining applicability to general non-self-adjoint, nonlinear, and inverse problems; the localized test functions turn the global residual into a set of element-wise weak residuals with favorable conditioning. On a suite of benchmarks spanning crack singularities, stress concentration, Neo-Hookean hyperelasticity, inverse parameter identification in heterogeneous media, and complex geometries, PG-KINN consistently outperforms legacy MLP baselines and state-of-the-art KAN-based strong/energy/inverse formulations (PIKAN). These results position the Petrov-Galerkin coupling of KAN trial spaces and polynomial test spaces as a robust and accurate route for AI-based computational mechanics.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究动机**：物理信息神经网络（PINNs）用于求解偏微分方程（PDE）时，长期以来主要依赖多层感知机（MLP）。但 MLP 存在两大缺陷：一是**频谱偏差**（高频率成分学习缓慢），二是**密集参数化**导致可解释性差。虽然 Kolmogorov–Arnold 网络（KAN）通过可学习的 B 样条激活函数缓解了这些问题，但其精度仍受限于损失函数的形式选择。
- **现有方法瓶颈**：
  - **强形式**（PINN）需要高阶导数，且边界损失与内部残差之间的权重调节困难。
  - **能量形式**（Bubnov–Galerkin）仅适用于自伴算子，且对于**逆参数识别问题**，其损失函数会驱使模量趋于零（零模量塌缩）。
  - **边界积分形式**需要已知基本解，无法用于非线性或强非均匀介质。
- **核心目标**：提出一种兼具低阶导数、通用算子适用性、且能避免逆问题塌缩的物理信息求解框架。

## 2. 论文提出的方法论：核心思想、关键技术细节和算法流程

### 2.1 核心思想
- **Petrov–Galerkin 弱形式**：试验空间（trial space）为 KAN（B 样条基函数），测试空间（test space）为独立的、紧支撑的、分段多项式空间。通过**分部积分**将导数从试验函数移到测试函数，从而降低导数阶数，同时保持对非自伴和非线性算子的通用性。
- **局部测试函数**将单个全局残差转化为多个**单元级弱残差**，改善条件数，并自然处理 Neumann 边界和材料界面。

### 2.2 关键技术细节
- **KAN 结构**：每层使用 B 样条基展开，加上残差连接和 SiLU 激活函数；输入通过归一化映射到样条网格 $[-1,1]$。
- **测试函数**：两类：节点型 C⁰ 函数（hat 函数或 Lagrange 函数）和**内部气泡函数**（基于移位 Legendre 多项式乘以消失包络），保证在 Dirichlet 边界上为零。
- **积分方法**：**Gauss–Legendre 求积**（ng ≈ 4–6），在背景网格单元上精确积分（因为 KAN 和测试函数均为分段多项式，积分精度高）。
- **边界条件处理**：Neumann 数据作为自然边界积分直接加入弱形式；Dirichlet 数据通过轻惩罚项或容许构造施加。
- **优化**：Adam + L-BFGS（正向问题）；反向问题仅用 Adam/L-BFGS。

### 2.3 算法流程
- **正向算法（Algorithm 1）**：  
  1. 构建测试基函数和 Gauss–Legendre 求积节点。  
  2. 初始化 KAN 参数 θ。  
  3. 对每个测试函数 vₖ，用自动微分计算 KAN 和梯度，在求积点上组装弱残差 Rₖ(θ)。  
  4. 计算损失 L = (1/M) Σ ωₖ Rₖ² + λᵤ L_Γu。  
  5. 用 Adam / L-BFGS 更新 θ。
- **逆向算法（Algorithm 2）**：  
  1. 同正向构建测试基和求积。  
  2. 将未知系数 κ 用 KAN 参数化 θκ。  
  3. 将测得的场 u 固定，在每个测试函数上组装 Rₖ(θκ) = ∫ κₕ ∇u·∇vₖ dΩ - ℓₖ。  
  4. 最小化 L_inv = (1/M) Σ Rₖ²（无边界惩罚项，因为该损失天然避免零模量塌缩）。  
  5. 更新 θκ。

### 2.4 逆问题无塌缩性证明（Proposition 1）
- 能量形式逆问题：应变能 Ψ = E·Ψ₀，最小化 Ψ 导致 E → 0。  
- PG 弱残差：Rₖ(κ) = ∫ κ ∇u·∇vₖ dΩ - ℓₖ，若 κ ≡ 0，则 Rₖ = -ℓₖ ≠ 0（数据非平凡时），因此零系数不是全局极小点。且真系数 κ* 满足 Rₖ*=0 为唯一全局极小点（若测试空间充分）。
