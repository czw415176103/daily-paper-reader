## 摘要
由大型语言模型（LLM）驱动的自主智能体通过交互不断积累经验，这为通过自我进化改进未来行为创造了机会。一个基本挑战是如何将丰富的、特定于任务的交互经验转化为可复用的模型能力，同时不牺牲对新兴证据的快速适应能力。显式文本状态（如技能和智能体框架）提供了快速、可读且可编辑的适应方式，但对外部上下文存在持续依赖；参数化策略则提供了紧凑且可复用的能力，但更新速度要慢得多。我们提出\textit{体验漏斗}（Experience Funnel），一种自进化框架，在交替循环中将快速状态适应与缓慢策略整合相结合。交互轨迹首先被提炼为显式文本状态，新获得的经验可以快速纳入并验证。随后，该框架有选择地识别在状态修订后仍有用的状态驱动行为，并通过转换感知提炼将其整合到策略中。更新后的状态-策略对接着生成新的轨迹，为下一轮状态适应和策略整合提供新的证据。在多种智能体基准上的实验表明，\textit{体验漏斗}在智能体能力上持续优于仅状态进化和策略内化方法，同时逐步将有用的显式经验转化为自主策略能力。

## Abstract
Autonomous agents powered by large language models (LLMs) continuously accumulate experience through interaction, creating an opportunity to improve future behavior through self-evolution. A fundamental challenge is how to transform abundant, task-specific interaction experience into reusable model competence without sacrificing the ability to adapt rapidly to newly observed evidence. Explicit textual states, such as skills and agent harnesses, provide fast, human-readable and editable adaptation, but incur persistent dependence on external context; parametric policies provide compact and reusable competence, but are substantially slower to update. We present \textit{Experience Funnel}, a self-evolving framework that couples fast state adaptation with slow policy consolidation in an alternating loop. Interaction trajectories are first distilled into an explicit textual state, where newly acquired experience can be rapidly incorporated and validated. The framework then selectively identifies state-enabled behavior that remains useful across state revisions and consolidates it into the policy through transition-aware distillation. The updated state--policy pair subsequently generates new rollouts, providing fresh evidence for the next round of state adaptation and policy consolidation. Experiments across diverse agent benchmarks show that \textit{Experience Funnel} consistently improves agent capability over state-only evolution and policy-internalization approaches, while progressively converting useful explicit experience into autonomous policy competence.

## 1. 论文的核心问题与整体含义

- **背景**：由 LLM 驱动的自主智能体在反复交互中会持续积累经验，自我进化（self-evolution）是提升其未来行为能力的自然途径。论文聚焦的核心问题是：**如何将海量、任务相关的交互经验转化为可复用的模型能力，同时不牺牲对新证据的快速适应能力**。
- **核心矛盾**：现有经验表征方式分为两类，各有权衡——
  - **显式文本状态**（技能库、记忆、程序性指令、harness 等）：快速、可读、易编辑，但会持续依赖外部上下文，且无限累积会导致检索与上下文成本上升。
  - **参数化策略**（通过 RL 或蒸馏内化经验）：紧凑、可复用，但更新速度慢，且盲目吸收所有经验可能固化噪音或冗余行为。
- **关键洞见**：单一表征形态均不是自我进化的理想终点；显式经验的价值**依赖于当前策略**——策略进化后，旧有的显式指导可能变得冗余、互补甚至冲突。因此需要一种机制，让经验在快（状态）与慢（策略）两种形态之间**渐进流动、持续过滤**。

## 2. 论文提出的方法论

### 2.1 总体框架：State–Policy Alternating Loop（状态-策略交替循环）
- 整体演化链条为：
  - **(S_k, π_k) → S_{k+1} → π_{k+1} → S_{k+2} → π_{k+2} → …**
- 每轮进化分为两大阶段：

**阶段一：状态演化（State Evolution）**
- 当前状态-策略对在部署中累积轨迹，攒够一批后冻结为反思批次。
- 在**跨轨迹层面**归纳反复出现的行为模式（如重复性错误、有效操作序列），而非单条样例上的纠错——用更高层的文本形式概括候选状态编辑。
- 候选更新在**独立保留的验证集**上、以当前策略执行并检验环境级结果，只有真正提升表现的状态编辑才被接受。此举用于过滤样本特异性或不可靠的更新。

**阶段二：选择性策略整合（Selective Policy Consolidation）**
- 被接受的状态更新改善了当前智能体，但也增加了对部署时上下文（外部状态）的依赖，因此需要把确有价值的状态驱动行为下沉为策略能力。
- 核心组件是 **Transition-Aware Skill Distillation（过渡感知技能蒸馏）**，包含三个层次：

a) **轨迹级选择（Transition-Aware Rollout Selection）**
- 对每条交互样本，分别评估三种条件下策略 π_k 的环境结果：
  - r_i⁰ = R(π_k, x_i)：无状态
  - r_i⁻ = R(π_k, x_i, S_k)：加旧状态
  - r_i⁺ = R(π_k, x_i, S_{k+1})：加新状态
- 用阈值化标记 b⁻、b⁺ 区分四种状态转移类型：
  - **(0,1) 新有用**：仅新状态带来增益 → 选入
  - **(1,1) 持续有用**：新旧状态均有增益 → 以系数 α 部分纳入
  - **(1,0) 退化**：新状态反而降低效用 → 不选
  - **(0,0) 无效**：状态无增量作用 → 不选

b) **token 级归因（State-Responsive Token Attribution）**
- 对入选轨迹中的每个 token，在相同前缀下比较“带状态”与“不带状态”两个分支的输出分布，用量化出的 Jensen–Shannon 散度衡量该位置对状态条件的响应程度。
- 归一化后得到 token 权重 w_{i,t}，从而将蒸馏信号聚焦于由状态驱动的具体决策位置，而非整条轨迹平均施加。

c) **策略整合目标**
- 蒸馏损失：让无状态的学生策略 π_θ 拟合带状态教师分支 p⁺ 的分布，以 a_i 和 w_{i,t} 加权。
- 完整目标函数为：**L_consolidate = L_state-free RL + λ_distill · L_distill**，即在无状态奖励优化（GRPO）的基础上叠加选择性蒸馏。
- 候选策略 π̃_{k+1} 只有在验证中确认无状态表现达标后才被采纳。

- **闭环反馈**：更新后的状态-策略对重新部署并生成新一轮轨迹；这些轨迹同时提供新经验和旧有状态的延迟证据——互补的保留、冗余的移除、未解决的失败驱动下一轮状态更新。由此实现经验在显式和参数表征间的持续“漏斗式”筛选。

### 2.2 论文的三条方法论要点
1. 状态更新必须经过**跨轨迹反思 + 保留验证门控**的过滤；
2. 策略整合只选择性吸收**跨状态版本仍有效的行为**，而非无差别蒸馏全部轨迹；
3. 状态演化与策略整合**交替进行、互为前提**，而非各自独立优化。

## 3. 实验设计

- **主要评测场景**（共 3 个环境）：

  - **ALFWorld**（具身交互）
  - **WebShop**（网页导航）
- **模型配置**：Qwen3.5-4B 作为可演化的部署策略；Qwen3.5-27B 作为固定的 OPD 教师模型。
- **评价指标**：SearchQA 用 Hard Answer Accuracy（ACC），三个环境均报告任务准确率/成功率。
- **数据协议**：训练集用于经验收集、状态修订、跨版本转移标注和 OPD；验证集仅用于接受状态修订与选择策略检查点；测试集只用于最终报告，不参与任何进化更新。
- **进化协议**：共运行 5 轮状态演化，其中第 1 轮和第 4 轮通过验证门控、触发策略整合，第 2、3、5 轮被拒绝、沿用上一组状态-策略对。
- **对比方法**，分四类：
  - 基线：Qwen3.5-4B 基座模型；
  - 显式状态演化类：SkillOpt-Lite、SkillOpt；
  - 策略内化类：SKILL0、SkillC、OPID；
  - 状态-策略协同进化类：SkillRL；以及本文方法（State–Policy Consolidation Loop）。

## 6. 论文的主要结论与发现

1. **总体性能提升**：本文方法在 SearchQA（62.4%）、ALFWorld（67.9%）、WebShop（42.4%）以及平均分（57.6%）上全面优于四类对比方法。
2. **策略自主能力持续增强**：可接受整合轮次后，无状态策略准确率从 58.1% 升至 61.3%，说明显式经验被渐进地转化为自主策略能力。
3. **显式经验的价值依赖策略上下文**：同一进化后状态与**初始策略**的配对只达 60.2%，与**同步进化策略**配对才达到 62.4%，且差距随进化加深（中间 0.8 pp → 最终 2.2 pp），支持“状态-策略应协同进化”的核心观点。
4. **跨版本选择性整合是收益关键**：仅使用新有用（01）+ 持续有用（11）的 63.0% 明显优于未过滤全样本（58.9%）以及单一的 01（55.2%）或 11（59.9%）子集，说明策略整合应有选择性地关注跨状态版本有效的行为。
5. **教师升级并非增益来源**：27B 教师不加状态时使性能跌至 56.29%，显著低于基线（58.14%）；仅当教师条件于进化后状态时，准确率才提升到 61.21%。增益本质来自“大教师在执行进化状态”这一条件化能力而非模型规模。
6. **整合后状态的角色转化为补充**：整合后的策略在无状态下达 61.3%，补回完整状态只有 +1.1 pp 的边际增长，而用残差状态即可维持同等性能，表明可复用经验已沉入策略，外部状态只保留尚未内化的补充信息。

## 7. 优点

- **设计角度**：
  - 明确提出“经验漏斗”的思路，找到快速状态适应和慢速策略整合的互补性切入点；
  - 用跨版本（旧状态 vs 新状态 vs 无状态）行为差异来筛选经验，比只对比“有 vs 无状态”更能捕捉策略转移依赖；
  - 把状态-策略协同进化的设想落到一个可直接训练的联合框架中，并设置验证门控以避免有害更新；
  - token 级归因让蒸馏信号集中在状态真正影响的决策点，而非平均化整条轨迹；
  - 把“策略如何改变状态价值”作为一等公民实验对象，验证了状态与策略联合演化的必要性。
- **实验角度**：
  - 在 3 个跨域（QA、具身交互、Web）环境上验证；覆盖 8 种以上方法和类型化对比；
  - 对教师容量、状态条件化、经验选择策略分别做控制对照，排除了常见混淆因素；
  - 消融显示“仅状态”与“仅策略”各自不足以取得最好性能，二者联合是必要的。

## 8. 不足与局限

- **适用场景局限**（作者明确承认）：框架主要面向部署后反复处理相关任务且反馈充分的环境，对一次性任务或反馈高度主观稀疏的应用不直接适用。
- **计算开销**：多条件（无状态/旧状态/新状态）的 rollout 评估、状态修订和策略整合带来显著额外算力；虽然有“低峰期异步整合”的缓解思路，但仍引入了经验与更新之间的延迟。
- **实验严谨性局限**：
  - 论文没有给出多次运行的均值/方差或显著性检验；对“4B 教师不受益于状态条件化”等判断作者自己也承认需更多重复来确认；

  - 有关 910B3 NPU 算力规模、每个实验的训练时长等资源描述相对粗略。
- **设备与优化层面的细节**：未披露超参数、蒸馏权重 λ、α 系数取值、批次/回合数等关键设置，给复现带来一定困难。考虑到数据规模可见于训练协议而超参缺失，稳健性可进一步提升。
