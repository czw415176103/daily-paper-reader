## 摘要
我们提出了Agents-A1，一个35B参数的混合专家智能体模型，通过扩展智能体视野达到了万亿参数级别的性能。我们从两个角度研究智能体视野扩展：扩展长程轨迹和扩展异构智能体能力。为支持这一目标，我们构建了一个长程知识-行动基础设施，连接外部知识、行动、观察和验证器结果，生成平均长度为45K令牌的智能体轨迹。在此基础上，我们采用三阶段方案训练Agents-A1。首先，进行全领域监督微调，使基础模型与广泛的智能体行为对齐。其次，训练领域级教师模型以捕捉每个领域的专业知识。第三，我们提出了一种多教师领域路由在线策略蒸馏方法，结合显著词汇对齐，以提高跨不同领域的知识迁移效率，将六个异构领域统一为一个可部署的学生模型。Agents-A1在长程智能体基准测试中取得了强大而广泛的表现。与万亿参数模型如Kimi-K2.6和DeepSeek-V4-pro相比，Agents-A1在SEAL-0（56.4）、IFBench（80.6）、HiPhO（46.4）、FrontierScience-Olympiad（79.0）和MolBench-Bind（56.8）上取得了领先结果，并在SciCode（44.3）、HLE（47.6）和BrowseComp（75.5）上保持高度竞争力。我们希望这项工作为社区提供一条实用路径，即使用35B智能体扩展视野，达到或匹敌万亿参数模型在长程任务上的性能。

## Abstract
We introduce Agents-A1, a 35B Mixture-of-Experts Agentic Model that reaches trillion-parameter-level performance by scaling the agent horizon. We investigate agent-horizon scaling from two perspectives: scaling long-horizon trajectories and scaling heterogeneous agent abilities. To support this goal, we build a long-horizon knowledge-action infrastructure that connects external knowledge, actions, observations, and verifier outcomes, producing agentic trajectories with an average length of 45K tokens. Based on this, we train Agents-A1 with a three-stage recipe. First, we perform full-domain supervised fine-tuning to align the base model with broad agentic behaviors. Second, we train domain-level teacher models to capture specialized expertise in each domain. Third, we propose a multi-teacher domain-routed on-policy distillation with salient vocabulary alignment to improve knowledge transfer efficiency across different domains, unifying six heterogeneous domains into one deployable student model. Agents-A1 achieves strong and broad performance for long-horizon agent benchmarks. Compared with 1T-parameter model such as Kimi-K2.6 and DeepSeek-V4-pro, Agents-A1 achieves leading results on SEAL-0 (56.4), IFBench (80.6), HiPhO (46.4), FrontierScience-Olympiad (79.0), and MolBench-Bind (56.8), and remains highly competitive on SciCode (44.3), HLE (47.6) and BrowseComp (75.5). We hope this work provides the community with a practical path for scaling the horizon using a 35B agent that can reach or match the performance of 1T models on long-horizon tasks.

- **核心问题**：当前大语言模型（LLM）向自主智能体方向发展，但在现实世界长程任务（如软件工程、科学研究、复杂决策）中，需要智能体具备多步规划、工具调用、交互反馈与策略调整能力。现有方法主要沿两条路线：一是**扩展模型参数**，让模型通过海量参数内化各种推理与工具使用模式，但这需要巨大资源且难以复现；二是**扩展智能体视野**，将中间决策过程显式化并作为可训练监督信号。然而，后者面临两大瓶颈：**知识基础设施不足**（缺乏能连接外部知识、动作、观察与验证信号的统一环境）和**异构能力整合困难**（多领域能力如信息检索、工具使用、约束跟踪等难以融合到一个模型中）。

### 2. 论文提出的方法论

#### 核心思想
- **以“视野扩展”替代“参数扩展”**：不依赖海量参数，而是通过生成极长（平均45K tokens）的智能体轨迹，将知识获取、动作执行、观察理解、验证反馈等过程作为可监督信号，让模型从接地反馈中学习。
- **三阶段训练管线**：
  1. **全领域SFT**：从Qwen3.5-35B-A3B出发，在多领域长程轨迹上进行监督微调，获得基础长程智能体能力。
  2. **领域级教师训练**：针对六个领域（搜索、机器学习工程、科学研究、指令遵循、工具调用、通用智能体任务）分别训练专用教师模型，使用SFT或强化学习（GRPO）提升其专项能力。
  3. **多教师在线蒸馏**：提出**领域路由在线策略蒸馏（Domain-Routed On-Policy Distillation）** 结合**显著词汇对齐（Salient Vocabulary Alignment, SVA）**，将各个教师的知识高效迁移到一个统一学生模型中，避免不同领域推理模式冲突。

#### 关键技术细节
- **长程知识-动作基础设施（KAG）**：
  - 构建领域特定的**知识-动作图（Knowledge-Action Graph, KAG）**，包含四元组：领域语料C、动作空间A、观察空间O、验证器集V。
  - 通过**自博弈图搜索与扩展**（提议者-求解者-验证者游戏）不断优化图质量，生成可验证、过程信息丰富的轨迹。
- **领域路由多教师蒸馏**：
  - 对于每个样本，根据其领域标签路由到相应教师。
  - **显著词汇对齐**：在教师选定的top-k有效词汇集合上计算反向KL散度，只约束学生在此显著集合上的分布，减少干扰。
  - **领域归一化目标**：对每个活跃领域内的样本损失取平均，再跨领域平均，防止高频领域主导更新。

#### 公式/算法流程（文字说明）
- 知识-动作图定义：\( G_d = (C_d, A_d, O_d, V_d) \)。
- 自博弈：\(\pi_P\)采样任务，\(\pi_S\)求解，\(\pi_V\)验证（需满足五条标准：可验证、有效、过程信息丰富、证据覆盖、无捷径）。
- 蒸馏损失：对每个样本，在学生生成的轨迹位置上，计算教师支持的top-k词汇上的截断反向KL散度。
- 总体损失：\( L_{MT-SVA} = \frac{1}{|D_B|} \sum_{d} \frac{1}{|B_d|} \sum_{i \in B_d} \ell_{SVA}^{(i)} \)。

1. **35B模型可达到万亿参数级性能**：Agents-A1在SEAL-0、IFBench、HiPhO、FS-O、MolBench-Bind上超越Kimi-K2.6和DeepSeek-V4-Pro；在BrowseComp、XBench、GAIA上高度接近或持平。

3. **全领域SFT存在领域冲突**：单一SFT会导致不同推理模式（如长思维 vs 多轮工具使用）相互干扰，表现下降。多教师蒸馏能有效缓解冲突。
4. **工具增强与推理增强可互相促进**：例如在科学研究任务中，工具使用能力提升有助于更好地利用外部资源，进而提升无工具推理能力。
5. **工程任务差距仍存**：在MLE-Bench-Lite和SciCode上，35B模型与万亿参数模型差距明显，表明完全工程流程要求更高的目标保持、记忆和探索能力。
