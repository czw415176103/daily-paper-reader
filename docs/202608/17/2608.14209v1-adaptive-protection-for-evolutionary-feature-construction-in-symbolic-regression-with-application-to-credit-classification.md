## 摘要
进化特征构建在符号回归中展现出强大的潜力，能够自动发现输入特征的信息性变换，从而增强简单基学习器的性能。然而，现有方法往往缺乏明确的机制来保护进化过程中发现的重要构建特征，当遗传算子破坏有效特征时，宝贵的遗传物质可能会丢失。本文提出了一种自适应保护机制，利用特征重要性度量在进化过程中选择性保留构建特征。该机制对更重要的构建特征提供更强的保护，同时仍允许较不重要的特征被修改，并从更重要的特征中整合有用的构建块。我们使用多种特征重要性计算方法评估了该方法，并证明了其在不同基学习器上的鲁棒性。在98个回归基准数据集上的实验结果表明，所提出的机制在解决方案质量上 consistently 优于基线方法，而在两个信用分类数据集上的实验表明，该方法也能有效推广到符号回归之外，提高搜索效果。

## Abstract
Evolutionary feature construction has shown strong promise in symbolic regression by automatically discovering informative transformations of input features that enhance a simple base learner. However, existing approaches often lack explicit mechanisms to preserve important constructed features discovered during evolution, and valuable genetic material can be lost when genetic operators disrupt effective features. This paper introduces an adaptive protection mechanism that leverages feature importance metrics to selectively preserve constructed features during evolution. The mechanism provides stronger protection for more important constructed features while still allowing less important features to be modified and to incorporate useful building blocks from more important features. We evaluate the approach using multiple feature importance calculation methods and demonstrate its robustness across different base learners. Experimental results on 98 regression benchmark datasets show that the proposed mechanism consistently improves solution quality over baseline approaches, and experiments on two credit classification datasets demonstrate that the method also extends effectively to improve search effectiveness beyond symbolic regression.

## 1. 论文的核心问题与整体含义

### 研究动机

- 符号回归（Symbolic Regression）旨在不预设函数形式的情况下，自动发现描述数据关系的数学表达式。
- 在符号回归的众多方法中，**基于进化特征构建（Evolutionary Feature Construction）** 的方法是一类重要分支：利用遗传规划（Genetic Programming, GP）演化出多个特征变换树，再将这些构造特征输入到简单基学习器（如岭回归、决策树、逻辑回归）中建立预测模型。
- 这类方法在回归和分类任务上已展现出较强的性能，但存在一个**核心缺陷**：进化过程中缺少显式机制来保护已经发现的重要构造特征。交叉（crossover）和变异（mutation）等遗传算子可能产生新特征组合，但也可能无意间破坏有价值的特征，导致宝贵的遗传材料（building blocks）丢失，从而降低解质量。

### 核心研究问题

- 如何在保持遗传算子探索能力的同时，有效保护进化过程中发现的重要特征？
- 能否设计一种**与具体遗传算子无关**的通用保护机制？

### 总体回答

本文提出一种**自适应保护机制（Adaptive Protection Mechanism, APM）**：利用特征重要性（Feature Importance）指标，为每个构造特征分配一个与重要性成正比的保护分数，在遗传操作之后按该分数选择性恢复（restore）高重要性的原始特征。重要性高的特征获得更强保护，重要性低的特征仍然可以自由修改或替换，从而在“保留有用构件”和“探索新组合”之间取得平衡。

## 2. 论文提出的方法论

### 核心思想

- 借鉴**精英主义（elitism）** 思想但比其更细化：不是保留整个个体，而是保留每个个体中最重要的**特征级构建块**。
- 保护力度与特征重要性成正比：`保护分数 sj = mprotect · Ĩj`，其中 Ĩj 为归一化特征重要性，mprotect 为保护系数。
- 该机制是**通用框架**，可以包裹在任何遗传算子（传统子树算子、语义算子、LLM-based交叉算子等）外层，无需重新设计算子本身。

### 算法流程（Algorithm 1: APM）

1. **保存原始树**：对个体中每个特征树 φj，保存当前状态作为原始版本（这些树本来就存储用于深度限制检查，无额外内存开销）。
2. **应用遗传操作**：对每个树执行交叉或变异，得到修改后的版本。
3. **归一化重要性**：计算每个树的归一化重要性 Ĩj ← |Ij| / Σ|Ij|。
4. **逐树判断恢复**：对每个树 j，采样 u ~ Uniform(0,1)，若 u < sj = mprotect · Ĩj，则将该树**恢复为原始状态**（即撤销遗传操作对该树的修改）；否则保留修改后的版本。

### 整体工作流（7个阶段）

1. **种群初始化**：ramped half-and-half 方法，每个个体包含 k=10 棵随机特征树。
2. **解评估**：基于构造特征训练基学习器，回归用 R²，分类用 AUC 作为适应度；损失向量用于 epsilon lexicase 选择。
3. **重要性计算**：根据基学习器类型选择不同的重要性度量（见下文）。
4. **父代选择**：epsilon lexicase selection，阈值由 MAD（中位数绝对偏差）确定。
5. **后代生成**：随机子树交叉/变异，可对多棵树多次调用。
6. **自适应保护**：如上算法所述。
7. **精英机制**：传统精英保留最优个体 + 保留 top-100 个体的集成归档用于最终预测（对随机决策树和逻辑回归使用，岭回归不用）。

### 三种特征重要性计算方法

1. **内置系数（Built-In）**
   - 岭回归/逻辑回归：重要性 = |βj|（特征已标准化，系数可反映贡献）
   - 随机决策树：按不纯度下降（impurity decrease）加权求和
   - 优势：计算开销几乎为零，复用已拟合模型
2. **SHAP值**：LinearSHAP 闭式解 βj(xij − E[Xj])，按实例取平均绝对值
   - 考虑了系数和特征分布，比单纯系数更全面，但计算较贵
3. **边际贡献（Marginal Contribution）**
   - 定义：IMC_j = R²_full − R²_−j（移除特征后重新拟合模型的 R² 下降量）
   - 模型无关、直观，但需每个特征额外拟合一次模型，计算成本最高
   - **缺陷**：特征高度相关时，移除一个特征可被其他特征补偿，导致低估其重要性

## 6. 论文的主要结论与发现

1. **RQ1（保护 vs 无保护）**：所有保护方法一致显著优于无保护基线。Built-In 在 56/98 个数据集上获胜且仅输 3 个；SHAP 在 60 个数据集上获胜且仅输 1 个。无保护时遗传操作对解的改变过于激进，严重损害搜索局部性（如案例中父代 R²=0.800 无保护降至 0.101，有保护提升至 0.814）。
2. **RQ2（自适应保护 vs 减少操作）**：自适应保护系统性优于简单减少遗传操作次数，说明保护的“选择性”比“一刀切削减变异”更有效。
3. **RQ3（重要性方法比较）**：三种方法预测性能总体相似（多数为统计持平），但 Built-In 在计算效率上优势显著。边际贡献在特征共线性严重时可能失效（相关特征相互补偿导致重要性低估）。
4. **RQ4（不同基学习器鲁棒性）**：以随机决策树为基学习器时，保护机制仍一致优于基线，说明其不依赖特定重要性度量类型。
5. **RQ5（信用分类迁移）**：训练 AUC 上保护方法优于所有基线，测试 AUC 与无保护持平、优于低操作率基线。保护在分类任务上**能提升搜索有效性**，但最终测试增益有限（论文归因于函数集可能不适合信用任务）。
6. **方法论发现**：重要性线性缩放（幂=1）最优，保护系数取 5 时效果最佳；确定性 Top-K 与概率性变体效果相当。

## 7. 优点

- **通用性强**：保护机制是操作器无关（operator-agnostic）的，可与任意遗传算子结合，不要求重新设计交叉/变异。
- **思路简洁有效**：只需在遗传操作前后保存/恢复树，几乎零额外内存开销；近似“特征级精英主义”，比个体级精英更精细。
- **保护粒度合理**：基于特征重要性进行软加权随机恢复，既保护高价值构件，又为低重要性特征保留探索空间，平衡性好。
- **多种重要性度量对比**：系统比较了系数、SHAP、边际贡献三种方法，实验设计严谨。
- **跨任务验证**：从 98 个回归基准扩展到信用分类，展示超出符号回归的泛化能力。
- **消融实验充分**：保护系数、幂变换、变体选择均有系统分析。
