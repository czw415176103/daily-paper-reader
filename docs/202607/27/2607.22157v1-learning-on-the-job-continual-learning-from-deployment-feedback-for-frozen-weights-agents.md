## 摘要
AI智能体在每一次运行中都会遇到学习机会，但几乎全部丢弃：底层模型在部署时被冻结，因此今天解决了一个困难请求的智能体，当明天再次出现时又得从零开始。然而，日常操作已经以结果判定和事后纠正的形式产生了反馈。我们证明，当冻结模型与一个将每个回合提炼为可检索的自然语言规则的外部记忆配对时，这种反馈是持续学习的充分信号。在τ-bench的银行业务领域，与检索完整政策语料的静态RAG对照组相比，从单比特结果判定中学习将单次尝试成功率提升至基线的1.6倍，从纠正中学习提升至2.6倍，并将基线从未解决的84个任务中的22个转化为可解。该结果跨越了部署光谱，在Mistral Large（一种有数据主权需求的组织可自行托管的开放权重模型）上测量，并在前沿模型Claude Sonnet 5上进行了复现。累积的记忆也具有可迁移性：每个模型读取由另一个模型构建的存储后，都超越了自身无记忆的基线。我们还发布了相关工具、协议和数据。

## Abstract
AI agents encounter learning opportunities in every episode they run, and discard nearly all of them: the underlying models are frozen at deployment, so an agent that resolves a difficult request today starts from zero when it recurs tomorrow. Yet ordinary operation already produces feedback, in the form of outcome verdicts and after-the-fact corrections. We show that this feedback is a sufficient signal for continual learning when the frozen model is paired with an external memory that distils each episode into retrievable natural-language rules. On the banking domain of $τ$-bench, against a static-RAG control retrieving over the complete policy corpus, learning from the one-bit outcome verdict lifts single-trial success to 1.6$\times$ the baseline, and learning from corrections to 2.6$\times$, converting 22 of the 84 tasks the baseline never solves. The result spans the deployment spectrum, measured on Mistral Large, an open-weights model that organisations with data sovereignty requirements can self-host, and replicated on a frontier model, Claude Sonnet 5. The accumulated memory also transfers: each model, reading the store built by the other, rises above its own no-memory baseline. The harness, protocol, and data are released.

## 论文详细总结（自动生成）

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：当前部署的 AI 智能体（agent）的模型权重在部署后完全冻结，导致系统无法从每天运行中产生的海量反馈中学习。例如，今天成功解决一个困难客户请求的 agent，明天遇到同样的请求时又得从零开始。  
- **整体含义**：日常操作本身就产出反馈信号（例如结果判决：任务是否成功；事后纠正：人工提供了正确的解决方案），但这些信号被完全丢弃。本文研究能否利用这些现成的反馈信号，让冻结权重的 agent 通过一个外部记忆系统持续改进性能，而无需更新模型权重（避免重训练成本和灾难性遗忘风险）。

### 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：将冻结权重的 LLM 与一个外部自然语言记忆系统（Spark）配对。每个回合结束后，agent 将经验蒸馏为一条可检索的自然语言规则（insight）存入记忆，后续回合通过检索这些规则来指导行动。学习完全由部署反馈驱动，无需梯度更新。  
- **关键技术细节**：
  - **记忆单元**：每条记忆包含标题、内容、检索查询（以问题形式）和可选的标签。  
  - **反馈信号**两种等级：
    - **结果判决（verdict）**：0/1 单比特，仅告知最终状态是否匹配正确结果。agent 必须自己从对话和该比特中提炼教训，失败时只能记录回避建议，不可推断正确动作。
    - **纠正（correction）**：失败回合后，agent 额外获得验证正确的完整动作序列，可以写出确切的规则。
  - **读路径**：由 agent 自主调用 `memory_search` 检索，记忆工具作为环境的 first-class 工具集成。每个回合第一次客户消息会插入提示，指导 agent 在关键决策前搜索记忆。
  - **写路径**：仅在回合结束后（reflection 阶段）执行，防止中途写入错误信息。写入时有严格约束：保持“WHEN-THEN”形式、决策关键值必须原样、不得削弱已有已验证规则等。写入后经过异步自动养护流水线（安全过滤、质量门禁、去重、冲突解决）。
  - **学习流程**：空记忆开始 → 冷启动（首轮无记忆帮助）→ 每轮结束后根据反馈写入一条规则 → 后续轮次检索执行 → 记忆持续累积。

### 3. 实验设计：数据集/场景、基准、对比方法

- **基准和数据集**：使用 τ-bench 的银行领域（banking domain），97 个任务，每个任务是多轮客服对话，agent 需检索约 700 个政策文档（BM25 稀疏检索）。任务的正确结果由预计算的地面真值程序化评估，大多数无需 LLM 判断。
- **对比条件**（均为静态 RAG 控制）：
  - **基线（No-memory baseline）**：标准 τ-bench agent，检索全部政策文档，但无跨试次记忆。
  - **经验（Experience）**：从结果判决单比特信号学习，仅能记录回避规则。
  - **指令（Instruction）**：从事后纠正（完整正确动作）学习，可记录确切规则。
- **额外实验**：跨模型记忆转移——将指令条件下一个模型构建的冻结记忆存储交给另一个模型只读使用，测试知识是否可迁移。
- **模型**：Mistral Large（版本 2512，开放权重）和 Claude Sonnet 5（前沿模型）。客户模拟器为 GPT-5.2。

### 6. 论文的主要结论与发现

- **部署反馈足够的持续学习信号**：从单比特结果判决学习使单试次成功率升至基线 1.6 倍；从事后纠正学习升至 2.6 倍。在 Mistral Large 上，指令模式将基线从未解决的 84 个任务中的 22 个转化为可解。
- **结果在更强模型上复现**：Claude Sonnet 5 上指令模式将 pass¹ 从 0.248 提升至 0.397，同样解决了大量基线失败任务。
- **记忆可跨模型转移**：每个模型读取另一个模型构建的冻结存储后表现均超过自身无记忆基线。例如 Mistral Large 读取 Sonnet 存储后 pass¹ 从 0.064 升至 0.289。转移在双向均有效，且弱模型的经验对强模型也有帮助。
- **记忆保持率**：经验模式保持率 0.88（但转化任务少），指令模式保持率 0.65（但转化任务多）。保持率高于基线随机再绘制的持久性。

### 7. 优点

- **方法创新**：利用已有部署反馈（无需额外标注），通过外部记忆实现持续学习，避免模型权重更新带来的灾难性遗忘和重新评估成本。
- **实验严谨**：对比静态 RAG 控制（已检索全部文档），消除知识库差异的影响；使用 pass^k、每轮成功率、保持率、分层分析（按基线可解性）等多维度度量。
- **跨模型验证**：覆盖开放权重模型和前沿模型，增强结论通用性。
- **记忆可迁移性**：展示了知识作为组织资产可跨模型共享，具有较强的实用价值。
- **开放发布**：释放了工具、协议和数据，便于复现和扩展。

### 8. 不足与局限

- **单次运行**：每个实验配置仅运行一次，未估计运行间方差（虽然作者认为任务间耦合弱，但仍有风险）。
- **反馈噪声理想化**：实验中使用完美评估器提供无噪声反馈信号，但实际部署中反馈可能延迟、缺失或错误。论文指出噪声鲁棒性超出范围，是未来工作。
- **领域和模型覆盖有限**：仅一个领域（银行）和两个模型。经验模式仅在 Mistral 上测试；扩到更强模型上可能表现更好，但未验证。
- **pass^4 指标解释限制**：在持续学习设置下，pass^4（所有四次均通过）会掩盖学习带来的进步，因为首次失败后成功的情况在 pass^4 中计为 0。作者承认这一点并用保持率补充。
- **跨任务耦合**：试次采用大轮次调度（所有任务第一轮后再第二轮），但后任务的冷启动可能已受前任务记忆影响，作者认为影响很小。
- **记忆可能干扰已解任务**：虽然观察到的干扰很小，但写入的不精确规则有可能误导 agent，需要更多机制保证。
