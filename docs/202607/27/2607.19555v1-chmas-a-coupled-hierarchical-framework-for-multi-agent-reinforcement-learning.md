## 摘要
多智能体强化学习系统在平衡全局协调与局部执行方面面临跨不同时间尺度的根本性挑战。本文提出了耦合分层多智能体系统（CHMAS），这是一种新颖的框架，将多智能体决策分解为集中式战略规划和分布式战术执行，并具有双向信息流。战略层整合所有智能体的状态与独占的全局环境状态，每T个时间步生成引导动作，而战术智能体执行由战略引导和局部邻域观测增强的分布式策略。与现有单向控制的分层方法不同，CHMAS建立了一种反馈机制，其中累积的战术奖励通过耦合系数λ影响战略目标，确保战略计划始终基于战术可行性。为了解决分层学习固有的非平稳性，我们提出了一种异步更新协议，其中战略参数每N_f个战术回合更新一次，使得战术策略能够在战略变化之间收敛到准平稳点。我们提出了一个捕获完整系统动态的通用双层公式，以及一个可处理的加性近似，从而能够进行严格分析。理论分析证明，在标准假设下，这种异步方案在K次战略更新后，战略层实现了O(log K/√K)的收敛。在多智能体觅食领域的实验验证表明，成功地学习了空间划分的探索策略，尽管存在分层耦合，但两层均稳定收敛。

## Abstract
Multi-agent reinforcement learning (MARL) systems face fundamental   challenges in balancing global coordination with local execution   across different temporal scales. This paper introduces the Coupled   Hierarchical Multi-Agent System (CHMAS), a novel framework that   decomposes multi-agent decision-making into centralized strategic   planning and distributed tactical execution with bidirectional   information flow. The strategic layer integrates all agents' states   with an exclusive global environmental state to generate guidance   actions every $T$ timesteps, while tactical agents execute   distributed policies augmented by strategic guidance and local   neighborhood observations. Unlike existing hierarchical approaches   with unidirectional control, CHMAS establishes a feedback mechanism   where accumulated tactical rewards influence strategic objectives   through a coupling coefficient $λ$, ensuring strategic plans   remain grounded in tactical feasibility. To address the   non-stationarity inherent in hierarchical learning, we propose an   asynchronous update protocol where strategic parameters update every   $N_f$ tactical episodes, allowing tactical policies to converge to   quasi-stationary points between strategic changes. We present both a   general bi-level formulation capturing full system dynamics and a   tractable additive approximation enabling rigorous analysis.   Theoretical analysis proves that this asynchronous scheme achieves   $\mathcal{O}(\log K/\sqrt{K})$ convergence for the strategic layer   after $K$ strategic updates under standard assumptions. Experimental   validation in a multi-agent foraging domain demonstrates successful   learning of spatially partitioned exploration strategies, with both   layers converging stably despite hierarchical coupling.

# 论文总结：CHMAS: A Coupled Hierarchical Framework for Multi-Agent Reinforcement Learning

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：多智能体强化学习（MARL）在平衡全局协调与局部执行时面临跨时间尺度的挑战。纯集中式方法因维度灾难不可扩展，纯分布式方法牺牲长期目标协调。现有分层MARL（如FeUdal Networks、option-critic）多为**单向控制**（高层→低层），缺乏战术层对战略层的反馈，导致战略计划可能脱离实际执行可行性。
- **背景**：信息不对称（全局环境状态 vs 局部观测）、非平稳性（战略变化改变战术层环境）、时间抽象（战略决策周期长，战术决策需快速响应）是核心困难。
- **整体含义**：提出**双向耦合分层框架CHMAS**，通过战略层与战术层之间的**双向信息流**（向下指导 + 向上奖励反馈），并设计异步更新协议管理非平稳性，实现稳定分层学习。

## 2. 方法论：核心思想、关键技术细节、公式/算法流程

### 核心思想
- **双层决策结构**：
  - **战略层**（全局）：每 \(T\) 个时间步，访问完整状态 \(\mathbf{s}^{\text{str}} = (s^{\text{env}}, s_1, \dots, s_N)\)（包括独占的全局环境状态 \(s^{\text{env}}\)），生成指导动作 \(\mathbf{a}^{\text{str}}_k\) 广播给所有智能体，持续 \(T\) 步。
  - **战术层**（分布式）：每个智能体 \(i\) 基于观测 \(o^{\text{tac}}_{i,t} = \phi_i(s_{i,t}, \{s_{j,t}\}_{j\in\mathcal{N}_i}, a^{\text{str}}_{i,k})\) 执行本地策略，奖励包含局部收集、区域合规等。
- **双向耦合**：
  - **向下耦合**：战略指导通过观测增强、奖励调制影响战术行为。
  - **向上耦合**：战术累积奖励 \(R^{\text{tac}}_k = \sum_{t=iT}^{(k+1)T-1}\sum_i r^{\text{tac}}_{i,t}\) 通过**耦合系数 \(\lambda\)** 加入战略奖励 \(R^{\text{str}}_k = R^{\text{global}}_k + \lambda R^{\text{tac}}_k\)，使战略计划尊重战术可行性。
- **非平稳性管理**：异步更新协议，战略参数**每 \(N_f\) 个战术回合**更新一次（步长 \(\eta^{\text{str}}_k = \alpha/\sqrt{k}\)），内部战术层在固定战略下收敛到准平稳点。

### 关键技术细节
- **问题形式化**：
  - 一般耦合双层问题：\(\max_{\theta^{\text{str}}} J^{\text{str}}(\theta^{\text{str}} \mid \{\theta^{\text{tac}*}_i(\theta^{\text{str}})\})\)，约束 \(\theta^{\text{tac}*}_i = \arg\max J^{\text{tac}}_i(\theta^{\text{tac}}_i \mid \theta^{\text{str}})\)。
  - **加性近似**：\(J^{\text{global}} = J^{\text{str}} + \sum_i J^{\text{tac}}_i\)，将耦合问题转化为坐标梯度更新。
- **算法流程（AHPG）**：
  1. 每个新战略时段（episode % \(N_f = 1\)）：观察全局状态，采样指导动作，广播。
  2. 战术执行阶段：\(T\) 步内各智能体并行收集经验。
  3. 战术更新（每 episode）：各智能体独立计算梯度更新（分布式）。
  4. 战略更新（每 \(N_f\) episodes）：聚合战术奖励，计算战略梯度，以 \(\alpha/\sqrt{k}\) 步长更新。
- **理论收敛**：在平滑性、PL条件、有界方差等假设下，战略层梯度范数期望 \(\min_k \mathbb{E}[\|\nabla J^{\text{str}}\|^2] = \mathcal{O}(\log K/\sqrt{K})\)，战术层平均梯度范数 \(\mathcal{O}(1/\sqrt{K})\)。

## 3. 实验设计

  - 战略动作：为每个智能体指定 \(9\times 9\) 区域中心（\(a^{\text{str}}_i = (gx_i, gy_i) \in [4,20]^2\)）。

- **任务**：最大化全局覆盖（新访问单元奖励）同时收集资源，战术层需遵守区域约束。

## 6. 论文的主要结论与发现

- CHMAS框架在4智能体GridWorld觅食任务中成功学习**空间分区探索策略**：战略层学会分配不重叠的区域，战术层在区域内高效收集资源，并通过\(T=5\)步的指导实现协调。
- 双向耦合（\(\lambda=0.5\)）使战略回报显著改善（从约-10到15），战术层从约-80到-10，表明战术反馈有助于战略计划落地。
- 异步更新（\(N_f=5\)）使战术策略能在战略变化间稳定收敛，避免非平稳崩溃；理论收敛界得到定性验证。

## 7. 优点

- **创新性**：首次系统性地提出分层MARL中的**双向耦合**机制，向上反馈使战略层感知执行代价，更具现实意义。
- **理论严谨**：提供了双层优化的加性近似和异步更新的收敛性证明（\(\mathcal{O}(\log K/\sqrt{K})\)），这在分层MARL中较少见。
- **算法设计**：异步更新协议 + 逐渐衰减步长有效管理非平稳性，且分布式战术更新保持可扩展性。
- **信息不对称设计**：战略层独占全局环境状态，战术层仅局部+指导，符合真实多智能体系统约束。

## 8. 不足与局限
