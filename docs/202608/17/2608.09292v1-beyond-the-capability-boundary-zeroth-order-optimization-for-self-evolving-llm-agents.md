## 摘要
自进化方法通过从底层LLM中采样轨迹并从这些轨迹中学习来提升LLM智能体的能力。然而，这些方法难以学习超越智能体固有能力边界的内容，因为智能体无法在困难示例上采样正确的轨迹以进一步改进。在本文中，我们提出了一种零阶自进化框架，通过扰动LLM参数以适应困难示例，无需任何轨迹标注，使智能体能够学习超越其能力边界。具体来说，我们扰动LLM的LoRA参数，运行智能体，计算在扰动和原始参数下的损失，并利用损失差来估计梯度，进而更新LoRA参数。我们使用更新后的LLM采样轨迹进行监督微调，以突破智能体的能力边界，形成闭环的自进化循环。我们引入了并行扰动推理机制和自适应查找机制，以减少零阶优化中的时间消耗，并采用答案困惑度损失，提供平滑稳定的零阶损失值。在多个深度研究基准上的实验表明，我们的方法获得了显著更多的成功轨迹，并且持续优于强基线，尤其是在困难示例上。代码和发布的工件可在https://github.com/hidk1911/ZOForLLMAgents获取。

## Abstract
Self-evolving methods improve the capabilities of LLM agents by sampling trajectories from the underlying LLMs and learning from these trajectories. However, these methods struggle to learn beyond the inherent capability boundary of the agents, since the agents cannot sample correct trajectories on difficult examples for further improvements. In this paper, we propose a zeroth-order self-evolution framework that enables agents to learn beyond their capability boundary by perturbing LLM parameters to adapt to difficult examples without any trajectory annotations. Specifically, we perturb LoRA parameters of LLMs, run the agent, compute the losses under the perturbed and original parameters, and use the loss difference to estimate gradients and further update the LoRA parameters. We sample trajectories using the updated LLMs for supervised fine-tuning to break through the capability boundary of the agents, forming a closed self-evolution loop. We introduce a parallel perturbation inference mechanism and an adaptive lookup mechanism to reduce time consumption in zeroth-order optimization, with an answer perplexity loss that provides smooth and stable zeroth-order loss values. Experiments on multiple deep research benchmarks show that our method obtains substantially more successful trajectories and consistently outperforms strong baselines, especially on difficult examples. The code and released artifacts are available at https://github.com/hidk1911/ZOForLLMAgents.

## 2. 论文提出的方法论

### 核心思想
- 利用**查询-答案对（QA pairs）** 作为唯一监督信号，不依赖中间推理轨迹标注。
- 为每个困难实例附加**实例专属 LoRA 模块**，通过零阶优化（Zeroth-Order Optimization, ZO）在参数空间中搜索能够降低答案损失的 LoRA 参数。
- 优化后的智能体能够生成成功轨迹，这些轨迹被收集起来用于后续 SFT，推动智能体整体能力提升。

### 关键技术细节与算法流程
1. **实例级 LoRA 优化**：
   - 对实例 `(q_i, y_i)`，定义 LoRA 参数 `w_i = [A_i, B_i]`。
   - 采样 K 个随机扰动方向，构建扰动参数：`θ_{i,k} = θ + (B_i + σ ε_{B_i,k})(A_i + σ ε_{A_i,k})`（式 10）。
   - 扰动策略与环境交互生成完整轨迹 `τ_{i,k}`（式 11）。
   - 计算扰动损失 `ℓ⁺_{i,k}`（式 12）和未扰动基线损失 `ℓ⁰_i`（式 13）。
   - 用损失差构造零阶梯度估计（式 14）：
     ```
     ĝ(A_i) = (1/BK) Σ Σ [(ℓ⁺_{i,k} − ℓ⁰_i)/σ] · ε_{A_i,k}
     ĝ(B_i) = (1/BK) Σ Σ [(ℓ⁺_{i,k} − ℓ⁰_i)/σ] · ε_{B_i,k}
     ```
   - 使用 Adam 更新 LoRA 参数。

2. **并行扰动推理机制（Parallel Perturbation Inference）**：
   - 利用 LoRA 的低秩结构：不同扰动分支共享同一主干的输出 `θx`，只需计算一次。
   - 并行计算各分支的 LoRA 增量 `(B + ε_B)(A + ε_A)x`，再加回共享的 `θx`。
   - 将采样时间从线性增长降为近似单次前向 + 轻量并行计算。

3. **自适应查找机制（Adaptive Lookup Mechanism）**：
   - 维护一个工具调用结果缓存池。
   - 对 search 操作使用语义相似度匹配（处理表面变体），对 visit 操作使用 URL + 访问目标严格匹配。
   - 命中缓存的请求直接复用结果，未命中的才执行外部调用并注册进缓存。
   - 减少多扰动 rollout 中的重复工具调用，显著压缩时间成本。

4. **答案困惑度损失（Answer Perplexity Loss）**：
   - 给定轨迹 `τ` 和真实答案 `y`，将轨迹中生成的答案替换为真实答案，计算该答案在轨迹条件下的负对数似然（式 16）：
     ```
     ℓ_ans(θ; q, τ, y) = −(1/M) Σ_{j=1}^M log π_θ(y_j | q, τ_{\ans}, y_{<j})
     ```
   - 相比二值奖励或 BERT 相似度，该损失提供了更平滑、更可分的密集信号；即使轨迹错误，若检索到的证据能提高真实答案概率，也能获得正向反馈。

5. **闭环自进化流程**：
   - 零阶优化 → 用优化后智能体采样轨迹 → 筛选低损失/正确轨迹入 buffer → SFT 更新共享模型 → 重复上述过程（如图 2 所示）。

- **零阶自进化有效**：在 GAIA 和 WebWalkerQA 上，Qwen-3-8B 配置下 GAIA 平均准确率从 ReAct 的 23.3% 提升至 47.5%（Ours-SFT），WebWalkerQA 从 15.5% 提升至 34.8%，大幅超越现有训练型深度研究智能体（如 ARPO 的 38.8%）。

- **责任与风险**：强化后的 agent 可能在真实环境中检索并传播不准确信息，或过度依赖外部网页内容；作者已在附录中说明将进行过滤，但并未在论文中展示具体过滤流程或样例审查结果。
