## 摘要
在最优控制、不确定性量化和反问题中，需要针对许多参数值反复求解参数化偏微分方程（PDE），而经典离散化方法往往难以实现。本章介绍降阶建模（ROM），它为参数化解集构建压缩而精确的表示，以实现快速在线评估。我们将参数化PDE的近似视为一个监督学习任务，并回顾了线性近似方法（对椭圆和抛物问题非常有效），然后转向在解表现出不连续或陡峭梯度时所需的非线性方法。接着，我们展示如何使用降阶模型从有限的测量中高效地恢复物理系统的状态，这是一个称为状态估计的反问题。自始至终，我们偏向于具有理论保证的结果，同时也讨论实用方法，并提供一个配套的Jupyter笔记本实现主要算法。

## Abstract
Solving parametric partial differential equations (PDEs) repeatedly for many parameter values,as needed in optimal control, uncertainty quantification, and inverse problems, is often prohibitive with classical discretizations. This chapter introduces Reduced Order Modeling (ROM), which builds compressed yet accurate representations of parametric solution sets for fast online evaluation. We formulate the approximation of parametric PDEs as a supervised learning task and review linear approximation, very effective for elliptic and parabolic problems, before turning to nonlinear methods needed when solutions exhibit discontinuities or steep gradients. We then show how to use reduced-order models to efficiently recover the state of a physical system from limited measurements, which is an inverse problem known as state estimation. Throughout, we favor results with theoretical guarantees while also discussing practical methods, and provide a companion Jupyter notebook implementing the main algorithms.
