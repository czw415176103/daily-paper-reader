## 摘要
强化学习（RL）用于搜索代理通常依赖于结果奖励。然而，由于中间步骤的价值不明确，它往往无法实现有效的信用分配。很难将它们的贡献与最终结果分开。在本文中，我们提出了一种基于事实效用估计的密集过程监督方法，该方法将推理过程建模为离散证据事实的累积。我们首先从原始观察中提取结构化事实，并将其组织成显式事实存储。为了支持信用分配，我们然后对语义等价的事实进行聚类，并使用贝叶斯估计在组滚动上推断每个事实聚类的后验效用。最后，我们将估计的事实效用转换为密集的步骤级奖励以指导 RL 训练。在七个单跳和多跳 QA 基准上的实验表明，我们的方法始终优于现有基线。消融研究验证了与仅结果奖励训练相比，在多跳 QA 上的明显相对改进。

## Abstract
Reinforcement learning (RL) for search agents typically relies on outcome rewards. However, it often fails to achieve effective credit assignment, due to the unclear value of intermediate steps. It is hard to separate their contributions from the final result. In this paper, we propose a dense process supervision method based on fact utility estimation, which models the reasoning process as the accumulation of discrete evidence facts. We first extract structured facts from raw observations and organize them into an explicit fact store. To support credit assignment, we then cluster semantically equivalent facts and infer the posterior utility of each fact cluster using Bayesian estimation over group rollouts. Finally, we convert the estimated fact utilities into dense step-level rewards to guide RL training. Experiments on seven single-hop and multi-hop QA benchmarks show that our method consistently outperforms existing baselines. Ablation studies validate clear relative improvements on multi-hop QA compared to outcome reward-only training.

# 论文总结：Dense Process Supervision for Search Agents via Fact Utility Estimation

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：搜索智能体（Search Agent）在复杂多步信息获取任务中的强化学习（RL）训练普遍依赖稀疏的最终结果奖励（outcome reward），导致**信用分配（credit assignment）困难**——中间步骤（如搜索、断言）的价值无法被有效评估，正确最终答案并不意味着每个检索证据都是必要的，失败的轨迹也不代表所有中间步骤都无效。
- **研究背景**：LLM 智能体在实时信息搜集（如 Deep Research 类系统）中表现突出，但其训练通常采用 GRPO 等基于组内相对优势的 RL 算法，仅以最终答案正确性作为奖励信号。这种信号稀疏、延迟且缺乏细粒度，难以指导智能体学会高质量的信息搜索与筛选。
- **核心思路**：将中间证据显式建模为离散的结构化事实（fact），并估计每个事实或语义等价事实簇对最终成功率的“效用”，从而将稀疏的结果奖励转化为密集的步骤级过程奖励，实现更有效的信用分配。
- **整体意义**：提出了一种无需外部奖励模型的、直接从组内 rollout 统计中提取密集过程监督信号的通用方法，可显著增强搜索智能体的多步推理与检索能力。

## 2. 论文提出的方法论

本文提出 **FactAgent** 框架，核心由三部分组成：

### 2.1 FactAgent 框架（事实中心化智能体）

- 与标准 ReAct 智能体将原始文本历史作为隐式记忆不同，FactAgent 维护一个显式的**事实库（fact store）F**，作为工作记忆。
- 动作空间包含三类动作：
  - **search**：生成查询并获得新的观察结果 `o_t`（仅保留最近一次观察，避免上下文无限增长）；
  - **assert**：从观察结果中提取结构化事实三元组（subject, relation, object），写入事实库，并附带简短摘要；
  - **answer**：基于问题和事实库输出最终答案，终止回合。
- 状态定义为 `s_t = (Q, o_t, F_t)`，其中 `F_t` 是累计事实集合，使输入长度在长期交互中保持近似恒定。
- 论文在附录 A 中给出了理论分析，证明在“语义充分性”假设下，事实库是历史交互的充分统计量，满足 Markov 性质且有最优策略等价性保证。

### 2.2 事实效用估计（Fact Utility Estimation）

- 每条轨迹 `τ` 的中间知识可以汇总为一组语义事实 `F(τ)`。
- 理想情况下希望估计每个事实 f 对成功的贡献 `v(f) ≈ Pr(R=1 | f)`，但自然语言事实空间极度稀疏，单个事实在 GRPO 组中通常只出现一次，无法可靠估计。
- 因此做**语义聚类**：将语义等价的事实（如“A born in New York”和“A originates from New York City”）聚合为事实簇 `C_k`。
- 聚类采用两阶段策略：
  1. **粗粒度**：嵌入（embedding）余弦相似度阈值（0.95）筛选候选等价对；
  2. **细粒度**：规则过滤（negation consistency、numeric consistency、relation-level similarity），并做双向主语/宾语交换检验以避免结构倒装导致的误分类。
- 针对每个事实簇 `C_k`，定义其效用为潜在的成功概率 `θ_k`，采用**贝叶斯估计**：
  - 先验：`θ_k ~ Beta(ϵ, ϵ)`（ϵ=0.5）
  - 给定组内 rollout 统计，后验为：
    \[
    θ_k | S(C_k), N(C_k) \sim \text{Beta}(S(C_k)+\epsilon, N(C_k)-S(C_k)+\epsilon)
    \]
  - 以后验均值作为稳定估计：
    \[
    P(C_k) = \frac{S(C_k)+\epsilon}{N(C_k)+2\epsilon}
    \]
  - 相对效用：`V(C_k) = P(C_k) − P̄_group`（与组均值比较）
- 通过**基于势函数的奖励塑形（PBRS）** 将簇效用转化为步骤级奖励：
  - 势函数：`Φ(s_t) = tanh(Σ_{C∈U_t} V(C))`，`U_t` 是当前事实库覆盖的唯一簇集合；
  - 过程奖励：`r_t^shape = ΔΦ_t = Φ(s_t) − Φ(s_{t-1})`，仅当新语义信息被添加时非零。

### 2.3 信用分配与 RL 训练

- **奖励再分配**：将 assert 步骤获得的势能收益部分（α=0.2）回溯到之前引导出该事实的搜索步骤，从而鼓励生成高质量搜索查询。
- **辅助惩罚**：对格式违规、重复搜索、空事实库下过早回答等行为施加过程惩罚；空事实库回答时强制设置终端奖励为 0。
- **总优势函数**：
  \[
  A_{i,j}^{total} = A_{i}^{outcome} + \Omega \cdot r_{i,j}^{proc}
  \]
  其中 Ω=0.5，`A_outcome` 为 GRPO 中标准组归一化结果优势。
- 训练采用步级（step-level）的 GRPO 变体，对每个动作分别计算重要性采样比率与截断代理目标，外加 KL 惩罚。

## 6. 论文的主要结论与发现

- **密集过程监督有效**：FactAgent 在 7B 骨干上平均 EM 达到 **51.2**，超过最强基线约 **+3.2 EM**；3B 骨干上同样一致领先（45.4 vs. 44.3）。
- **多跳任务收益更大**：相对纯结果奖励训练（只保留全局结果优势），去除密集过程奖励导致平均 EM 从 51.2 降到 40.5，说明该方法是核心组件，尤其在多跳推理中作用显著。
- **事实库带来效率收益**：输入 token 长度在 8 轮交互后仍近似恒定，而 ReAct 输入长度约为 FactAgent 的 **4 倍**，在长轨迹推理中具备显著扩展性。
- **过程奖励进一步提升事实覆盖率**：训练中参考三元组召回率相对初始提升约 40%，而纯结果奖励基线无明显上升，说明过程监督有效优化了智能体的信息提取行为。
- **SFT 冷启动不作为性能上限保障**：SFT 主要起到训练稳定性和格式锚定作用，不提升最终表现上限。
- **效用分布高度集中**：前三名事实簇即覆盖 93% 以上的总效用质量，支持“成功轨迹依赖少数高价值证据事实”的设计假设。

## 7. 优点

1. **思想创新性强**：将中间证据建模为结构化事实，通过统计事实簇与成功结果的关联而非训练奖励模型，用贝叶斯方法做稠密过程监督，是一种轻量且无外部标注依赖的方案。
2. **理论有据**：附录给出了事实库作为状态抽象时的 Markov 性质与策略最优性保持证明，为方法提供了扎实基础。
3. **工程效率设计巧妙**：仅保留最近观察 + 显式事实库，使上下文长度不随交互数线性增长，解决 ReAct 类方法的上下文爆炸问题。
4. **信用分配粒度细致**：将 assert 步骤的势函数收益回溯到前置 search 动作（α=0.2），缓解时间滞后带来的信用错配。
5. **Anti-hacking 设计**：采用去重聚类避免冗余表述制造虚假的势能增益；tanh 限制势能范围改善稳定性；空事实库回答强制零奖励，保证答案需基于显式证据。
6. **多组分析全面**：从输入效率、事实覆盖率、冷启动训练动力学、Ω敏感性、训练成本等多角度做了实验分析，对方法行为有较深入刻画。

## 8. 不足与局限

1. **训练开销较高**：恢复交互上下文并计算每个步骤的更新，相对于仅结果奖励的方案 GPU 内存消耗更大（平均每步训练时间高约 2.6%左右，但主要成本在内存/轨迹存储）。
2. **效用估计依赖聚类质量**：论文自述聚类算法质量以及 GRPO 组 rollout 的充分性会影响效用估计的准确性；语义聚类的边界情形（逐字/数字差异、否定表达）仍然存在误差风险。
3. **评估只覆盖静态 QA**：尚未验证在动态、开放式 agent 任务（GAIA、BrowseComp 等）上是否有效；对于真实生产搜索环境（网页噪声多、广告多、格式复杂）的适应性未检验。
4. **组规模受限**：默认 rollout_n=6，贝叶斯平滑（Beta 先验）只是缓解而非解决小组样本下的高方差问题；扩大组数有额外成本且论文显示 8 个 rollouts 时收益已趋饱和。
5. **与基线检索条件不对等**：Zerosearch、ReSearch 使用真实 Google Search，而 FactAgent 用自己的本地检索索引。作者说明在更受限条件下仍胜出，但无法完全排除“较强的本地检索器/索引质量差异”对比较公平性的影响。
6. **未报告多次随机种子的方差**：实验结果缺少统计显著性检验，不能完全排除结果的偶然性。
7. **SFT 冷启动的 SFT 数据用“rejection sampling”**：对轨迹质量的筛选标准和成本有依赖，且论文指出 SFT 对性能不提升，仅对训练稳定性有作用，读者需要自行判断是否值得投入该阶段。
8. **事实抽取依赖 LLM 的 assert 动作质量**：低质量骨干模型在早期容易被“结构化输出格式”拖累，论文也承认直接 RL 可能偶尔出现 JSON 崩溃现象。
