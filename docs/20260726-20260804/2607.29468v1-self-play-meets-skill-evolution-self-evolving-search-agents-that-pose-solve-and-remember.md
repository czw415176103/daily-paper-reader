## 摘要
自我对弈智能体可以在没有目标基准问题的情况下生成训练问题，但它们的课程缺乏持久状态：失败会影响梯度，却不会明确塑造未来的练习。外部技能记忆保留程序性经验，但通常从固定的任务分布中学习。我们引入了\textbf{SESA}（自我进化技能增强智能体），它将程序性记忆变为工具增强搜索自我对弈的演化状态。挑战者提出问题，而单独参数化的求解器仅检索技能。有信息量的失败被提炼为可复用技能并写回记忆。更新后的记忆改变求解器行为和成功率，进而改变挑战者的奖励和未来问题的分布；由此产生的前沿产生新失败，从而重写记忆。这种双向循环使任务生成和技能记忆共同演化。由于检索到的技能塑造在线策略训练轨迹，其益处既能进入模型参数，也能保留在外部库中，从而支持无记忆部署和可选的推理时检索。在七个开放域和多跳问答基准上，SESA在多个骨干网络上比SSP平均准确率提高1.2–3.2个百分点，并在统一评估协议下比技能增强的SkillRL基线提高0.9个百分点。在Qwen3模型上，SESA-Off相比SSP保留了1.8–2.2个百分点的提升，而最终技能库进一步增加0.5–1.0个百分点。这些结果表明，演化技能记忆不仅仅是推理时的插件：它改变策略学习和未来训练分布，同时保留作为可选外部记忆的价值。我们的代码可在https://github.com/Zenghuang-Fu/SESA-Self-Evolving-Search-Agents获取。

## Abstract
Self-play agents can generate training problems without questions from target benchmarks, but their curricula lack persistent state: failures affect gradients yet do not explicitly shape future practice. External skill memories preserve procedural experience but are typically learned from fixed task distributions. We introduce \textbf{SESA} (Self-Evolving Skill-Augmented Agent), which makes procedural memory an evolving state of tool-augmented search self-play. A challenger poses problems, while a separately parameterized solver alone retrieves skills. Informative failures are distilled into reusable skills and written back to memory. The updated memory changes solver behavior and success, which changes the challenger's reward and the distribution of future problems; the resulting frontier produces new failures that rewrite memory. This bidirectional loop makes task generation and skill memory co-evolve. Because retrieved skills shape on-policy training trajectories, their benefits can enter the model parameters as well as remain in the external bank, enabling memory-free deployment and optional inference-time retrieval. Across seven open-domain and multi-hop question-answering benchmarks, SESA improves average accuracy over SSP by 1.2--3.2 points across multiple backbones and surpasses the skill-augmented SkillRL baseline by 0.9 points under a unified evaluation protocol. On Qwen3 models, SESA-Off retains 1.8--2.2 points of improvement over SSP, while the final skill bank adds a further 0.5--1.0 points. These results show that evolving skill memory is not merely an inference-time plug-in: it changes policy learning and the future training distribution while retaining value as optional external memory. Our code is available at https://github.com/Zenghuang-Fu/SESA-Self-Evolving-Search-Agents.

## 1. 核心问题与研究动机

- **背景问题**：当前 LLM 智能体训练存在两条互补路线，但各有缺陷：
  - **自我对弈（Self-Play）**：智能体可自主出题并求解（如 SSP），无需外部题库，但失败经验是**瞬时的**——只贡献一次策略梯度，不留下可复用的显式经验，即"课程缺少持久状态"。
  - **技能增强 RL（Skill-Augmented RL）**：将经验蒸馏为可检索的技能存入外部记忆，但技能通常来自**固定任务分布**，而非智能体自主选择的练习。
  
- **核心矛盾**："自我对弈决定练什么，但忘记经验；技能增强记住经验，但经验来自它未曾选择的任务。" 两者缺失的关键设定是——**能否同时做到"自己选择练习内容"与"保留经验教训"**。

- **论文目标**：提出 SESA（Self-Evolving Skill-Augmented Agent），将程序性记忆作为工具增强搜索自博弈中的**演化状态**，实现任务生成与技能记忆的**双向共演化**。

## 2. 方法论

### 核心思想
SESA 构建了一个"失败→技能→求解器→新前沿→新失败"的闭环：挑战者出题，求解者检索技能求解，信息量大的失败被蒸馏为技能写回记忆，更新后的记忆改变求解行为与成功率，进而改变挑战者的奖励和未来题目分布。

### 关键设计：四个算法阶段

1. **记忆启动（Memory Priming）**：用 15 条人工编写的技能 + 142 条自博弈启动阶段挖掘的技能初始化技能库 B₀ = B_seed ∪ B_warm（共 157 条），提供初始检索基底。

2. **不对称自博弈（Asymmetric Self-Play）**：
   - 挑战者（proposer）与求解器（solver）为**分离参数化**策略；
   - 技能检索**仅对求解器可见**，防止技能直接泄漏给挑战者；
   - 挑战者通过奖励反馈自适应，但不能直接观察求解导向的记忆。

3. **前沿塑造（Frontier Shaping）**：用钟形、端点惩罚的奖励函数引导挑战者生成**求解器当前能力边界附近**的题目：
   - r_p(x) = -λ（当 p̂_s ∈ {0,1}），否则 r_p(x) = 4(ℓ+p̂_s)(h-p̂_s)；
   - p̂_s(x) 为 G 次求解器 rollout 的成功率；
   - 该机制同时惩罚"全对"（过于简单）和"全错"（不可解）的问题。

4. **失败蒸馏（Failure Distillation）**：三阶段生命周期（同步于训练步）：
   - **检索**：用 E5-base-v2 稠密编码器对问题检索 top-k 技能，仅对求解器前置注入；
   - **失败收集**：失败 rollout 存入 300 条待处理队列，优先重复失败和"有检索指导仍失败"的样本；每 10 步批量处理至少 20 条，最多 30 条；
   - **巩固**：判决器（DeepSeek-v4-pro）将失败抽象为技能卡片（触发条件、区分证据、避免提示、查询模板）；基于余弦相似度 ≤ 0.93 去重；通过有用/有害计数维护记忆（有用则 helpful+1，错误答案则 hurt+1），淘汰负面技能，超出 800 条时低分淘汰。

### 训练优化
- 使用 GRPO（Group Relative Policy Optimization），每个问题采样 G=5 次求解 rollout；
- 奖励采用可验证的答案匹配（先归一化精确匹配，再由模型做语义等价判断）；
- 技能参与在线策略 rollouts，因此技能益处可**内化到模型参数**（支持无记忆部署）而不仅是推理时提示。

### 双路径技能复用
- **SESA-Off**（无记忆推理）：π_off = π_θT(τ|q, T)，测量技能训练带来的参数化携带收益；
- **SESA-On**（记忆增强推理）：π_on = π_θT(τ|q, T, R(q; B_T))，测量推理时检索的额外收益。

## 6. 主要结论与发现

1. **技能持久化提升自博弈效果**：在多骨干上，SESA 相对 SSP 平均提升 1.2–3.2 点，且随模型规模增大或指令微调后**优势不消失**（Qwen3-4B +2.3、Qwen3-8B +3.2、LLaMA-3.1-8B +1.2）；
2. **大部分收益驻留在策略参数中**：SESA-Off（无记忆推理）在 Qwen3-4B 和 Qwen3-8B 上仍比 SSP 高 1.8 和 2.2 点，**说明技能塑造了训练轨迹并内化到参数**，而非仅推理时提示技巧；
3. **外部技能库提供额外但任务相关的增益**：SESA-On 相对 SESA-Off 再增 0.5–1.0 点，验证了记忆库作为可选增强的价值；
4. **失败蒸馏是最关键的组件**：去掉后性能下降最大（2.7 点），直接支持"持久化经验带来超过自博弈更新的价值"的核心主张；
5. **与 SkillRL 相比**：SESA 在同一评估协议下高出 0.9 点，说明"技能演化耦合内生任务前沿"优于"固定数据集上的技能学习"；
6. **训练动态验证共演化机制**：验证质量随训练提升、问题提取成功率上升、活跃技能先扩增后收缩（去重和淘汰导致），表明记忆在自我精炼而非无界增长。

## 7. 优点与亮点

- **概念创新**：首次将"自博弈题目生成"与"持久技能记忆"统一为耦合演化系统，填补了"既能选任务又能记经验"的空白；
- **不对称设计**：技能仅求解器可见、对挑战者隐藏，有效防止策略泄漏，保持博弈的对称性缺失（有意设计）；
- **前沿塑造的奖励设计**：钟形端点惩罚奖励比朴素的"1-准确率"更稳，避免过度奖励不可解题，保证记忆吸收的是可行动失败而非噪声；
- **优雅的双路径评估**：Off/On 对比设计清晰地分离了"参数内化收益"和"外部检索收益"，避免将推理时提示效果误认为训练效果；
- **严谨的基线设置**：SSP 和 SESA 从相同初始化训练，SESA 仅额外开启技能路径，控制变量清晰。
- **记忆维护机制完备**：有用/有害计数、去重阈值（0.93）、容量上限（800）、种子技能保留，形成有生命周期的记忆系统。
