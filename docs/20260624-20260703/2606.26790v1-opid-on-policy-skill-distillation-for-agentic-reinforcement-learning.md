## 摘要
基于结果的强化学习为语言智能体提供了稳定的优化基础，但其稀疏的轨迹级奖励对哪些中间决策应被强化或抑制提供的指导很少。在线策略自蒸馏提供了密集的令牌级监督，然而现有的技能条件变体通常依赖于外部技能记忆或检索到的特权上下文，这些维护成本高昂，并且可能与多轮交互中当前策略所引发的状态分布不匹配。我们提出OPID（在线策略技能蒸馏），这是一个直接从完成的在线策略轨迹中提取技能监督的框架。OPID将轨迹事后视角表示为分层技能：片段级技能捕获全局工作流或故障避免规则，而步骤级技能捕获关键时间步的局部决策知识。一个关键优先路由机制在识别出关键决策时使用步骤级技能，否则回退到片段级技能作为默认指导。所选技能被注入交互历史中，允许旧策略在原始和技能增强的上下文中重新评分相同的采样响应。由此产生的对数概率偏移产生了一个令牌级自蒸馏优势，与结果优势相结合用于策略优化。因此，OPID保留了RL作为主要训练目标，同时引入了密集的、分布匹配的事后监督。在ALFWorld、WebShop和基于搜索的QA上的实验表明，与仅结果RL和现有的技能蒸馏基线相比，OPID普遍提高了智能体性能、样本效率和鲁棒性。我们的代码可在https://github.com/jinyangwu/OPID/tree/main获取。

## Abstract
Outcome-based reinforcement learning provides a stable optimization backbone for language agents, but its sparse trajectory-level rewards provide little guidance on which intermediate decisions should be reinforced or suppressed. On-policy self-distillation offers dense token-level supervision, yet existing skill-conditioned variants often rely on external skill memories or retrieved privileged context, which are costly to maintain and can be mismatched with the state distribution induced by the current policy in multi-turn interaction. We propose \textbf{OPID} (\textbf{O}n-\textbf{P}olicy Sk\textbf{i}ll \textbf{D}istillation), a framework that extracts skill supervision directly from completed on-policy trajectories. OPID represents trajectory hindsight as hierarchical skills: episode-level skills capture global workflows or failure-avoidance rules, while step-level skills capture local decision knowledge at critical timesteps. A critical-first routing mechanism uses step-level skills when critical decisions are identified and falls back to episode-level skills as default guidance otherwise. The selected skill is injected into the interaction history, allowing the old policy to re-score the same sampled response under both original and skill-augmented contexts. The resulting log-probability shift yields a token-level self-distillation advantage, which is combined with the outcome advantage for policy optimization. OPID thus preserves RL as the primary training objective while introducing dense, distribution-matched hindsight supervision. Experiments on ALFWorld, WebShop and Search-based QA demonstrate that OPID generally improves agent performance, sample efficiency, and robustness over outcome-only RL and existing skill-distillation baselines. Our code is available at https://github.com/jinyangwu/OPID/tree/main.

- **整体目标**：提出一种无需外部技能库、且能提供分布匹配的事后监督的框架——OPID，通过从当前策略自己完成的轨迹中提取层次化技能，并将其转化为密集的令牌级引导信号，与结果奖励共同优化策略，从而弥补结果型RL的不足，提升智能体的学习效率与鲁棒性。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
- 将完成的在线策略轨迹视为监督源，从中提取两种层次的文本技能：**片段级技能（episode-level skills）** 捕获全局工作流或失败避免规则；**步骤级技能（step-level skills）** 捕获关键时间步的局部决策知识。通过**关键优先路由（critical-first routing）** 机制，在关键决策状态选用步骤级技能，其余状态回退到片段级技能。将选定的技能注入交互历史，使旧策略在原始和技能增强两种上下文下对同一响应重新评分，得到令牌级自蒸馏优势，并与轨迹级结果优势结合用于策略优化。

### 关键技术细节
1. **在线技能提取**：使用LLM分析器（论文采用GLM-5.2）对每条完成的轨迹（包括任务、观测、动作、反馈和结果）进行分析，输出一个片段级技能和一组稀疏的步骤级技能（针对关键时间步）。
2. **关键优先路由**：若当前时间步被分析器识别为关键步骤，则使用对应的步骤级技能；否则使用片段级技能。
3. **技能注入与自蒸馏优势**：定义$H(\cdot,\cdot)$为确定性技能注入函数，将路由后的技能添加到交互历史中。旧策略$\pi_{\theta_{\text{old}}}$在原历史$h$和增强历史$\tilde h$下对相同的响应$y$进行评分，得到令牌级对数概率差异：
   $$A_{\tau,t,\ell}^{\text{skill}} = (\log \pi_{\theta_{\text{old}}}(y_{\tau,t,\ell}|\tilde h_{\tau,t},y_{\tau,t,<\ell}) - \log \pi_{\theta_{\text{old}}}(y_{\tau,t,\ell}|h_{\tau,t},y_{\tau,t,<\ell})) m_{\tau,t,\ell}$$
4. **组相对结果优势**：遵循GRPO方式，对每个提示的轨迹组内奖励进行归一化：
   $$A_{\tau}^{\text{ep}} = \frac{R(\tau) - \mu_q}{\sigma_q}$$
   广播至所有有效令牌。
5. **最终优势**：
   $$A_{\tau,t,\ell}^{\text{OPID}} = A_{\tau,t,\ell}^{\text{ep}} + \lambda_{\text{skill}} A_{\tau,t,\ell}^{\text{skill}}$$
6. **优化目标**：使用裁剪的PPO目标优化策略，包含KL正则项。

## 7. 优点

- **无需外部知识库**：技能从自身完成轨迹提取，无需维护或检索外部技能库，降低了维护成本和分布不匹配风险。
- **分布匹配**：技能来源于当前策略的轨迹，状态分布自然对齐，避免了离策略偏差。
- **层次化设计**：episode级技能提供全局稳定引导，step级技能提供局部精准引导，路由机制根据关键性灵活选用。
- **保留RL主目标**：RL作为主要优化目标，技能蒸馏作为辅助信号，避免了仅依赖蒸馏可能导致的策略退化。
- **推理零开销**：推理时与普通策略相同，无额外计算。
- **可解释性**：提取的技能是自然语言，便于理解与调试。

## 8. 不足与局限

- **对分析器质量敏感**：技能提取依赖于LLM分析器（论文使用GLM-5.2），若分析器能力不足或偏差，可能影响技能准确性，进而影响性能。
- **训练时额外开销**：每个完成的轨迹都需要调用分析器提取技能，并在旧策略下进行两次前向传播（一次原始历史，一次增强历史），增加了训练计算成本和时间。
- **关键步骤识别无完美保证**：分析器识别的关键步骤未必是最优，可能遗漏或误判，虽然实验显示路由机制能缓解，但仍有改进空间。
- **实验范围局限**：基准测试集中于文本化环境（ALFWorld、WebShop、搜索QA），未涉及更具视觉或多模态的智能体任务（如VisualWebArena、手机操作等），也尚未在如OdysseyArena等更长周期任务上验证。
- **理论分析简化**：附录A中的理论分析采用无裁剪损失假设，实际训练中使用裁剪损失，理论保证仅在局部有效；且分析未考虑技能提取误差的进一步传播。
- **超参数敏感性**：技能系数$\lambda_{\text{skill}}$需要调优，论文未全面分析其敏感性。
- **代码复现成本**：虽然代码开源，但需要部署分析器（如GLM-5.2）和多次前向传播，对普通研究者可能存在门槛。
