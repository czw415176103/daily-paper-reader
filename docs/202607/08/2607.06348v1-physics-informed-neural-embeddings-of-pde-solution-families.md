## 摘要
我们引入了一种物理信息框架，用于学习偏微分方程解族的有限维嵌入。该方法使用多头物理信息神经网络，其中共享主体学习表示解空间的潜在流形，而线性头重构与不同初始条件相关的单个解。头正交化惩罚消除了潜在表示中的退化，并稳定了训练过程中主成分谱。由于初始条件通过构造被纳入网络输出，这些主成分衡量了网络在初始轮廓之上学习到的额外变异性，而非完整解本身。我们将该方法应用于一维粘性Burgers方程，并以热方程和波动方程作为鲁棒性检验。对于潜在维度$n_b=20$，学习到的流形表现出显著的有效降维：对于Burgers动力学，仅2-4个主成分捕获了约95%的潜在空间方差，而4-7个主成分捕获了约99%，具体取决于初始条件族；对于热方程和波动方程，同样存在定性的压缩。我们还沿波数轴划分频带（"傅里叶壳层"），并测量每个频带对每个主成分的贡献。得到的频率分布在正交化惩罚在潜在空间中留下的基变换自由度下保持不变，因此在独立训练中可重复。更广泛地说，这确立了学习到的谱分布和主成分作为解流形几何的稳健可观测量的地位。

## Abstract
We introduce a physics-informed framework for learning finite-dimensional embeddings of solution families of partial differential equations. The method uses a multihead Physics-Informed Neural Network in which a shared body learns a latent manifold representing the solution space, while linear heads reconstruct individual solutions associated with different initial conditions. A head-orthogonalization penalty removes degeneracies in the latent representation and stabilizes the principal-component spectrum across training realizations. Because the initial condition is built into the network output by construction, these principal components measure the additional variability the network learns on top of the initial profile, not the full solution itself. We apply the method to the one-dimensional viscous Burgers equation, with the heat and wave equations as robustness checks. For a latent dimension $n_b=20$, the learned manifolds exhibit pronounced effective dimensional reduction: for Burgers dynamics, only $2$-$4$ principal components capture about $95\%$ of the latent-space variance, while $4$-$7$ capture about $99\%$, depending on the initial-condition family; the same qualitative compression holds for the heat and wave equations. We also split the wavenumber axis into bands (``Fourier shells'') and measure how much each band contributes to every principal component. The resulting frequency profile is invariant under the change-of-basis freedom that the orthogonalization penalty leaves in the latent space, and is therefore reproducible across independent training runs. More broadly, this establishes the learned spectral profiles and principal components as robust observables of solution-manifold geometry.

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

- **核心思想**：
  - 使用多头PINN（Multihead PINN）架构，共享体（body）学习潜在流形，线性头（linear heads）重构不同初始条件对应的解。
  - 通过硬强制（hard enforcement）将初始条件内置到网络输出中，使得潜在成分只表示超出初始轮廓的额外变化。
  - 引入头正交化惩罚（head orthogonalization penalty）消除潜在表示的退化，使主成分谱在不同训练实现下稳定。
  - 定义傅里叶壳层贡献分解，将每个主成分的方差按波数壳层（Fourier shells）拆分，得到跨训练不变的频率分布。

- **关键技术细节**：
  - 网络架构：全连接前馈神经网络，共享体5层×128神经元，输出20维潜在空间；20个线性头（无激活、无偏置）分别对应20个初始条件。
  - 硬强制公式：
    \[
    \psi_{NN}(x,t;\mathrm{IC}_i) = v(x;\mathrm{IC}_i) + F(x,t)\sum_{j=1}^{n_b} w_j^{(\mathrm{IC}_i)} H_j(x,t)
    \]
    其中 \(F(x,t) = \frac{x-x_{\min}}{x_{\max}-x_{\min}}\left(1-\frac{x-x_{\min}}{x_{\max}-x_{\min}}\right)(1-e^{-t})\)，确保初始条件在 \(t=0\) 严格满足。
  - 头正交化惩罚（方形矩阵 \(W\in\mathbb{R}^{n_h\times n_b},\;n_h=n_b=20\)）：
    \[
    L_{\text{add}} = \|WW^\top - I\|_F^2 + \|W^\top W - I\|_F^2
    \]
    迫使 \(W\) 近似正交，从而使得不同训练间的基变换 \(A = W^{-1}\hat{W}\) 近似正交，稳定PCA谱。
  - PCA及傅里叶壳层分解：
    - 计算潜在空间协方差矩阵 \(C_{ij} = \sum_l H_i(x_\mu^l) H_j(x_\mu^l)\)。
    - 傅里叶壳层化：将空间波数 \(k\) 划分为离散壳层 \(Q\)，定义壳层协方差 \(C^{(Q)}\)，其变换规律与全协方差相同。
    - 壳层谱权重：\(\rho_n(Q) = v_n^\top C^{(Q)} v_n\)，满足 \(\lambda_n = \sum_Q \rho_n(Q)\) 且在不同训练间不变（当 \(A\) 正交时）。
  - 数值上还利用了梯度湮灭项（gradient annihilation term）帮助Burgers方程陡峭梯度区域的训练。

## 6. 论文的主要结论与发现

1. **显著有效降维**：在名义维度20的潜在空间中，Burgers方程仅需2-4个主成分即可捕获约95%方差，4-7个捕获约99%；热方程和波动方程同样表现出强烈压缩。
2. **初始条件族依赖性**：多项式初始条件的压缩最强（几乎仅需1-2个PC达95%），傅里叶和小波族需要更多PC；表明结构依赖于训练所用的解族，而非通用的低维表示。
3. **傅里叶壳层谱的稳定性**：头正交化保证了PCA谱及壳层权重 \(\rho_n(Q)\) 在独立训练间可复现，成为解流形几何的稳健可观测量。
4. **物理尺度组织**：前几个主成分主要贡献来自低-中波数壳层（Q1~Q4），高波数壳层贡献迅速衰减，揭示了神经网络学到的层次化尺度结构。
5. **硬强制的重要性**：PCA是对“超出初始条件之外的额外变化”进行的，而非对整个解；特别是波动方程，若对完整解做PCA将得到近平坦谱（因正交傅里叶模式在长时间下仍正交），而潜在空间PCA仍显示压缩，体现了硬强制的设计优势。

1. **全新框架**：首次将PINN的多头架构用于显式分析解流形几何，并通过正交化罚项解决潜表示退化问题。
