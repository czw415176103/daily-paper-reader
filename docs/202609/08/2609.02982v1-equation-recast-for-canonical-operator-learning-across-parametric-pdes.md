## 摘要
在广泛参数范围内学习解算子，可能需要同时覆盖输入函数和物理参数的众多样本，尤其是对于纯数据驱动的参数化模型而言。此外，所得到的模型可能在训练分布之外无声地失效。我们引入了方程重铸，该方法将参数化算子学习重新表述为对单一规范算子的学习。由参数引起的算子变化是从控制方程解析推导出来的，并吸收为有效的源项，从而能够在新参数区间实现零样本预测。在多参数、非线性及奇异PDE设置中，方程重铸支持外推，以共享的规范表示整合稀疏异质数据集，并利用收敛性损失作为重铸迭代失败的内在预警信号。在用于核聚变的高保真托卡马克模拟中，该框架通过在单一联合训练算子内进行规范域映射，统一了四种装置几何结构下的电子温度数据。方程重铸为可复用的神经PDE求解器提供了一条路径，该求解器结合了方程引导的迁移、数据效率与可监测的推理。

## Abstract
Learning solution operators across broad parameter ranges can require substantial coverage of both input functions and physical parameters, particularly for purely data-driven parametric models. In addition, the resulting models may fail silently outside the training distribution. We introduce equation recast, which reformulates parametric operator learning as the learning of a single canonical operator. Parameter-induced operator variations are derived analytically from the governing equation and absorbed into effective sources, enabling zero-shot prediction across new parameter regimes. Across multi-parameter, nonlinear, and singular PDE settings, equation recast supports extrapolation, integrates sparse heterogeneous datasets in a shared canonical representation, and uses loss of convergence as an internal warning signal for failure of the recast iteration. In high-fidelity tokamak simulations for nuclear fusion, the framework unifies electron-temperature data across four device geometries through canonical-domain mapping within one jointly trained operator. Equation recast provides a route toward reusable neural PDE solvers combining equation-guided transfer, data efficiency, and monitorable inference.

## 1. 核心问题与整体含义（研究动机和背景）

- **研究背景**：参数化偏微分方程（PDE）的解算子学习是科学机器学习领域的核心目标。传统纯数据驱动的参数化算子模型通常需要在很宽的物理参数范围内覆盖大量输入函数与物理参数样本，数据获取成本极高；且这类模型往往在训练分布之外静默失效，缺乏内部预警机制。
- **核心问题**：参数化 PDE 的算子学习面临三大难题——(1) 参数空间覆盖需求巨大，难以负担；(2) 训练数据分布之外泛化失败且不易察觉；(3) 无法有效整合来自不同几何、不同设备或不同参数区的稀疏异质数据。
- **整体含义**：本文提出的"**方程重铸**"（equation recast）将参数化算子学习重构为对**单一规范算子（canonical operator）**的学习，将参数变化解析地转化为等效源项，实现新参数区间的零样本预测，为可复用的神经 PDE 求解器提供了新路径。该工作还延伸了 Physics-informed ML 领域对"参数编码器/坐标条件输入"等传统做法之外的另一种结构化方法，在规范化一个算子（embedding）的意义上与 LLM 的规范化思想产生了跨领域共鸣。

## 2. 方法论：核心思想、关键技术细节与算法流程

- **核心思想**：从**控制方程本身解析地**推导出参数变化引起的算子差异，将其吸收为有效的源项，从而训练一个单一规范算子，该算子不依赖物理参数输入。
  - 直觉依据：**单一规范算子足以捕获参数依赖**。作者用 FNO 框架下的二维泊松方程实证表明，若有 `u_k+1 = G(u_k)` 的固定点迭代格式，不同 PDE 参数的解可作为同一规范算子的固定点，仅源项和初始条件不同，且该计算的线性部分与理论预期一致。
- **数学原理**：基于自洽迭代映射 `G(u,x) = sum_i c_i(x) u^{...+1}` 的固定点重铸 PDE 求解；若 `u* = G(u*)` 且参数选择条件导致 c_i 中显式参数依赖可被吸收，则可构造规范方程 `P*u = S`，用统一规范算子覆盖多个参数区；文中给出线性最小二乘定理匹配自洽形式，说明模型设计有理论保证。
- **关键技术细节**：
  - **解析推导**：通过代数从控制方程中显式求解出参数影响，将其编码进有效源项，使规范方程不含原始 PDE 的物理参数；
  - **收敛性损失作为内部预警**：在重铸迭代逼近解的过程中，若迭代不收敛，可作为模型是否失败的内在信号，从而避免"静默失败"；
  - 该方法无需覆盖"参数×输入函数"的乘积空间，只需覆盖输入函数空间即可。
- **算法流程（文字描述）**：
  1. 给定一个参数化 PDE 集合，解析地改写方程，将参数依赖变换为等效的规范方程形式（含有效源项）；
  2. 构造自洽迭代映射 G，利用固定点迭代求解；
  3. 在规范表示的空间上训练单一的神经算子（本文采用 FNO 架构）学习该映射；
  4. 对新参数区间进行推断时，只需对新参数计算等效源项，即可在同一规范算子上实现零样本预测；
  5. 推理过程中监控迭代是否收敛，以预警潜在失败。

## 6. 主要结论与发现

- 方程重铸在数学上保证了解析型参数依赖的表述，避免了特征学习（如参数坐标条件化）对数据覆盖度的依赖，从而实现了真正参数区间外的**零样本预测**。

- 该方法训练成本更倾向于**只覆盖输入函数空间**而不是"参数×函数"乘积空间，因此在理论样本复杂度上更具优势。

## 7. 优点与亮点

- **理论根基扎实**：从控制方程推导参数影响并归入有效源项，这一解析化思路比单纯依赖神经网络从数据中隐式学习参数映射更有数学保证；
- **优雅解决参数覆盖问题**：将参数化算子学习简化为单一规范算子学习，避免了数据量需求随参数维度指数级增长的问题；
- **内部失败监控机制**：固定点迭代"不收敛即预警"的机制为科学 ML 的安全部署和可信推理提供了重要参考；
- **跨几何统一样本**：同时处理多种托卡马克几何结构，使模型向实际问题迈进一步；该跨域/统一方法在整个科学计算和机器学习可迁移性研究的基线上具有方法论意义，为可复用神经 PDE 求解器提供平台价值。
