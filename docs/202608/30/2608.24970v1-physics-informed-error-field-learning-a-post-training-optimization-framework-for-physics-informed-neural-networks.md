## 摘要
物理信息神经网络（PINN）已成为求解偏微分方程（PDE）的一类重要数值方法。然而，在优化过程的后期，进一步的参数更新往往只能带来微弱的精度提升，同时却增加了计算成本。针对这一问题，本文提出了一种用于PINN的物理信息误差场学习（PIEFL）框架。与传统的使用单一网络不断逼近解场的方法不同，PIEFL在主网络达到满意精度后引入一个辅助误差网络，并将学习目标从解场转移到误差场。通过推导物理约束下的误差控制方程，误差网络学习当前近似解与精确解之间的差异，并将学习到的误差修正与主网络的预测相结合，以提高解的精度。所提出的框架避免了持续优化整个解空间，而是将计算资源集中在修正现有预测误差上。此外，PIEFL无需修改主网络架构，因此可与现有PINN模型兼容，并可作为通用的训练后优化策略应用。在代表性PDE上的数值实验表明，PIEFL在相同计算预算下能够获得更高的解精度，验证了其在提升PINN性能方面的有效性。

## Abstract
Physics-Informed Neural Networks (PINNs) have emerged as an important class of numerical methods for solving partial differential equations (PDEs). However, during the late-stage optimization process, further parameter updates often yield diminishing accuracy improvements while increasing computational costs. To address this issue, this paper proposes a Physics-Informed Error Field Learning (PIEFL) framework for PINNs. Unlike conventional approaches that continuously approximate the solution field using a single network, PIEFL introduces an auxiliary error network after the primary network achieves satisfactory accuracy and shifts the learning objective from the solution field to the error field. By deriving error control equations under physical constraints, the error network learns the discrepancy between the current approximation and the exact solution, and the learned error correction is combined with the primary prediction to improve solution accuracy. The proposed framework avoids continuous optimization of the entire solution space and focuses computational resources on correcting existing prediction errors. Moreover, PIEFL requires no modification to the primary network architecture, making it compatible with existing PINN models and applicable as a general post-training optimization strategy. Numerical experiments on representative PDEs demonstrate that PIEFL achieves higher solution accuracy under the same computational budget, validating its effectiveness in improving the performance of PINNs.

- **核心痛点**：PINN 训练进入后期时，持续优化网络参数的**边际收益递减**——精度提升极其缓慢、甚至停滞，但计算开销仍持续增加。此时解网络已捕获解场的整体结构，却仍将大量算力花费在收益极低的参数微调上。
- **核心问题**：在训练收益递减阶段，是否还有必要继续优化原始解网络？能否通过**改变学习目标**（从解场转向误差场）来实现更高效的精度提升？

## 2. 方法论（PIEFL 框架）

### 2.1 总体思路

PIEFL 采用**两阶段级联架构**，将求解过程分解为：

- **第一阶段（主网络）**：训练标准 PINN 获得初始近似解 \(u_p\)；
- **第二阶段（误差网络）**：固定主网络参数，引入辅助误差网络学习误差场 \(u_e = u - u_p\)；
- **最终融合**：将误差网络输出叠加到主网络预测上，得到高精度解 \(u_{\text{final}} = u_p + \hat{u}_e\)。

### 2.2 误差控制方程的推导

- 设 \(u = u_p + u_e\)，代入原 PDE \(\frac{\partial u}{\partial t} + \mathcal{L}[u] = 0\)；
- 结合主网络残差 \(f_p := \frac{\partial u_p}{\partial t} + \mathcal{L}[u_p]\)，定义误差场非线性算子：
  \[
  \mathcal{L}_e[u_e] = \mathcal{L}[u_p + u_e] - \mathcal{L}[u_p]
  \]
- 得到**误差场控制方程**：
  \[
  \frac{\partial u_e}{\partial t} + \mathcal{L}_e[u_e] + f_p = 0
  \]
- 误差网络残差定义为：
  \[
  f_e := \frac{\partial u_e}{\partial t} + \mathcal{L}_e[u_e] + f_p
  \]

### 2.3 误差网络损失函数

\[
MSE_e = MSE_{u_e} + MSE_{f_e}
\]

- \(MSE_{u_e}\)：误差场的初边值条件损失（由原始 IC/BC 减去主网络预测得到 E-IC/BC）；
- \(MSE_{f_e}\)：误差场控制方程的物理残差损失。

### 2.4 关键技术细节

- **不修改主网络架构**：误差网络是独立于主网络的附加模块，因此 PIEFL 可兼容现有各类 PINN 增强技术（网络结构改进、自适应采样、损失加权等），泛用性较强；
- **输出缩放系数 \(\alpha\)**：由于误差场幅值通常很小，引入 \(\alpha\) 放大误差网络输出，降低学习难度；
- **论文分别针对 KdV、非线性 Schrödinger、KP 方程**具体推导了误差场控制方程与残差形式。

## 6. 主要结论与发现

- **核心结论**：PIEFL 在同等计算预算下比标准 PINN 获得更高的解精度，验证了"训练后期从解场学习转向误差场学习"这一思路的有效性；
- **精度提升幅度**（相对标准 PINN 的误差降低率）：
  - KdV 方程：\(84.83\%\)（\(\alpha=0.001\)）；
  - NLS 一孤子：\(95.22\%\)；二孤子：\(91.49\%\)；
  - KP 一孤子：\(80.89\%\)；二孤子：\(38.53\%\)；
- **结构影响**：对于解结构较简单的场景，误差网络能有效学习误差场的主导特征，实现高精度修正；对于复杂解结构（如 KP 二孤子），虽然精确重建误差场变得困难，但误差网络仍能捕捉有用的误差信息，带来正向修正；
- **缩放系数 \(\alpha\) 的作用**：合适的 \(\alpha\)（0.001 量级）能有效放大误差场信号，显著影响误差网络的学习效果；\(\alpha\) 过大会导致误差网络难以收敛（表中 \(\alpha=1, 0.1\) 时 ERR 为负）；
- **收敛行为**：PIEFL 在约 7,000 次迭代时就达到标准 PINN 训练 15,000 次的精度，且后期误差曲线更平稳；标准 PINN 在训练后期误差下降趋缓且波动更明显。

- **方法创新性**：将学习目标从"解场"转移到"误差场"，是 PINN 训练范式的一种重新思考，而非简单的网络结构堆叠；
