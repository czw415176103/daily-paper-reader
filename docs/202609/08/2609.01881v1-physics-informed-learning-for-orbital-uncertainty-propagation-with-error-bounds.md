## 摘要
福克-普朗克偏微分方程（FP-PDE）控制着随机动力系统中的不确定性演化。在轨道动力学中，由于非线性运动、高维状态和大时空域，求解FP-PDE具有挑战性。我们开发了一种物理信息神经网络（PINN）方法，该方法将FP-PDE解近似为单一时空概率密度，同时量化其最坏情况近似误差。这一方法原则上独立于状态坐标选择和神经网络架构。具体而言，为了将概率密度函数（PDF）特性强制引入神经网络，我们设计了一种物理信息高斯混合模型（PINN-GMM）。然后，伴随误差PINN学习近似误差的动力学，并产生时间相关界，这些界定义了PDF的模糊集。该模糊集通过可处理的线性规划实现对事件概率上界和下界的严格计算。对说明性一维示例及多个4D至6D轨道测试用例的数值研究表明，该方法能够实现准确的不确定性传播、正确且信息丰富的误差界，并且相比常见的不确定性传播基线方法（高斯近似、无迹变换和高斯混合模型）具有更高的可靠性。构建PINN-GMM需要离线训练，使其成本高于基线近似方法；然而一旦训练完成，一次前向传递即可在亚毫秒时间内（在我们的实现中为0.16毫秒）返回任意时刻的密度。

## Abstract
The Fokker-Planck partial differential equation (FP-PDE) governs uncertainty evolution in stochastic dynamical systems. In orbital dynamics, solving the FP-PDE is challenging because of nonlinear motion, high-dimensional states, and large space-time domains. We develop a physics-informed neural network (PINN) approach that approximates the FP-PDE solution as a single space-time probability density, while also quantifying its worst-case approximation error. This approach is, in principle, independent of the choice of state coordinates and neural network architecture. Specifically, to enforce probability density function (PDF) properties into the neural network, we design a Physics-informed Gaussian mixture model (PINN-GMM). Then a companion error PINN learns the dynamics of the approximation error and yields time-dependent bounds that define an ambiguity set of PDFs. This ambiguity set enables rigorous computation of upper and lower bounds on event probabilities through tractable linear programs. Numerical studies on illustrative 1D examples and several 4D--6D orbital test cases demonstrate accurate uncertainty propagation, correct and informative error bounds, and improved reliability over common uncertainty-propagation baseline methods (Gaussian approximation, unscented transform, and Gaussian mixture model). Constructing the PINN-GMM requires offline training, making it costlier than the baseline approximations; once trained, however, a single forward pass returns the density at any time in sub-millisecond time $(0.16~\mathrm{ms}$ in our implementation).

# 基于物理信息的轨道不确定性传播学习及其误差界（论文总结）

## 一、论文的核心问题与研究动机

轨道不确定性传播在空间目标碰撞规避、交会分析等任务中至关重要。不确定性随连续时间演化的精确模型由随机微分方程（SDE）描述，其概率密度函数（PDF）的时间演化严格受福克-普朗克偏微分方程（FP-PDE）控制：

$$\frac{\partial p(x,t)}{\partial t} + \sum_{i=1}^{n}\frac{\partial}{\partial x_i}[f_i p(x,t)] - \frac{1}{2}\sum_{i,j=1}^{n}\frac{\partial^2}{\partial x_i x_j}\left[\sum_{k=1}^{m} g_{ik}g_{jk} \, p(x,t)\right] = 0$$

然而，FP-PDE 对一般物理系统不存在闭式解，在轨道动力学背景下求解存在以下核心难点：

- **非线性动力学**导致 PDF 形态随时间的复杂演化；
- **状态维度高**（4D–6D），数值方法受维数灾难困扰；
- **时空域大**，概率质量往往集中在大域中的极小子集，导致采样信息稀释；
- **缺乏误差保证**：现有方法（高斯近似等）无法量化所得密度与真实密度的偏差，误差以未知水平存在，可能造成严重后果。

该文的核心目标即：**在学习空间–时间 PDF 的同时，给出时变的最坏情况逼近误差界**，并以此支撑事件概率的严格上下界计算。

## 二、论文提出的方法论

### 2.1 总体框架

将不确定性传播转化为"单一时空 PDF 的学习"，采用两阶段物理信息学习流程：

1. **密度逼近阶段**：训练 PINN 逼近 FP-PDE 的解 $p(x,t)$；
2. **误差逼近阶段**：训练伴随误差 PINN $\hat{e}(x,t)$ 学习误差 $e(x,t):=p(x,t)-\hat{p}(x,t)$ 的动态方程：
$$\mathcal{D}[e] + \mathcal{D}[\hat{p}] = 0, \quad e(x,0) = p_0(x)-\hat{p}(x,0)$$
再由 $\hat{e}$ 构造误差界 $B(t) = 2\max_{x\in X}|\hat{e}(x,t)|$。

### 2.2 关键设计一：坐标选择策略

为缩减有效计算域、提升可训练性，提出四类坐标设计：

| 坐标类型 | 特点 |
|---|---|
| 旋转球坐标 | 绑定标称轨道旋转，缩小域；有解析坐标变换密度公式（存在极点奇异性） |
| 轨道要素坐标 | 赤道面要素/改进赤道面要素可降低非线性耦合 |
| 参考偏差坐标 | $\delta x = x - x_{\text{ref}}$，当概率集中时显著缩小域范围 |
| 广义映射坐标 | 光滑可逆变换 $z=\Phi(x,t)$，基于 Itô 引理推导隐空间 SDE，连通编码器–潜动态–解码器架构 |

### 2.3 关键设计二：PINN-GMM 分布表示

为保证 PDF 性质（非负、归一化）在构造上天然满足，提出时间条件高斯混合神经网络表示：

$$\hat{p}(x,t)=\sum_{i=1}^{K_{\text{GMM}}} w_i(t)\,\mathcal{N}(x;\,\mu_i(t),\,\Sigma_i(t))$$

核心机制：

- 混合权重、均值、协方差（Cholesky 因子）均由神经网络以时间 $t$ 为输入生成；
- 权重采用 **logit + 均匀混合**形式：$w_i(t)=(1-\alpha)\frac{e^{v_i(t)}}{\sum_j e^{v_j(t)}}+\frac{\alpha}{K_{\text{GMM}}}$，防止权重坍塌；
- 通过**固定编码器**（白化变换）对状态缩放，缓解轨道状态量纲差异巨大的数值稳定性问题；
- 推导了解码过程、边缘密度闭式表达式。

### 2.4 关键设计三：误差界与事件概率模糊集

- 由误差界 $B(t)$ 构造包含真实 PDF 的**可容许 PDF 集合**：
$$\mathcal{P}(\hat{p},B,t)=\left\{p(x,t): |p(x,t)-\hat{p}(x,t)|\le B(t),\ p\ge 0,\ \int p=1\right\}$$
- **命题 1**：事件概率上下界化归为**线性规划（LP）**——将状态域划分为单元格 $\{c_i\}$，对每个单元格取其逐点上下界的松弛，求解上界 LP（含与事件相交的格）和下界 LP（含被事件包含的格）；
- **定理 1**：当 $\hat{p}$ 为 GMM 时，单元格上 PDF 上下界可通过"高斯分布在线性约束集上的极值"获得（对应凸二次规划与 Bauer 最大值原理），使计算可处理。

### 2.5 训练策略

- **损失函数**：初始条件损失采用**Hellinger 型（HT）损失**（对上界总变差有理论意义），残差损失为 FP-PDE 残差的 MSE；误差网络采用标准 MSE；
- **采样策略**：提出"均匀基线 + 自适应池 + 组合"三层次采样，组合策略以 FIFO 方式限制池规模，保持新随机采样对域的覆盖；
- **优化器**：Adam，统一步长衰减，梯度裁剪；对均值网络、协方差网络、权重网络分别设置学习率 $10^{-3}$、$10^{-4}$、$10^{-4}$。

6. **消融分级证据**：PINN-GMM(proposed) > PINN-MLP(vanilla) > PINN-GMM(vanilla) ≈ PINN-GMM(no-encoder)，表明"正确表示 + 好的采样 + 尺度归一化"三项缺一不可；
7. **可计算的事件概率界**：LP 方法能给出含参照概率的上下界区间，且界随分区细化而收紧（4D 情形比 6D 更紧）；
8. **关于成本**：离线训练开销显著（数千秒级），但推理为亚毫秒级别。

## 七、优点

1. **理论奠基较为扎实**：误差界构造源于前期工作[16]的定理（Corollary 1），非启发式安全系数，且界有效性在本实验中得到实证支持；
2. **结构设计遵循物理约束**：以 GMM 形式直接从构造层面保证 PDF 归一化与非负性，绕开了标准 MLP 的后处理或惩罚项；
3. **方法坐标无关**：广义映射坐标框架（含 Itô 引理推导）使之可适配不同坐标系；
4. **下游任务的桥接**：将误差界构建为模糊集（ambiguity set），并给出可执行的算法（Algorithm 1）用于事件概率区间计算；
5. **采样策略创新**：自适应池 + 新鲜随机样本的组合策略有效缓解了高维采样时的信息稀释问题；
6. **消融实验设计完整**：表征了表示选择、采样策略、编码器各自的作用——这在该类文献中较少见；
7. **可直接推理**：训练后实时（0.16 ms）给出密度，适合在线应用；
8. 代码已开源，便于复现、扩展。

## 八、不足与局限

1. **误差界仅是次优/保守的**：误差界取空间最大值（均匀界），比空间变化界更保守；论文承认需要更高阶误差学习才能收紧，但高阶方法在轨道问题中不实用；
2. **误差界有效性依赖误差 PINN 训练精度**：界由误差网络的收敛情况决定。如果误差 PINN 训练不充分，界则不可靠；理论上的"保守检验条件"（[16] Prop. 1）依赖于难以在高维轨道问题中紧凑估计的常数，并未实际评估；
3. **时域受限**：最长传播时域约为 7.2 小时。向 1 天或多天传播的扩展性未验证——而这是轨道不确定性研究中的常见需求；
4. **对假设的约束**：要求动力学连续可微，不适用于含脉冲推进的间断动力学；
5. **大规模 MC 参照系构建成本极高**（最高 66200 秒），且参照密度本身基于 GMM 拟合存在偏差风险；
6. **与部分领域最新方法未直接对比**（张量分解方法[14]、状态转移张量方法[8–10]等），实验相对充分但非穷尽；
7. **没有报告计算环境具体硬件信息**，公平比较训练/推理时间困难；
8. **$K_{\text{GMM}}$ 的选择仍无系统性规则**——论文承认这是一个开放的难题，实际采用试错式策略；
9. **对高维（更高维 > 6D）的可扩展性仍受维数灾难限制**，论文明确承认组合采样等仅是缓解策略，不消除维数灾难。
