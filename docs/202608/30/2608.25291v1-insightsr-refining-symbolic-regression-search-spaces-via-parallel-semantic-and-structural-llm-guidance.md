## 摘要
符号回归(SR)旨在从观测数据中发现简洁的数学定律，然而传统方法往往难以应对物理上有意义的表达式的巨大组合搜索空间。我们提出InsightSR，一个将大型语言模型(LLMs)嵌入为PySR遗传编程引擎周围的指导层的框架。与依赖LLM直接生成表达式不同，InsightSR利用LLM通过两个互补路径逐步转化搜索空间本身：语义种子路径(Semantic Seed Pathway)提出量纲一致的功能骨架，结构特征路径(Structural Feature Pathway)推荐非线性特征变换。这些变换随迭代累积，扩展了输入空间，并将符号搜索从在原始变量上构建深层表达式树转变为在丰富、语义感知的特征集上组装浅层树。生成后的反馈循环评估候选解，根据经验效度对特征进行分类，并为下一次迭代优化指导，将发现过程从开放式生成转变为迭代式自校正优化。在三个基准测试上，InsightSR在费曼基准上达到95%的精确恢复率，在LLM-SRBench LSR-Transform任务上达到80.18%的准确率，大幅超越最先进的遗传编程和神经符号方法，同时在实际数据集上保持强分布外泛化能力。

## Abstract
Symbolic regression (SR) seeks to discover parsimonious mathematical laws from observational data, yet conventional approaches often struggle with the vast combinatorial search space of physically meaningful expressions. We present InsightSR, a framework that embeds Large Language Models (LLMs) as a guiding layer around the PySR genetic programming engine. Rather than relying on LLMs to generate expressions directly, InsightSR uses LLMs to progressively transform the search space itself through two complementary pathways: a Semantic Seed Pathway that proposes dimensionally consistent functional skeletons, and a Structural Feature Pathway that recommends nonlinear feature transformations. These transformations accumulate over iterations, broadening the input space and shifting the symbolic search from constructing deep expression trees over raw variables to assembling shallow trees over a rich, semantically informed feature set. A post-generation feedback loop evaluates candidates, categorizes features by their empirical utility, and refines the guidance for the next iteration, transforming the discovery process from open-ended generation into iterative, self-correcting refinement. Across three benchmarks, InsightSR achieves a 95% exact recovery rate on the Feynman benchmark and 80.18% accuracy on the LLM-SRBench LSR-Transform task, substantially outperforming state-of-the-art genetic programming and neural-symbolic methods while maintaining strong out-of-distribution generalization on real-world datasets.

### 1. 论文的核心问题与整体含义

**研究动机与背景：**
- 符号回归（SR）旨在从观测数据中直接提炼出简洁的数学定律，是自动化科学发现的核心工具之一。
- 符号回归的优化本质上是 **NP-hard 问题**，候选表达式的组合搜索空间随表达式复杂度呈指数级增长，导致传统方法面临严重的**组合爆炸**问题。
- 纯数据驱动的 SR 方法（如遗传规划 GP）经常产生数值精度高但**违反物理原则**（如量纲不一致、违背守恒定律）的表达式。
- 现有基于神经网络的方法（如 DSR、NeSymReS）严重依赖训练分布，**分布外泛化能力差**；且物理约束多为训练时硬编码，缺乏对新型物理情境的适应性。
- 已有的 LLM 辅助 SR 方法（如 LLM-SR、SR-LLM、LaSR）存在两点不足：① 频繁调用 LLM 导致**推理开销大**；② 每种方法仅沿单一维度（结构假设生成或输入空间变换）利用 LLM 引导，**未利用两者的协同潜力**。

**核心问题：** 如何将 LLM 的科学先验知识以低开销、多维度、自适应地嵌入符号回归搜索过程，以缓解搜索空间爆炸并保证物理一致性？

**整体含义：** InsightSR 不是让 LLM 直接生成表达式，而是让 LLM 通过两条互补路径**渐进式地转变搜索空间本身**，将开放式生成转化为迭代式自校正优化，从而显著提升符号回归的恢复率、精度与分布外泛化能力。

### 2. 论文提出的方法论

**核心思想：** 将 LLM 作为引导层嵌入 PySR 遗传规划引擎周围，在搜索前（种子）、搜索中（复杂度偏置）、搜索后（反馈分析）三个环节介入指导，通过语义与结构双重路径协同收敛搜索空间。

**算法流程（每代循环）：**

1. **上下文初始化与单位合成（Contextual Initialization and Unit Synthesis）：**
   - 从数据集元数据和问题描述中提取变量的量纲信息。
   - 对缺失单位的变量，LLM 依据物理语义推断其可能量纲。
   - 通过强制**量纲齐次性**，从搜索空间中剪除物理上不一致的候选表达式。

2. **并行引导策略（Parallel Guidance Strategy）：**
   - **语义种子路径（Semantic Seed Pathway）：** LLM 基于问题上下文和量纲约束，提出**量纲一致的功能骨架**（含有待优化的符号常量），作为物理信息启发的进化搜索种子；同时提供**逐算子复杂度偏置**，引导遗传规划倾向于物理上合理的算子组合。
   - **结构特征路径（Structural Feature Pathway）：** LLM 基于性能历史推荐非线性特征变换（如幂律项 $x_i^n$、超越函数 $\sin(x_i)$），将增广特征拼接至输入矩阵：
     $$X_{aug} = [x_1, \ldots, x_d, \phi_1(x), \ldots, \phi_k(x)]$$
     特征跨代累积，将搜索从构建深表达式树转变为在丰富特征集上组装浅层组合。

3. **PySR 引导搜索（Search with PySR）：**
   - 优化目标：$f^\* = \arg\min_{f \in \mathcal{F}_{seed}} L(f(X_{aug}), D)$
   - **复杂度偏置机制：** 调整表达式树的复杂度惩罚 $C'(f) = \sum_{o \in f}(c_o + \omega_o)$，LLM 推荐的算子获得负偏置（复杂度折扣，促进其在前沿存留），物理上不可能的算子被正偏置惩罚。
   - **热启动机制：** 保留上一代最佳候选作为新一代种群中的精英个体，确保渐进收敛。

4. **多维度评估与策略反馈（Multi-Dimensional Evaluation and Strategic Feedback）：**
   - LLM 作为批后评论者，从**数值精度、物理可解释性、变量覆盖完整性**多维度评估 Pareto 最优候选。
   - 对特征空间做诊断分析，将每个工程化特征分类为有效/无效。
   - 评估结果存入动态知识库，用于在下一次迭代中：优化种子表达式、调整算子复杂度偏置、优先选择特征变换。

### 8. 不足与局限

4. **实验结果缺乏统计分析：** 未提供多次重复实验的方差、置信区间或显著性检验，部分性能指标（如 95% 精确恢复率）的稳健性无法评估。

7. **评估指标偏严格：** 精确恢复率要求符号形式与真值完全等价，但在真实场景中，无数值等价的简化表达式可能同样有效；Acc_τ 对异常值敏感，可能低估实际预测性能。
