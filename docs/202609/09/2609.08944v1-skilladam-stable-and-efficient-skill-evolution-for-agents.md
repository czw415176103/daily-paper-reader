## 摘要
智能体技能为冻结的语言模型智能体提供了一种轻量级的方式来装备领域知识和程序性指导，然而获取高质量技能仍然代价高昂且难以扩展。专家编写的技能需要大量人力。最近的技能自演化方法自动化了一个迭代循环，利用执行反馈来修订技能，但其启发式更新策略往往导致优化不稳定和迭代效率低下。我们识别出在实现稳定且高效的技能自演化中面临的两个挑战。方向稳定性要求有效的修正能够累积，而不是被迭代局部的反馈覆盖。更新自适应性要求每次修订的范围反映近期案例级改进的一致性。我们引入了SkillAdam，一个受Adam启发的框架，用于优化离散且不可微的技能文档。作为Adam一阶矩的功能类比，优化记忆记录已识别的问题和先前解决方案尝试的结果，以稳定更新方向。作为Adam二阶矩的功能类比，波动驱动的编辑预算跟踪近期案例级改进的历史加权变化，并自适应地控制更新幅度。在跨越短程和长程任务的七个基准上，SkillAdam以更稳定的优化动态实现了最先进的性能。它还以显著更少的优化迭代和更低的成本获得了更强的技能，优于先前方法。代码仓库：https://github.com/ruc-datalab/SkillAdam

## Abstract
Agent skills provide a lightweight way to equip frozen language-model agents with domain knowledge and procedural guidance, yet obtaining high-quality skills remains costly and difficult to scale. Expert-written skills require substantial human effort. Recent skill self-evolution methods automate an iterative loop that uses execution feedback to revise skills, but their heuristic update strategies often yield unstable optimization and low iteration efficiency. We identify two challenges in realizing stable and efficient skill self-evolution. Direction Stability requires effective corrections to accumulate rather than be overwritten by iteration-local feedback. Update Adaptivity requires the scope of each revision to reflect the consistency of recent case-level improvements. We introduce SkillAdam, an Adam-inspired framework for optimizing discrete and non-differentiable skill documents. As a functional analogue of Adam's first moment, an optimization memory records identified problems and the outcomes of prior solution attempts to stabilize the update direction. As a functional analogue of Adam's second moment, a volatility-driven edit budget tracks the history-weighted variation of recent case-level improvements and adaptively controls the update magnitude. Across seven benchmarks that span short- and long-horizon tasks, SkillAdam achieves state-of-the-art performance with more stable optimization dynamics. It also obtains stronger skills with substantially fewer optimization iterations and lower cost than prior methods. Code repository: https://github.com/ruc-datalab/SkillAdam

## 2. 论文提出的方法论

### 2.1 核心思想

SkillAdam 以 Adam 优化器为灵感，建立功能对应而非数值对应——不计算梯度，而是在语言空间中构造承担相同优化角色的状态组件：
- **优化记忆（Evolving Issue Tracker，EIT）** ← 类比一阶矩 \(m_t\)：积累已识别的问题、状态及历史解决尝试与结果 → 稳定更新方向
- **波动驱动的编辑预算（Volatility-driven Edit Budget）** ← 类比二阶矩 \(v_t\)：累积近期使案例级改进方差的估计 → 自适应调节更新幅度

### 2.2 关键技术细节

**问题表述：**
- 技能 \(S\) 视为 Markdown 格式的自然语言指令文档；
- 任务数据集 \(D = \{d_1,\dots,d_N\}\)，评估器返回结构化逐案例分析反馈：\(E(S,d) = (\mathbf{E}(S,d), C(S,d))\)，其中 \(\mathbf{E}\) 为数值指标向量、\(C\) 为诊断信息；
- 优化目标：\(J(S) = \Phi(\{\mathbf{E}(S,d) | d \in D\})\)，寻找 \(S^* = \arg\max_{S \in \mathcal{S}} J(S)\)。

**算法流程（每轮迭代 t）：**
1. **Rollout**：从数据集采样小批量 \(B_t\)，以当前技能 \(S_{t-1}\) 执行得到轨迹 \(\mathcal{T}_t\) 与评估反馈 \(F_t^{\mathrm{roll}}\)；
2. **Patch 生成**：LLM patch 生成器以当前技能、轨迹、反馈、上一轮遗存的优化记忆 \(M_{t-1}\) 和编辑预算 \(\sigma_t\) 为条件生成技能补丁 \(g_t\)，得到候选技能 \(\tilde{S}_t\)；
3. **候选评估**：在同一小批量上评估候选技能，获得 \(F_t^{\mathrm{val}}\)，与 rollout 反馈逐案例可比；
4. **接受门控**：根据基准的多指标接受协议判断是否用 \(\tilde{S}_t\) 替换 \(S_t\)；
5. **状态更新**：
   - EIT 利用配对反馈演化问题条目（链接失败、记录尝试与结果、重开复发问题）
   - 计算逐案例改进 \(\delta_{t,i}\) → 方差 \(\hat{V}_t\) → 历史加权波动 \(V_t = \beta_2 V_{t-1} + (1-\beta_2)\hat{V}_t\)
   - 计算下一轮编辑预算：\(\sigma_{t+1} = \max\Big(b_{\min}, \big\lfloor b_{\mathrm{base}} \big(1 - \mathrm{clip}(V_t/V_{\max}, 0, 1)\big) \big\rfloor\Big)\)——高波动对应小预算，低波动允许大范围修改。

### 2.3 核心机制

- **Evolving Issue Tracker**（方向记忆）：结构化问题条目 \(I_j = (p_j, z_j, A_j)\)，记录错误模式、状态、历史尝试与结果，避免重复发现同一失败、防止新修正覆盖有效旧修正；被拒绝修改的失败经验同样被记录。
- **波动驱动的编辑预算**（幅度自适应）：衡量候选技能对评估案例影响的一致性——改进不一（高方差）时收敛编辑范围，改进一致（低方差）时允许更大范围修改。
- **轨迹引导初始化**：使用执行轨迹及评估反馈构造初始技能，优于随机初始化。

## 6. 论文的主要结论与发现

1. **性能领先**：SkillAdam 在全部 7 个基准（10 个切片）上取得最优或并列最优结果——5 个短程基准中 4 个严格最优、1 个并列最优；长程上 DP-Avg 较 SkillOpt 提升 6.7 个百分点（28.3% vs. 21.7%），DP-Travel 从近乎失败的 1.7% 提升至 11.7%。
2. **动态更稳定**：在 Shopping L1 分析中，SkillAdam 首次迭代即发现强修正，且所有被接受的后续技能保持在初始性能之上；SkillOpt 的接受路径则围绕初始性能波动。
3. **效率显著提升**：相同 token 成本下性能增益约为 SkillOpt 的 4 倍；分析运行中约 4M tokens 即达到 56% 测试精度，而 SkillOpt 在约 20M tokens 产生的相当候选尚未被其接受——效率来自更少的无效修改尝试，而非更短的个别调用。
4. **迁移性更好**：GPT-5.5 优化所得技能迁移至 GPT-5.4-mini 时，平均目标分数从 63.1% 提升到 67.8%，平均保留率从 76.2% 提升到 81.3%。
5. **文档质量更高**：在 1-5 分技能质量评判中，SkillAdam 在全部十个切片上高于 SkillOpt，平均从 3.30 提升到 3.88。
6. **消融支持**：完整框架从无组件基线上将 DP-Avg 从 19.2% 提升至 28.3%；单独加编辑预算增益最大（+6.7 pp），单独加优化记忆亦有增益（+2.5 pp）。

## 7. 优点

### 方法层面
- **独创的问题转化**：将 Adam 的矩估计思想抽象为对离散不可微文档优化的“功能对应”框架，而非简单直接套用数值算法——概念上新颖且具启发性。
- **约束保护与经验重用**：EIT 记录历史失败与已解决问题，天然防止回退（regression）；接受门用多指标保护防止弱证据更新破坏既有能力。
- **显式的“何时改多少”控制**：波动驱动的编辑预算依据近期逐案例改进的一致性自适应调节修改范围，不同于此前方法固定步长或启发式修改。
- **无额外验证集需求**：接受决策在同一 mini-batch 的比较反馈上进行，简化了优化流程。
- **跨模型通用性好**：通过优化记忆记录“任务层面”的修正而非模型特有的措辞，使优化所得技能对骨干模型更具移植性。
- **代码开源**：提供仓库便于复现与扩展。

### 实验设计层面
- 覆盖多类型任务（检索问答、文档 VQA、表格操作、数学推理、具身交互、长程规划），包含短程与长程对比、跨模型迁移、文档质量评判等多维度评价；
- 通过同批次同案例评估当前技能与候选技能，确保逐案例反馈可比性；
- 通过与 SkillOpt 共享同一初始技能的设置控制变量。

## 8. 不足与局限

### 实验与评估方面
- **缺少重复实验统计**：未见多次随机种子运行的标准差或显著性检验（如配对 t 检验），结论稳健性难以从统计上判定；
- **单次运行动态分析**：第六节稳定性/效率分析仅基于一次运行（Shopping L1），虽然正文承认无法用单次运行隔离因果，但仍保留一定的过度解读风险；
- **消融的累积式局限**：消融设计无法区分“纯编辑预算”与“纯优化记忆”各自在完整框架中的贡献，也无法分析两者交互；
- **成本度量非货币化**：token 数并不直接对应实际美元开销，也未涉及不同模型厂商价格差异的影响；
- **裁判评估偏见**：技能质量评分虽通过单次调用并隐藏方法名，但未报告评分者间一致性，也未评估裁判维度之间的内部差异。

### 方法与应用方面
- SKILLADAM 需要可数值化且对齐到具体案例的领域评估器来量化逐案例改进 \(\delta_{t,i}\)，在难以获得细粒度自动指标的领域中，应用将受到限制；
- 波动度量依赖小批量（minibatch）的方差——小批量可能导致方差估计噪声较大，极端情况下（<2 有效案例）直接设为零（正文承认该限制）；
- EIT 与 patch 生成依赖 LLM 的指令遵循与结构化输出能力，受骨干模型能力上限制约；
- 超参数（\(\beta_2, b_{\mathrm{base}}, b_{\min}, V_{\max}\)）的取值未见敏感性分析，在不同任务场景下是否需要调整尚不明确；
- 论文未单独清洗分析被拒绝的高测试精度候选的影响——接受门仅依赖已验证的优化用例，可能丢弃潜在有效的修改（正文对第 8 迭代的拒绝案例做了说明，但未系统性分析这种系统性偏差的影响）。

**总体评价**：SkillAdam 在方法设计上具有较强的新颖性与启发性，实验结果呈现也具有较好的多维覆盖度，但其统计稳健性、成本归因和消融的独立隔离方面尚有提升空间。
