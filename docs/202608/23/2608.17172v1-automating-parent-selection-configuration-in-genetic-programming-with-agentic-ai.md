## 摘要
我们研究代理式人工智能是否可以通过引入一个代理框架来自动化遗传编程系统设计过程中的部分环节，该框架利用大语言模型（LLM）推理和检索增强生成来识别并实现父代选择算法。以符号回归作为测试平台，我们首先对四种LLM类型进行消融研究，以评估代理推理和检索对生成算法类别、有效性、实现相似性以及下游性能的影响。结果表明，这些组件显著影响生成的算法类型，但其下游性能在很大程度上取决于底层LLM。最强的配置，即带有5 mini（5 mini--AR）的完整代理设置，一致地生成了成熟的ε-lexicase实现，同时保持了具有竞争力的下游性能。然后，我们将此配置与锦标赛选择和半动态MAD ε-lexicase的固定实现进行基准比较。在六个符号回归问题上，5 mini--AR的表现与ε-lexicase相似，同时总体优于锦标赛选择。这些发现证明了代理式AI在将领域知识转化为生成可执行组件方面的潜力，为进化系统的自动化配置和设计迈出了一步。

## Abstract
We investigate whether agentic artificial intelligence can automate parts of the process of designing genetic programming systems by introducing an agentic framework that identifies and implements parent selection algorithms using large language model (LLM) reasoning and retrieval-augmented generation. Using symbolic regression as a test bed, we first conduct an ablation study across four LLM types to evaluate the effects of agentic reasoning and retrieval on generated algorithm categories, validity, implementation similarity, and downstream performance. Results show that these components substantially influence the types of algorithms generated, but their downstream performance largely depends on the underlying LLM. The strongest configuration, the full agentic setup with 5 mini (5 mini--AR), consistently generated established $ε$-lexicase implementations while maintaining competitive downstream performance. We then benchmark this configuration against fixed implementations of tournament selection and semi-dynamic MAD $ε$-lexicase. Across six symbolic regression problems, 5 mini--AR performed similarly to $ε$-lexicase while generally outperforming tournament selection. These findings demonstrate the potential of agentic AI to translate domain knowledge into generating executable components, providing a step toward automated configuration and design of evolutionary systems.

## 1. 核心问题与研究动机

- **背景**：符号回归（Symbolic Regression, SR）是遗传编程（Genetic Programming, GP）的重要应用领域，GP的灵活性使其能够针对特定问题定制表示方式、评估流程、选择机制和变异算子，但这种灵活性也带来了由大量相互依存的算法与参数选择构成的巨大设计空间。

- **研究意义**：若代理式AI能够自主识别并实现有效的GP组件，将不仅减轻人工配置负担，更可为"自动化设计和构建进化系统"这一更宏大的目标奠定基础，是向"Agentic GP"概念框架迈出的关键一步。

## 6. 主要结论与发现

- **RAG显著改变算法生成行为**：对oss 20b、4o、4.1 mini，LLM和ANR配置几乎100%生成锦标赛选择；引入RAG后，ε-lexicase成为主导算法族（44.4%–98.4%），说明外部领域知识能有效引导模型生成目标算法。
- **5 mini存在先天知识优势**：5 mini在纯LLM配置下就有85.7%的概率生成ε-lexicase，说明该模型预训练知识中已包含较新的父选择方法；ANR反而降低了ε-lexicase比例（73.0%），表明代理推理有时会将模型从正确方向引开。
- **算法族的正确不等于参数化的正确**：尽管AR配置使4o和4.1 mini大量生成ε-lexicase，但其参数化方式大多偏离已有文献的有效设置（4o全部非MAD、4.1 mini仅25.0%用MAD），导致下游性能反而大幅劣化。真正关键的是完整的实现质量（变体、阈值方法）而非算法族标签。
- **最强配置为5 mini–AR**：AR配置使5 mini的ε-lexicase生成率达到100%、MAD阈值使用率升至89.7%，分类成功率达到85.7%（对比LLM 77.0%、ANR 76.2%）。
- **基准结果**：5 mini–AR在6个问题上与固定半动态MAD ε-lexicase均无显著差异，并在5个问题上显著优于锦标赛选择，表明代理框架能产生与专家定义实现竞争的性能。
- **性能不稳定提示需要验证机制**：在Housing和Yacht上个别5 mini–AR重复出现极端MSE值，说明生成质量并非均匀可靠。

## 7. 优点与亮点

- **研究框架的先导性**：首次将代理式LLM+系统化RAG用于GP父代选择的自动化配置，给出了从概念（Agentic GP）到实证落地的完整路径。
- **消融实验设计严谨**：通过AR/ANR/LLM三配置的对比，清晰区分了代理推理和RAG各自的贡献，而非笼统评估"有无AI辅助"。
- **多维评价体系完整**：同时覆盖算法族分布（生成层面）、参数化细节（内容层面）、执行/分类有效性（正确性层面）、代码相似性（一致性层面）和下游测试MSE（性能层面），多层次三角验证。

## 8. 不足与局限

### 8.1 实验覆盖范围有限

- **单一组件**：仅评估了GP四要素（表示、父选择、变异、适应度评估）中的父选择一项，尚未涉及多组件协同的完整Agentic GP闭环。
- **单一领域**：仅限于符号回归的6个中小规模UCI问题，未涵盖程序合成、多目标优化或其他回归以外的常见GP应用域。

### 8.2 语料库与检索配置的局限

- 语料库仅含9篇专家选定的论文，规模较小且依赖人工策划；检索配置固定（top-k=4、块大小256），未系统研究语料构成和检索策略对生成质量的影响。
- RAG工具本身不保证LLM能正确运用检索到的信息——4o和4.1 mini在获得文献后仍生成了偏离文献的参数化方式，暴露了"检索到"与"理解并正确应用"之间的鸿沟。

### 8.3 无验证-反馈闭环

- 框架生成的实现没有经过任何先验验证就投入使用，未经下游性能反馈来修订实现。个别重复上的极端性能失败（Housing、Yacht）正是这一缺点的直接体现；未来应引入"生成-评估-修订"的闭环机制。

### 8.4 LLM选择的局限性

- 仅评估4种模型，且受限于作者基础设施的可用性；GPT-5 mini由于不暴露解码参数，与其余模型在推理设置上不完全对等，可能引入细微偏差。
- 未包含开源替代模型（除oss 20b外）或更前沿的推理型模型，结论的泛化性有待扩展验证。

### 8.5 其他潜在偏差

- 执行失败的实现（如infinite loop、IndexError）被强行赋值为该问题中最差的MSE，这一处理方式虽然使意图明确（惩罚失败），但在统计上可能高估了真实性能差异。
- 代码相似性分析基于Winnowing指纹，受生成代码中的注释、格式差异等因素影响，可能不完全反映语义级别的相似性。
