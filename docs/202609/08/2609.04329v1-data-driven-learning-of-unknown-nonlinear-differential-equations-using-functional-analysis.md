## 摘要
本文重新表述了数据驱动的非线性常微分方程(ODE)发现问题，并提出了一种新的可解释机器学习(ML)方法。该方法旨在仅从单条状态轨迹数据中，在缺乏系统物理先验知识的情况下学习非线性动力学的未知向量场。所提方法与现有方法有两个根本区别：1) 该方法中的表述基于泛函分析与算子理论推导；2) 代价函数在函数空间中被构建为两个函数之间距离的积分形式，而非现有ML方法中使用的误差离散和。提出了一种增量学习算法来以在线方式学习未知向量场以处理新增训练样本。该方法能够从受迫与不受迫的自洽及非自洽(或时变)动力系统中发现未知向量场，并能同时发现随时间变化的外部作用力与未知底层动力学。最后，通过数值算例验证了所提方法的优势。

## Abstract
In this paper, the problem of data-driven discovery of nonlinear ordinary differential equations (ODEs) is recast, and a new interpretable machine learning (ML) method is proposed. The proposed method aims to learn the unknown vector field of nonlinear dynamics without prior knowledge of the system's physics from only one single state trajectory's data. The proposed method has two fundamental differences with existing methods: 1) the formulation presented in this method is derived based on Functional Analysis and Operator Theory, and 2) the cost function is constructed in the function space as a distance between two functions as an integral, instead of the discrete-sum of errors used in existing ML approaches. An incremental learning algorithm is proposed to learn the unknown vector field to handle new training samples in an online manner. The proposed method can discover the unknown vector field from both forced and unforced autonomous and non-autonomous (or time-varying) dynamical systems. The proposed method is able to simultaneously discover unknown external forces as a function of time and unknown underlying dynamics. Finally, numerical examples are given to demonstrate the advantages of the proposed method.

- 现有方法（如 SINDy、NODE、Koopman/EDMD、符号回归、算子学习等）大多依赖**离散误差和**作为损失函数，将样本视为独立无序的点；且普遍存在**可解释性弱、需要导数估计、难以在线更新、需要多轨迹或大量数据**等问题。
- 本文提出一种全新可解释机器学习方法 **FINS（Functional-Analysis-Based Identification of Nonlinear Systems）**，核心目标为：仅用**单条状态轨迹数据**即可学习未知向量场，并可同时辨识未知外部作用力。

## 2. 论文提出的方法论

### 核心思想
- 将 ODE 学习问题重新表述为**函数空间中的优化问题**，基于**泛函分析与算子理论**进行建模。
- 与现有方法的关键区别有二：
  1. 以线性积分算子作用于未知向量场，将原问题转化为算子反演问题；
  2. 损失函数不是离散误差和，而是**函数空间中的积分距离**（即两个函数差的范数平方的积分）。

### 关键技术细节
- 考虑系统：\(\dot{x}(t)=f(t,x(t))+F(t)\)，其中 \(f\) 未知，\(F\) 为外部力（可能未知）。
- 将方程写成积分形式：
  \[
  x(t)=x(t_0)+\int_{t_0}^t f(s,x(s))ds+\int_{t_0}^t F(s)ds
  \]
- 定义线性算子 \(T(f)(t)=\int_{t_0}^t f(s,x(s))ds\)，然后根据观测数据构造序列优化问题：
  \[
  \min_{f}\ \left\| \int_{\bar{t}} f\,ds - x(\bar{t})+x(t_0)+\int_{\bar{t}}F\,ds \right\|_{L^2_w}
  \]
- 在 Hilbert 空间中使用 **Hermite 多项式**作为正交基，将未知向量场展开为有限项：
  \[
  \hat{f}(t,x)=C H(x,t)
  \]
  其中系数矩阵 \(C\) 为优化变量。
- 优化最终化为关于 \(C\) 的**二次型最小化问题**；当 Hessian 半正定时，可转化为求解线性方程，复杂度较低。
- 使用**梯形法则进行数值积分**，从而导出**增量学习算法**（Algorithm 1）：当新数据到达时，只需利用上一时刻的矩阵和少量局部信息递归更新，不需要重新训练。

### 其他重要机制
- 提出了稀疏促进版 **FINS\(_s\)**：通过 \(l_0\)-范数或压缩感知方法筛选稀疏向量场，以获得更简洁的可解释模型。
- 适用范围：
  - 自治/非自治系统；
  - 受迫/非受迫系统；
  - 能同时学习“多项式形式”的隐藏外部输入和底层动力学；
  - 支持均匀与非均匀采样，对初值无特殊限制。
- 限制条件：需要完整状态测量或输入-状态测量，不能用于纯输入-输出数据的系统辨识；非多项式向量场只能部分近似或发现其中多项式分量。

## 6. 主要结论与发现

- 提出的 FINS 方法能够**仅凭单条轨迹数据**，在没有物理先验和经济性模型假设的情况下，准确恢复由有限阶多项式表示的未知向量场。
- 基于函数空间中积分误差的损失函数比离散误差和更自然，能够利用样本之间的时序与连续关系。
- FINS 可同时学习**未知动力学与未知外部力函数**，并且适用于自治、非自治、受迫和不受迫系统。
- 在多个数值算例中，FINS 的预测误差通常比 SINDy 和 EDMD 小约一到两个数量级（如无噪声 Duffing 预测例子），在噪声条件也展现出较好的稳健性。
- FINS\(_s\)（稀疏版本）可以生成极紧凑的模型（甚至精确恢复已知方程），但对噪声的鲁棒性比 FINS 差，对稀疏阈值敏感。
- 增量学习算法使消耗的内存和计算量低，适合在线/实时应用与隐私受限场景，而现有同类方法大多不支持增量学习。
- 对非多项式向量场（如 Mathieu 方程），FINS 能正确发现其中多项式部分（如 \(\dot{x}=y\)），但无法完整恢复非多项式项。

## 7. 优点

- **理论可解释性强**：基于算子理论、Hilbert 空间和 Hermite 正交展开，而非纯黑盒神经网络。
- **数据要求低**：单条状态轨迹即可能恢复未知多项式向量场；不需要多个初始条件生成多个轨迹。
- **无需求导**：避免了 SINDy 等直接方法因差分近似导数而对噪声敏感的问题。
- **支持非均匀采样**：不同于 EDMD/KLT 对均匀采样的依赖。
- **连续积分误差**：尊重物理系统的连续性和光滑性，且不需要在训练循环中求解 ODE。
- **可在线增量学习**：新样本只需局部更新矩阵，极适合实时、嵌入式或内存受限场景。
- **同时辨识外力与动力学**：扩大了传统系统辨识的适用边界。
- **计算开销低**：相对神经网络类方法快数个数量级，且没有大量超参数需要训练。

## 8. 不足与局限

- **需要完整的状态或输入-状态测量**：若只能得到输入-输出数据，FINS 无法给出向量场表示。
- **无法完整学习非多项式向量场**：当系统包含正弦、指数等非多项式项时，只能部分近似或发现某些多项式分量。
- **维度诅咒**：随状态维数 \(n\) 增高或 Hermite 多项式最大阶数增大，待估系数数量和存储矩阵大小会指数增长；虽然讨论了分布式算法思路，但大规模高维应用仍面临挑战。
- **多项式阶数选择无自动化准则**：选太低位欠拟合、选太高会因过拟合和数值不稳定增大误差；论文仅在例子中展示现象，未提出自动确定阶数的方法。
- **系数矩阵半正定条件不保证**：非凸情况下只能求驻点或亚优解，而对应算法未在本文展开。
- **对噪声的鲁棒性缺乏理论证明**：虽然数值实验表现良好，但没有严格的统计误差界。
- **理论收敛性有待深化**：例如在无限数据、非均匀采样或超长时域情形下，算法收敛到真实向量场的数学条件未严格证明。
- **实验以合成数据为主**，缺少真实物理系统的数据验证，可能限制结论的工程可信度。
- **与其他最新深度方法的公平比较不足**：如 ODENet 未充分调参，SymNN 只在一个方程上进行测试；且论文中部分对比方法（如 NODE、DeepONet）未纳入正式实验。
