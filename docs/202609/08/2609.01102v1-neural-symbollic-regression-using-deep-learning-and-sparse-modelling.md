## 摘要
符号回归（SR）旨在发现简洁的数学表达式，以表示数据中的基本关系，其可解释性和科学理解超越了黑箱模型。然而，遗传规划等传统方法面临可扩展性挑战，且对噪声高度敏感，而SINDy等稀疏回归技术则严重依赖预定的特征库。在这项工作中，我们提出了一种神经符号回归（NSR）框架，将神经网络视为符号发现的函数预处理器。我们的方法采用解耦流程：神经网络首先在交互感知的非线性特征空间中学习目标函数的平滑、抗噪声近似，然后应用LASSO提取稀疏、可解释的闭式表达式。通过集成分布式超参数优化与Ray Tune和ASHA调度，提高了预测精度和符号保真度。在Nguyen基准测试集上的实验表明，我们的方法在RMSE、噪声鲁棒性和分布外泛化方面始终优于SINDy和未调优的神经基线。消融研究证实了特征交互、神经网络深度和调优策略的重要性。总体而言，本研究提出了一种可扩展且可理解的神经符号框架，为科学机器学习中的神经逼近与稀疏方程发现之间建立了坚实的桥梁。

## Abstract
Symbolic Regression (SR) seeks to find succinct mathematical expressions that represent the fundamental relationships within data, providing interpretability and scientific understanding that exceeds that of black-box models. Nevertheless, traditional methods like Genetic Programming face challenges with scalability and are highly sensitive to noise, while sparse regression techniques such as SINDy rely significantly on predetermined feature libraries. In this work, we present a Neural Symbolic Regression (NSR) framework that treats neural networks as functional preconditioners for symbolic discovery. Our approach uses a decoupled pipeline: a neural network first learns a smooth, noise-robust approximation of the target function in an interaction- aware nonlinear feature space. LASSO is then applied to extract sparse, interpretable closed-form expressions. To improve predictive accuracy and symbolic fidelity by integrating distributed hyperparameter optimization with Ray Tune and ASHA scheduling. Experiments on the Nguyen benchmark suite show that our approach consistently outperforms SINDy and non-tuned neural baselines in RMSE, noise robustness, and out-of-distribution generalization. Ablation studies confirm the significance of feature interactions, neural depth, and tuning strategies. In general, this study presents a scalable and understandable neural-symbolic framework, creating a solid link between neural approximation and the discovery of sparse equations for scientific machine learning.

- **研究背景**：符号回归（Symbolic Regression, SR）旨在自动发现可解释的闭式数学表达式，以揭示数据背后的基本规律，在科学发现和工程建模中具有重要价值。
- **现有方法的痛点**：
  - **遗传规划（GP）**：表达能力强，但收敛慢、计算开销大、易出现代码膨胀，对高维和噪声数据适应性差。
  - **SINDy 等稀疏回归方法**：将符号回归转化为带惩罚的回归问题，但严重依赖人工预定义的特征库，难以捕捉复杂的非线性交互关系。
  - **神经符号方法（如 DSR）**：将神经网络与符号搜索耦合在同一优化过程中，虽提升灵活性，但易不稳定、计算成本高、可解释性难控制。
- **核心目标**：构建一个**解耦的神经符号回归（NSR）框架**，将神经网络用作符号发现的**函数预处理器**（平滑、降噪），再通过稀疏回归提取可解释的闭式表达式，从而兼顾精度、可解释性与鲁棒性。

## 二、方法论：NSR 框架

### 1. 核心思想

神经网络不直接生成符号表达式，而作为**平滑算子**，先在非线性交互特征空间中学习目标函数的低噪声近似；随后以 LASSO 对同一特征空间进行稀疏回归，恢复出简洁的闭式表达。

### 2. 关键技术流程（四阶段解耦管线）

1. **非线性特征库构建**：
   - 基础函数集：F = {id, sin, cos, exp, log(1+x), x², x³, tanh}。
   - 主特征库：将各基函数作用于每个输入维度，得 Φ(X)。
   - 二阶交互项：Φ⁽²⁾(X) = {fₚ(xₐ)·f_q(x_b) | a≠b, fₚ,f_q ∈ F}，用于捕捉跨维度关系。
   - 完整特征库：Φ_full = Φ(X) ∪ Φ⁽²⁾(X)，总维度 O(kd + k²·C(d,2))，使用 Joblib 并行构建。
   
2. **神经网络近似**：
   - 结构：多层感知机（MLP），以 Φ_full(X) 为输入，层数 L∈{1,2,3}，宽度 H∈{32,64,128}，使用 ReLU/GELU 激活、dropout 和权重衰减。
   - 目标函数：L_NN(θ) = (1/n)Σ(f_θ(Φ(xᵢ)) − yᵢ)² + α‖θ‖²₂。
   - 优化器：AdamW，GPU（CUDA/MPS）加速训练。

3. **LASSO 稀疏符号提取**：
   - 目标：β\* = argmin ‖Φ_full(X)β − y‖²₂ + λ‖β‖₁。
   - 非零系数对应激活的符号项；用 SymPy 重建解析表达式。

4. **分布式超参数优化**：
   - 使用 Ray Tune + ASHA 调度器，自动搜索学习率、网络深度/宽度、批大小和 LASSO 正则化强度 λ，以验证集 RMSE 最小化为目标，提前终止性能不佳的 trial。

### 3. 算法流程（文字版）

> 输入数据集 (X,y) → 构建非线性变换主特征库 → 添加二阶交互项形成完整特征库 → 在该特征库上训练MLP逼近目标函数 → 用LASSO从特征库提取稀疏符号系数 → 用SymPy将激活系数组合为解析式 → 输出符号函数 f\*(x)。

### 4. 复杂度特点

- 时间：O(Nk + EN(kH+H²) + Nk²)，空间：O(Nk + NLH + kH)。
- 与遗传规划（指数式树膨胀）和 SINDy（依赖小规模预设库）相比，NSR 将重计算转移至 GPU 加速的神经训练，稀疏提取仅执行一次。

1. **NSR 在 Nguyen-1 至 Nguyen-3 上取得最低 RMSE**，优于 PySR 和 SINDy，展示了解的稳定性；PySR 在 Nguyen-4 上领先，但跨基准一致性较弱。

## 七、优点与创新亮点

1. **解耦设计**：将"神经函数逼近"与"符号稀疏提取"显式分离，有效降低噪声敏感性，避免单目标耦合过程中的不稳定。
2. **交互感知特征库**：在基础非线性变换上引入二阶成对交互项，在可控的复杂度内增强跨维度公式的恢复能力，弥补了 SINDy 刚性库的不足。
3. **重新定义神经网络的角色**：将神经网络视为符号回归中一种"预处理/预条件"操作而非表达式生成器，视角新颖且实用。
4. **系统引入超参调优到神经符号回归流程**：通过 Ray Tune + ASHA 实现了自动化的架构与正则化搜索，显著改善符号发现的稳定性。
